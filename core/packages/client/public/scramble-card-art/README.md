# Scramble hub artwork

Transparent SVG illustrations for `/scramble`. The page loads them as static
assets and renders card labels, formulas, and MCC rows as text.

| Asset | Renderer and state |
| --- | --- |
| `generate.svg` | VisualCube net for the scramble shown on the Generate card. |
| `solver-cube.svg` | Rounded, fill-only VisualCube projection with only the center stickers colored, shared by Solve and Subsolver. |
| `pattern.svg` | Three VisualCube projections matching the visible sticker patterns in the supplied reference. |
| `batch.svg` | Three cube nets using the shared unfolded SVG renderer, starting with the Generate state. |
| `symmetry.svg` | Eighteen diagrams drawn with the symmetry page's `SymGlyph` geometry. |
| `hardest.svg` | VisualCube net for the first representative in `CN_XCROSS_10_REPS`. |
