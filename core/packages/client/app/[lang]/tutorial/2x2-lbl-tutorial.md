# 二阶层先法教程需求与模板验收

状态：`ACTIVE`。本合同记录 2026-11-19 确认的 Web 教程需求。教法、案例、摆位、公式和口诀以桌面「魔方根资料」中的《2x2 LBL-CHS》为准。

## 教程范围

- 入口在「教程 → 二阶 → 层先法」。引言包含概览，用三个结果图讲清底层、黄面和角位置。认块、拿法和转动记号链接到三阶层先法教程。实体魔方故障不列入教学。
- URL 与三阶采用同一章节格式。`?step=lesson-1` 到引言，`?step=lesson-2` 到底层概览，`?step=lesson-3` 到黄面，`?step=lesson-4` 到角位置，`?step=lesson-5` 到完整示范。`section` 可定位到任一操作小节，也可以把小节 ID 直接传给 `step`。换章加入浏览器历史，手动换节时更新当前地址。
- 课程顺序为底层、黄面、角位置。三章均以概览开场，用两张魔方图和一句说明对比起始状态与目标状态。小节完成反馈只说明本节的达成结果。流程图位于章末，可点击节点查阅相应小节。底层流程图按四个白角的还原顺序排列，黄面和角位置流程图按盘面分类。最后提供一段完整还原示范。示范用同一个魔方和播放进度，从打乱连续走到复原。可随机换打乱，公式和讲解按实际盘面更新。整套独立还原练习暂缓。
- 白橙蓝角分两问，共用同一颗魔方和视角。问题 1 点选白橙蓝角的任一可见贴纸，错答显示所点角块的三种颜色。点「提示」会让其他角块暂时变灰，约 1.6 秒内淡入淡出。点对后仍可转体。点击「继续」进入问题 2 时保留朝向，其他角块保持灰色，目标角保留原色。
- 问题 2 转体把白橙蓝角摆在底层左后，白格朝下。实时反馈和达标判定读取播放器中白格的实际角位和朝向，方位以 F 面为准。进题时恰好摆对，系统随机换一个未达标的朝向。摆对后显示完成提示，仍可继续转体，转离目标后恢复实时反馈。
- 白橙蓝角初始以 F 面为主，露出 R 面 30°、U 面 30°。视角在上下、左右 30° 内自由拖动，到边界后继续拖动一小段触发 90° 转体动画，转后保留边界的观察角。该节不显示视频、进度条或贴纸高亮圈。
- 白蓝红角先试转顶层 U、右层 R、前层 F。点击继续保留当前摆法和视角，白蓝红角从灰色淡入为原色。第二题继续使用这三层，将目标角移到顶层或底层的左前角。开场已经在左前方时，系统随机把目标角换到其他角位。达标后仍可转层，转离目标后恢复待完成时的文案和进度，「继续」暂时失效。回到任一左前角位即可继续。点击「哪里是左前方？」会让两个角位各三张贴纸淡入紫色，约 1.6 秒后恢复原色，开始转层时提前淡出。前两题中白橙蓝角始终留在底层左后。第二题通过后，在同一颗魔方上做第三题「上勾下回」。第三题按 `L' U' L U` 逐步校验转层和方向，贴纸箭头提示下一步，转错时回弹。每做完一组四步检查两个角是否归位，需要时继续下一组。「教我上勾下回」打开独立的二阶演示弹窗，沿用三阶层先法的四步口诀。三题的观察视角均限制在上下、左右各 30° 内。
- 白红绿角先试转 U、R，观察前两个白角留在左侧。摆位题用这两层把目标角移到顶层或底层的右前角，再用右手「上勾下回」归位。
- 白绿橙角先把整颗魔方向左转四分之一圈，让右后的空位来到右前。转体题在上下、左右各 30° 内只调整视角，越界时动画转体 90°。摆位题只转 U 面，把目标角移到空位正上方，再用右手「上勾下回」完成底层。
- 底层摆位或归位小测切题时，当前盘面还未达标就直接沿用。已经达标时随机切换到未达标盘面，在同一个播放器上把目标角贴纸从彩色渐变成灰色，换盘面后再渐变为彩色。块体始终可见，已拼好的角块保持原位。白蓝红角的归位练习从左前方五种盘面中抽取，白红绿角和白绿橙角从右前方五种盘面中抽取，均为底层两种朝向、顶层三种朝向。完成后可点「再练一次」，连续两次抽题使用不同盘面。摆位时试转会带动已归位角块的面，松手后回弹并显示气泡。归位题核对播放器内每个已完成角的实际角位与贴纸朝向。
- 黄面章末的流程图（G 类）按顶面黄格数查阅二碰、四不碰、小鱼或下一章。教学依次讲右鱼、左鱼、二碰、四不碰，四节都从摆位开始。摆对后仍可转 U 面，转离目标时「继续」失效。尝试转其他层时，松手位置旁显示「这一步只转 U 面」。右鱼和左鱼把鱼头摆到指定前角，再用对应公式翻到顶面全黄。二碰和四不碰的左拇指靠在前面左下格旁。每次有效顶层转动结束后，拇指轻拍前面左上格两下。摆对时拇指停在该贴纸上，转离目标后回到初始姿势。接着用右鱼公式变成小鱼。
- 右鱼、左鱼小节的说明区右侧提供辨识视频。全程用 AlgPlayer 的立体魔方，隐去其他颜色后抬高视角，确认顶面一格黄、三格灰。介绍鱼头和鱼鳍时，整张贴纸以紫色闪烁，镜头环绕展示三片鱼鳍。转顶层摆到位后，用气泡指向黄色鱼头和正面的黄色鱼鳍。片尾收起气泡，并排对照两种小鱼。
- 黄面章的公式弹窗打开时按需加载左手模型。教程演示的魔方在手部加载前后保持同一取景尺寸。
- 角位置依次是概览、有眼、无眼、流程图。章末流程图说明两种盘面如何处理。有眼先把眼放到右面。可拖贴纸转 U 面，或横向拖动画布空白处做 y 方向转体。摆到位后仍可继续转，眼离开右面时「继续」失效。接着做二阶教材的 `x' R2 D2 R' U' R D2 R' U R' x`。如果前面用 U 摆眼，公式结束后根据盘面补一次顶层对齐，直到六面复原。无眼直接做一次公式造眼。「有眼」摆位页的标题旁有「什么是眼？」视频，以同色顶排和无眼盘面对照讲解。
- 六个顶层案例均包含互动小测。教学步骤共用一颗魔方，公式按贴纸箭头逐步执行，转错回弹，半转可拆成两次同方向的四分之一转。公式演示沿用三阶的口诀和逐步播放方式。

## 练习目标

2026-11-23 暂停二阶 LBL 的独立「练习本节」入口，练习融入各小节。保留独立练习的题目和判定，日后可通过 `practiceEnabled` 恢复。

| 情况 | 达标条件 |
| --- | --- |
| 白橙蓝角 | 系统识别 `x/y/z` 转体。白格朝下，白橙蓝角位于底面左后。 |
| 白蓝红、白红绿、白绿橙 | 起始态预先完成前面的角。用户找角、摆位，再将目标角归位，保留前面已还原的角。 |
| 二碰、四不碰 | 保持底层，做到小鱼。 |
| 左鱼、右鱼 | 保持底层，做到顶面全黄。 |
| 有眼 | 完整复原。 |
| 无眼 | 保持底层和全黄顶面，做到有一对眼。 |

原稿每种情况至少一题。练习沿用三阶 LBL 的拖动、提示、重来和反馈手感，可按二阶调整。由实际魔方状态判定达标，允许灵活转法。指定公式的题暂时沿用同一判定规则。摆位题的 `x/y/z` 记录来自模拟器的整步转体手势，视角观察不计步。

## 通用模板

后续四阶、五阶、五魔方、SQ1 等教程复用页面骨架、导航、播放、分步展示、练习和反馈。实操节默认按目标、识别与摆位、分步演示、练习组织。概览等小节按需要选用环节。课程提供拼图类型、双语内容、案例状态、动作与达标条件。

图文难以说明连续变化时，用可播放的时间线编排魔方动作、镜头、文案和高亮。时间线允许按镜头选布局；普通教学按小节选布局。沿用[教程画面分类](./responsive-layout-inventory.md)与[多端规范](./responsive-design.md)。

## 布局自动化与真机验收

- 以实际教学容器决定布局。宽于高且两栏能放下主要内容时左右排，其余情形优先上下排。空间紧张先收紧留白、收起次要操作，保证魔方、当前说明与主要控件的可用空间。
- 主测试窗口宽度为 320–1920 CSS px，高度为 320–1200 CSS px。扫描横向、纵向、接近正方形、常见手机及折叠屏视口，额外实测容器宽高比与紧凑布局的切换点。单独列出低于范围时的滚动兜底。报告记录实际采样尺寸，不把采样称作逐像素遍历。
- 逐布局类型检查可见魔方大小、主区和控件相对位置、溢出、遮挡与可点性。页面本身不产生意外滚动；B 类说明区和练习参考区按各自规则处理，滚到底验证末行可达。
- 报告中的四组像素抽查分别测量可见魔方的宽和高，两者均至少达到画布对应尺寸的 45%。
- 练习转屏和折叠展开后保留魔方状态与已记录动作。
- 淡点阵覆盖实际魔方拖动区域。观察小节可拖动改变视角，练习中的拖动按题目要求处理。
- 真机验收覆盖 iPhone 18 Pro Max Safari 横竖屏和 iPhone DUO Safari 外屏、内屏、展开及折叠切换，检查浏览器工具栏、安全区和触控。通用浏览器视口、设备模拟和真机分别记录。

## 样板入口与复用方法

- [二阶课程数据](./2x2-lbl/lesson-data.ts)列章、小节、双语操作要点、观察视角和练习数据。观察画面沿用对应练习的起始状态。
- [InteractiveTutorial](./components/InteractiveTutorial.tsx)消费交互小测、魔方观察和练习数据。新增练习提供初始态、参考路线及状态判定。
- 本地预览运行后，从 `core/packages/client` 执行 `node scripts/check-tutorial-layout.mjs`。`--quick` 只跑代表尺寸，`--last-layer` 只检查黄面和角位置，`--webkit` 使用已安装的 Playwright WebKit。失败截图写到 `.tmp/png/`。可通过 `CUBEROOT_TUTORIAL_URL` 指定预览端点。 [自动化脚本](../../../scripts/check-tutorial-layout.mjs)
