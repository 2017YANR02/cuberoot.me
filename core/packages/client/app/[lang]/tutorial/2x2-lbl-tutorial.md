# 二阶层先法教程需求与模板验收

状态：`ACTIVE`。本合同记录 2026-11-19 确认的 Web 教程需求。教法、案例、摆位、公式和口诀以桌面「魔方根资料」中的《2x2 LBL-CHS》为准。

## 教程范围

- 入口在「教程 → 二阶 → 层先法」。引言包含概览，用三个结果图讲清底层、黄面和角位置。认块、拿法和转动记号链接到三阶层先法教程。实体魔方故障不列入教学。
- URL 与三阶采用同一章节格式。`?step=lesson-1` 到引言，`?step=lesson-2` 到底层概览，`?step=lesson-3` 到黄面。底层四个操作小节依次用 `section=white-orange-blue`、`section=white-blue-red`、`section=white-red-green`、`section=white-green-orange` 定位，也可以把小节 ID 直接传给 `step`。换章加入浏览器历史，手动换节时更新当前地址。
- 课程顺序为底层、黄面、角位置，最后提供一段完整还原示范。示范用同一个魔方和播放进度，从打乱连续走到复原。整套独立还原练习暂缓。
- 白橙蓝角分三问，共用同一颗魔方和视角。问题 1 选白橙蓝角，错答显示所点角块的三种颜色。点「提示」会让其他角块暂时变灰，约 1.6 秒内淡入淡出；点击「继续」进入问题 2 后，其他角块保持灰色，目标角保留原色。问题 2 点底层左后，错答显示实际点到的位置。点「提示」会让这个角位及其背面提示贴纸短暂变紫。位置以 F 面为基准，按角块当前占用的位置判断。前两问均可点同一个角的任一可见贴纸。问题 3 实际摆放魔方，提示和达标判定统一读取播放器中白格所在的角位及朝向。
- 白橙蓝角初始以 F 面为主，露出 R 面 30°、U 面 30°。视角在上下、左右 30° 内自由拖动，越界时用动画完成一次 90° 转体，转后保留越界前在边界的观察角。该节不显示视频、进度条或贴纸高亮圈。摆位练习要求白格向下，角块位于底面左后。
- 问题 3 摆对后锁定转体，仍可在上下、左右各 30° 内调整视角，拖到边界即停。
- 白蓝红角先试转顶层 U、右层 R、前层 F。点击继续保留当前摆法和视角，白蓝红角从灰色淡入为原色。第二题继续使用这三层，将目标角移到顶层或底层的左前角。开场已经在左前方时，需要先转离两个目标角位，再转回来。达标后仍可转层，目标角处于任一左前角位时「继续」才可用。点击「哪里是左前方？」会让两个角位各三张贴纸淡入紫色，约 1.6 秒后恢复原色，开始转层时提前淡出。前两题中白橙蓝角始终留在底层左后。第二题通过后，在同一颗魔方上做第三题「上钩下回」。第三题按 `L' U' L U` 逐步校验转层和方向，贴纸箭头提示下一步，转错时回弹。每做完一组四步检查两个角是否归位，需要时继续下一组。「教我上钩下回」打开独立的二阶演示弹窗，沿用三阶层先法的四步口诀。三题的观察视角均限制在上下、左右各 30° 内。
- 白红绿角先试转 U、R，观察前两个白角留在左侧。摆位题用这两层把目标角移到顶层或底层的右前角，再用右手「上钩下回」归位。
- 白绿橙角先把整颗魔方向左转四分之一圈，让右后的空位来到右前。摆位题只转 U，把目标角移到空位正上方，再用右手「上钩下回」完成底层。
- 两节小测切题时保留魔方状态。摆位时试转会带动已归位角块的面，松手后回弹并显示气泡。归位题核对播放器内每个已完成角的实际角位与贴纸朝向。
- 二碰用可拖动观察的魔方、操作要点和参考公式讲解，随后可进入对应练习。
- 黄面样板包含「二碰 → 小鱼」的教学和对应练习。

## 练习目标

| 情况 | 达标条件 |
| --- | --- |
| 白橙蓝角 | 系统识别 `x/y/z` 转体。白格朝下，白橙蓝角位于底面左后。 |
| 白蓝红、白红绿、白绿橙 | 起始态预先完成前面的角。用户找角、摆位，再将目标角归位，保留前面已还原的角。 |
| 二碰、四不碰 | 保持底层，做到小鱼。 |
| 左鱼、右鱼 | 保持底层，做到顶面全黄。 |
| 无眼 | 保持底层和全黄顶面，做到有一对眼。 |
| 有眼 | 完整复原。 |

原稿每种情况至少一题。练习沿用三阶 LBL 的拖动、提示、重来和反馈手感，可按二阶调整。由实际魔方状态判定达标，允许灵活转法。指定公式的题暂时沿用同一判定规则。摆位题的 `x/y/z` 记录来自模拟器的整步转体手势，视角观察不计步。

## 通用模板

后续四阶、五阶、五魔方、SQ1 等教程复用页面骨架、导航、播放、分步展示、练习和反馈。实操节默认按目标、识别与摆位、分步演示、练习组织。概览等小节按需要选用环节。课程提供拼图类型、双语内容、案例状态、动作与达标条件。

图文难以说明连续变化时，用可播放的时间线编排魔方动作、镜头、文案和高亮。时间线允许按镜头选布局；普通教学按小节选布局。沿用[教程画面分类](./responsive-layout-inventory.md)与[多端规范](./responsive-design.md)。

## 布局自动化与真机验收

- 以实际教学容器决定布局。宽于高且两栏能放下主要内容时左右排，其余情形优先上下排。空间紧张先收紧留白、收起次要操作，保证魔方、当前说明与主要控件的可用空间。
- 主测试窗口宽度为 320–1920 CSS px，高度为 320–1200 CSS px。扫描横向、纵向、接近正方形、常见手机及折叠屏视口，额外实测容器宽高比与紧凑布局的切换点。单独列出低于范围时的滚动兜底。报告记录实际采样尺寸，不把采样称作逐像素遍历。
- 逐布局类型检查可见魔方大小、主区和控件相对位置、溢出、遮挡与可点性。页面本身不产生意外滚动；B 类说明区和练习参考区按各自规则处理，滚到底验证末行可达。
- 报告中的四组像素抽查分别测量可见魔方的宽和高，两者均至少达到画布对应尺寸的 45%。
- 练习转屏和折叠展开后保留魔方状态与已记录动作。
- 淡点阵覆盖实际魔方拖动区域。观察小节可拖动改变视角，练习中的拖动按题目要求处理。
- 真机验收覆盖 iPhone 18 Pro Max Safari 横竖屏和 iPhone DUO Safari 外屏、内屏、展开及折叠切换，检查浏览器工具栏、安全区和触控。通用浏览器视口、设备模拟和真机分别记录。

## 样板入口与复用方法

- [二阶课程数据](./2x2-lbl/lesson-data.ts)列章、小节、双语操作要点、观察视角和练习数据。观察画面沿用对应练习的起始状态。
- [InteractiveTutorial](./components/InteractiveTutorial.tsx)消费交互小测、魔方观察和练习数据。新增练习提供初始态、参考路线及状态判定。
- 本地预览运行后，从 `core/packages/client` 执行 `node scripts/check-tutorial-layout.mjs`。`--quick` 只跑代表尺寸，`--webkit` 使用已安装的 Playwright WebKit。失败截图写到 `.tmp/png/`。可通过 `CUBEROOT_TUTORIAL_URL` 指定预览端点。 [自动化脚本](../../../scripts/check-tutorial-layout.mjs)

## 本轮本地验收

- Windows 桌面 Chrome 通过 176 组窗口尺寸，覆盖 A、B、F 三类画面。通过实际渲染尺寸抽查、色块指向、说明末行可达、播放中缩窗与练习状态保留。
- 引言和底层概览分别在 14 组代表尺寸检查中英文排版和末项可达。URL 直达、刷新、浏览器前进后退均通过验证。
- 浏览器中用鼠标实测 x、y、z，并在移动触屏模拟中验证单指转体及横竖屏切换。底层四道练习和黄面样板题通过端到端判定。
- iPhone 18 Pro Max 和 iPhone DUO 的 Safari 真机验收待补。浏览器记录采用通用视口与触屏模拟。
