# LBL / F2L 教程多端适配

状态：`REFERENCE`。适用于 Web 上的 LBL 和 F2L 教程，含隐藏章节。本文规定布局与验收要求；不代表所有章节、设备都已验收。原生 App 和小程序不在本次范围内。

## 1. 按画面分类，不按播放器实现分类

同一类画面应有相同的排版和交互，不区分它由静态魔方、AlgPlayer、视频还是时间线编排实现。只有真正的时间线视频可以随镜头在短句、参考卡和总结图之间切换类型。非视频教学按整个教学单元固定一种布局，不能因播放进度、出现第二句或短公式改变类型（维护者要求，2026-11-16）。

“1～2 行文案”指一句或两句简短说明，不是固定两行高度。英文或窄屏自动换行后，仍属于短句布局；不得截断文字或缩小字体来强行凑行数。

### 分类依据与呈现方式（2026-11-16）

先判断内容的重要性、是否必须同时可见，再判断能否分阶段呈现。保留 A、B 的区别；旧 E（魔方加流程图）合入 C（魔方加完整图文），共 A、B、C、D、F、G 六类。静态或动态不决定布局类型。

每个画面还要区分两种呈现方式：

- **教学 / 阅读**：用户决定阅读速度。A、B 按最新的区域独立适配规则处理：A 无滚动，B 仅手机说明区可滚动。C 的说明区滚动及 D/F 的各自阅读规则另行适用。
- **时间线视频**：独立时间进度驱动编排镜头，每个镜头分别分类。自动播放的 AlgPlayer、带步进控制的完整演示仍属于非视频教学，不因名称有“演示”或内部使用计时器就算视频。舞台与播放控件位置稳定，正常字号下不能依赖滚动才能看懂当前画面。先去掉重复信息、调整主次占比；仍放不下时拆成连续镜头，而不是把整张桌面画面和文字等比缩小。

时间线视频的 C 类可按“整体关系 → 魔方动作及当前参照 → 完整总结”编排。只需要当前公式段时按 B 类呈现；必须同时比较的内容仍须同屏，不能任意隐藏一半。手机端不得仅因舞台较矮而隐藏原镜头的正文或用气泡内容替换正文；教学气泡保留在气泡内，与该镜头完整说明同时可见。仅章节顶部师生对话沿用手机端隐藏规则（2026-11-17 修正）。手机拆镜头应共享原始状态和播放进度，不能改变公式、动作次序或教学结论。结束后可停留阅读完整图文。

宽度超过 760px 且高度不超过 500px 的极矮横屏目前保留舞台滚动兜底：隐藏重复的问答区，播放控件留在舞台外，图文保持可读；这不是无滚动演示的验收通过。

极端小视口、浏览器放大文字时，可读与可操作优先于禁止滚动；允许说明区的兜底滚动，不能用 overflow 隐藏未能容纳的教学内容。验收时必须区分正常视口通过与此兜底。

逐章、逐镜头核对见 [画面分类清单](./responsive-layout-inventory.md)。分类完成不等于浏览器验收完成。

## 2. 尺寸与布局切换

尺寸单位是浏览器视口的 CSS 像素，不是设备物理分辨率。折叠屏、分屏和横竖屏按当前可用空间处理，不按设备名称判断。

| 尺寸类别 | 判定与用途 | 布局要求 |
| --- | --- | --- |
| 宽屏 | 通常为宽度 ≥ 1024px 的电脑或平板 | 左侧小节导航；正文可以左右并排。适当放大魔方，不把留白全部堆在一边 |
| 中等宽度 | 761～1023px | 保留可折叠侧栏；正文扣除侧栏后不足以容纳两栏时，改上下排列。不能仅因为超过 760px 就强行挤成两栏 |
| 窄屏 | 宽度 ≤ 760px | 隐藏左侧侧栏，小节菜单放到底部翻页区；正文以魔方在上、说明在下为主 |
| 小手机 / 短屏 | 例如 320×568、375×667；横屏也可能很矮 | 优先减少装饰间距和魔方占高，保证文字、公式、操作按钮可读可用；确实放不下时仅下方说明区滚动，主魔方与控件不滚动 |

760px 是当前共用导航的切换断点；1024px 是验收分类，不是要求新增统一媒体查询。正文是否能并排，要看实际剩余宽度。低高度是独立约束，不能只检查宽度。

## 3. 共用导航与页面骨架

- 顶部章节导航统一使用 `ChapterNavigation`。`tutorial-chapters` 外层上下 padding 均为 **0**，电脑和手机一致；按钮内部间距另算，不因压缩外层留白而失去点击区域。
- 窄屏章节过多时横向滚动，当前章节保持可见；不换成多行挤占教学区。
- 桌面小节导航使用 `TutorialNavigationShell`，每个小节是标准导航项；折叠后保留图标。折叠按钮与图标中心在同一列，展开和折叠过程中不能水平跳动。
- 桌面小节目录沿用 Navigation Shell，不换回旧控件。展开／折叠按钮固定在顶部，仅下方目录滚动；滚动条始终隐藏，上下方向仍有内容时显示对应箭头，可点击滚动约七成可视高度，滚轮和触控板仍可用。图标保持 36px，窗口高度 ≤ 650px 时收紧行距。切换当前小节时仅在目录内部将其尽量居中，首尾受滚动边界限制；用户手动浏览时不自动拉回。缩窗、展开折叠和条目变化后重新检查溢出，尊重减少动态效果设置（2026-11-17）。
- 导航背景融入页面底色，选中和悬停状态使用站内主题样式。两套教程共用命名和组件，不分别维护外观相同的实现。
- F2L Lesson 3、Lesson 4 的分类导航只展示具体分类（如“层先”“顶同分离”“顶异分离”），桌面侧栏与手机菜单一致；不展示“入门”“顶层分离”等上一级分组标题。保留原有分类顺序、案例归属与跳转。
- 手机的小节菜单使用 `SectionMenu`，与上一节、下一节、练习或示例切换按钮放在同一个底部操作区。
- 翻页区保持在学习区底部，不随字幕长短或播放阶段上下跳动。固定操作区必须预留空间和安全区，不能遮住最后一行文字或公式。
- 魔方、控件、说明区应有稳定的布局位置。改变字幕、出现高亮或展开公式时，不应让魔方和翻页按钮跟着移动。
- 正文沿用现有最大宽度；LBL 不超过 1180px。大屏适配不靠无限拉宽页面完成。

### 手机主魔方与滚动边界（2026-11-16 更新）

- 维护者最新要求：单个主魔方在上、说明在下的画面，主魔方及播放控件不参与纵向滚动；A 类说明独立适配、不滚动；B 类下方说明和公式可独立滚动，C 类参考卡或流程图按自身规则处理。顶部章节导航和底部翻页区保持固定。
- 本条取代此前将魔方、控件、文案一起放入学习区滚动的实现；B 类原有的独立说明区规则继续有效。普通教学中的 C 类同样遵守；A 类说明改为独立缩放适配，不滚动，不因使用静态图、AlgPlayer 或时间线演示而改变滚动边界。
- 主魔方默认画布尺寸 350px，同时受可用宽度及扣除导航、播放控件后的可用高度 60% 上限约束；画布尺寸不包含进度条和操作按钮。同一可用视口的同类小节采用相同预算，不随当前文案长短变化。
- 说明区占剩余高度，允许收缩；A 类独立缩放，手机 B 类可独立滚动，不能再用 160px 等最小高度撑大外层、把魔方推离视口。短句在区域内安全居中；超长内容从顶部阅读，最后一行必须可到达。每个说明区只保留一个纵向滚动容器，不再在阶段内部嵌套滚动。
- 小手机或低高度先减少留白、缩小魔方占高，不回退到让主魔方随文字滚动。D 类多魔方对比、F 类纯图文仍按各自规则滚动；G 类练习遵守其操作与提示区域边界。
- 实现验收必须实际滚动说明区，确认魔方、播放控件和底部按钮坐标不变；文档规则不代表未核对的画面已完成适配。

## 4. 布局类型

### A. 一个魔方 + 1～2 行简短说明

典型画面：观察一个棱角的位置、讲解当前动作、完整演示中的一句提示。对应 `tutorial-single-caption`。

| 宽屏 | 窄屏 | 小手机 / 短屏 |
| --- | --- | --- |
| 魔方在左，说明在右；说明在所属区域居中，与魔方视觉平衡。已有上下式短片可保留上下结构 | 魔方在上，说明在下；文字水平居中，并在下方可用说明区内垂直居中；字号采用重点句档，默认 1.5rem（根字号 16px 时为 24px） | 保留可读字号，允许自然换行；先减少空白和魔方占高。文字自然换行后仍超过区域时，说明构图独立缩放到容器内，不滚动、不裁切 |

- 没有第二句、备注或公式时，不保留一行空内容的占位。
- 不把一句话放在大块下半区域的左上角，也不为凑满高度添加无意义说明。
- 短句切换时预留合理稳定区域；当前样式的最小高度是实现参数，不应成为短屏溢出的理由。

“角块在底层”的引导短片（含“无论哪种情况，直接做右公式”结尾）属于 A 类：只展示简短说明，不重复列出公式和口诀；公式留在随后正式教学中。分类依据是画面的教学结构，不按实际换行数机械判断。

### B. 一个魔方 + 分阶段公式和文案

典型画面：每阶段包含动作说明、公式、口诀；播放时依次进入不同阶段。总内容可以很长，但同一时间只需完整展示当前阶段。当前阶段不是机械限制为一两行，公式与对应动作不可拆散。对应 LBL 的 `SegmentedInstructions`、F2L 的阶段列表。

| 宽屏 | 窄屏 | 小手机 / 短屏 |
| --- | --- | --- |
| 魔方在左，阶段说明在右；阶段按阅读顺序排列，当前阶段明确高亮。右侧说明区独立适配大小，不滚动；左侧魔方独立适配容器，控件保持可操作 | 魔方和播放控件在上，阶段说明在下；下方是独立的可滚动区域，自动跟随当前阶段 | 先控制魔方高度，为说明区留出能阅读当前阶段的空间；阶段过高时在同一个说明滚动区继续向下阅读，不能只显示标题而把公式永久挡住 |

字号例外（2026-11-16，维护者要求）：B 类在视口宽度 ≤ 760px 时允许适度降低教学文字字号；宽屏基础字号沿用原值，整个说明构图仅在放不下时独立缩放。按 `data-tutorial-layout="B"` 限定，动态演示仅当前 B 类画面使用，不波及 A 类短句、C 类参考卡、导航和播放器按钮。LBL 备注／口诀 0.875rem、正文 1rem、步骤标题／公式 1.125rem、独立大记号 1.375rem；F2L 阶段标题／公式 0.9375rem、演示说明 1.125rem，已有更小的辅助文字不再缩小。仍保留自然换行、独立滚动和浏览器文字缩放，不按内容长度继续压缩。

自动跟随与手动阅读规则：

B 类说明区垂直居中（维护者要求，2026-11-16）：电脑端右侧、手机端下方的公式与文案作为一个整体，在所属说明区内上下居中。内容超过可用高度时安全回退到顶部起排，保留同一个滚动区及原有播放跟随／手动浏览，不能因居中导致首段不可到达。已有说明区缩放仍使用其居中结果，不重复添加居中偏移；本条不改变文字的水平对齐。

1. 使用播放器实际转动位置判断当前阶段，不另开定时器猜进度。拖动进度、步进、重播和点击公式后的高亮、滚动位置一致。
2. 阶段进入时，仅在当前内容不完整可见时滚动；内容已经可见就不移动。过高的阶段先对齐顶部，不强行居中。
3. 自动滚动只作用于说明区，不把整张页面和魔方一起拉走。
4. 用户触摸滑动、滚轮滚动、拖动滚动条或使用滚动键时，暂停自动跟随。播放器可继续播放，后续阶段不能抢回阅读位置。
5. 再次操作播放、步进、进度条、重播或点击教学步骤时，恢复跟随；仅重置魔方视角不恢复。不要几秒后自动恢复。
6. 切换教学案例或小节时重置跟随状态。尊重减少动态效果设置，使用即时滚动替代平滑滚动。

共用入口为 `useTeachingFollow`，窄屏说明区使用 `tutorial-follow-pane`。桌面目前不自动跟随；不要把手机跟随行为描述为已覆盖桌面。

### C. 一个魔方 + 完整图文（含原 E 流程图）

典型画面：魔方配完整参考卡、状态关系图、动态流程图或转化路径。图文是有独立信息量的教学主体，不能当短字幕压缩。动态高亮只改变行为，不增加布局类型。

| 宽屏 | 窄屏 | 小手机 / 短屏 |
| --- | --- | --- |
| 魔方在左；右侧说明与参考卡分区，卡片位置稳定，当前公式段高亮 | 主魔方与控件固定在上，说明和参考卡放在下方同一个滚动区；卡片里的小魔方、名称、公式保持关联 | 下方整体允许滚动，优先保留当前讲解和对应公式；长公式按教学分组换行，不缩成难以辨认的小字 |

- 这类画面不能直接套用“单句说明垂直居中”，否则参考卡可能被挤出可用区域。
- 文案已经说明当前动作时，不在文案和卡片里重复堆放同一份公式。
- 如下方还有多阶段列表，按 B 类处理跟随；只有一张参考卡时，不凭播放进度无意义地滚动。

### D. 两个或多个同等重要的教学单元

典型画面：LBL 与 F2L 对比、正确与错误对比、术语总结。每个单元包含魔方、标签、进度和补充说明，必须作为一组安排。同步比较优先同屏、等宽、相同魔方比例；不能为了放大一侧而隐藏另一侧。

| 宽屏 | 窄屏 | 小手机 / 短屏 |
| --- | --- | --- |
| 并排或按关系排列，统一魔方比例；说明和进度条有稳定位置 | 简单的两个小魔方可并排；每个魔方附带较多文案时改为上下排列，保持标签与魔方对应 | 优先保证关键贴纸、标签可辨认；不能把整组画面等比缩小成看不清的缩略图。普通教学上下排列后允许内容区滚动；连续比较保留两侧同屏，先压缩重复说明与进度的排版 |

- 时间线由多魔方切到单魔方时，不能造成进度条或翻页区跳动。
- 悬停放大不推动下方文案、进度条；触屏通过点击获得同等信息，不能依赖 hover 才能读到解释。

### F. 纯图文 / 案例列表

典型画面：概念介绍、公式记号、魔方结构、案例选择网格；没有持续播放的主魔方。

| 宽屏 | 窄屏 | 小手机 / 短屏 |
| --- | --- | --- |
| 使用完整正文宽度，按内容组织图文或网格；不保留空魔方栏 | 减少网格列数，图与对应说明靠近；多段正文左对齐，短图注可居中 | 保留字号，进一步减少列数；长内容在学习区滚动，末项仍可到达 |

纯阅读内容不启用播放跟随。不能因为它只有一个 `<p>` 就把整篇长说明按 A 类居中。

**整体等比例缩放（维护者确认，2026-11-16）**：F 类普通图文根据窗口或屏幕中的实际可用内容区域缩放。图片、文字和间距作为一个整体，保持原比例，完整居中呈现。比例同时受可用宽度和高度约束；空间不足时缩小，空间足够时保持原尺寸，不额外放大。导航和翻页按钮不参与缩放，不把浏览器外框尺寸或设备物理分辨率当作正文可用尺寸。

当前共用实现为 `ReadingFit`，已接入 LBL 图文阅读（包括 Lesson 5 概览）及 F2L 案例列表的电脑端；窗口大小变化时重新计算比例。此规则取代这些桌面画面原有的 F 类滚动兜底，已由试用转为确认方案。宽度 ≤ 760px 目前仍沿用原布局，手机端的具体缩放效果需另行实现与验收，不能据此宣称已覆盖。独立流程图继续保留此前确认的二维拖动，不自动套用整体缩放。

**章节概览的分类**：LBL 和 F2L 的概览先区分视频与静态图文。静态图文概览统一归 F 类，即使含有多个魔方状态示意，也作为完整图文整体缩放；视频概览继续按每个镜头的内容类型排版，不整段套用 F 类。视频中的纯图文镜头同样归 F 类，在电脑端复用整体等比例缩放，按扣除播放控件后的舞台宽高完整显示；时间线、播放进度与控件尺寸不变。纯图文总结即使有多个魔方示意或转化路径，也不因“视频”形式而排除缩放（维护者确认，2026-11-16）。LBL 底面十字概览按 F → A → F：小花到十字总览与结尾正确／错误对照是 F 类，整体缩放；中间聚焦单魔方、倾斜与高亮是 A 类，电脑端魔方沿原时间线平滑移向左侧，文案在右侧居中，保持正常字号，仅魔方适配可用高度。进度条在舞台外，切换布局不重置播放；手机端保留现有上下排列。F → A 过渡时，先隐藏说明，等魔方完成移位后再用同一播放时钟淡入文字；暂停、进度拖动和重播均按同一时间点还原，不用独立延时器提前显示文字。该约定不将公式轮播、交互教学或练习仅因入口名称包含“概览”就改成静态图文。电脑端静态概览已统一接入共用缩放，具体入口与保留的视频／交互分支见画面分类清单；未提供静态概览的章节不额外新增概览。

独立流程图使用一个二维浏览区域，同时承接横向、纵向和斜向拖动，不再由内层横滚、外层竖滚分别处理。顶部章节导航和底部翻页区保持固定；图中节点轻点仍可预览或跳转，拖动后不得误触。保留滚轮、键盘滚动与浏览器双指缩放。这属于 F 类阅读交互，不改变连续演示的固定舞台规则。

## 8. 桌面缩窗与滚动治理：讨论方案（2026-11-16，待确认）

维护者反馈：桌面浏览器缩小窗口后，多类教程画面普遍出现滚动条。本轮先讨论并记录方案，不修改页面实现。以下是建议，不覆盖前文已确认的字号、分类、手动阅读、二维流程图和播放契约；需要改变既有行为的项目确认后再实施。

### 问题与目标

当前规则分别允许外层学习区、阶段说明、参考图文等区域滚动。如果多个层级同时依靠滚动处理空间不足，局部都可访问，整体仍会产生多个滚动区域。加上宽度断点没有充分表达高度限制、导航与正文各自保留最小尺寸，就容易在桌面缩窗时集中暴露问题。具体溢出链仍需后续逐层测量，不能将此分析当成所有页面已定位的结论。

目标是让约定支持尺寸内的核心教学画面无需滚动即可理解和操作，而不是仅隐藏滚动条。禁止裁切正文、隐藏未呈现的教学内容，或将整张桌面画面连同文字不断缩小。任意小窗口、字号不降、全部内容同时展示、绝不滚动四项不能同时保证，必须明确内容组织和极端尺寸的取舍。

### 统一空间分配

1. LBL 与 F2L 共用学习区布局规则：先从实际窗口扣除页头、章节导航、翻页与播放控件，再给正文分配可用宽高。不要让每个组件分别按整屏计算高度、再加上自身最小高度。
2. 同时判断正文的可用宽度与高度。窄而高的空间可以上下排列；宽而矮的空间优先保持左右排列，不能一缩窗就上下堆叠。桌面窗口也可以进入紧凑布局，不按设备名称区分。
3. 空间不足时依次减少装饰留白、收紧重复的页头／问答、将导航改为紧凑形式、调整栏比例与魔方大小；达到文字与图形可读下限后，转入内容组织方案，不继续硬挤。
4. 同一教学单元的魔方、说明与控件预算稳定，不随每一句话长短改变。非视频教学仍保持整个单元的类型；只有时间线视频按镜头切换类型。缩窗、改变排列不重置播放、案例选择或用户浏览位置。

### 各类内容如何减少滚动

| 类型 | 建议的核心教学呈现 | 必须保留的信息与取舍 |
| --- | --- | --- |
| A：魔方＋短说明 | 同屏呈现完整短说明；依空间改左右／上下布局，优先调整魔方与留白 | 不裁字、不截成省略号；长翻译不能仅凭原文短就假定能放下 |
| B：魔方＋分阶段内容 | 紧凑空间只展示一个完整阶段，用明确的前后阶段操作查看其他阶段；播放时跟随当前阶段 | 阶段里的动作、公式与口诀保持关联；用户查看其他阶段时暂停跟随，不能把浏览其他阶段自动当成跳转播放器。宽裕空间可展示完整列表。此建议会改变现有长列表滚动交互，待确认 |
| C：魔方＋完整图文 | 为图文保留足够面积，允许其占比超过魔方；重排参考卡和路径，去掉重复说明 | 必须同时对照的内容不能随意拆页。仍放不下时提供明确的完整图文查看方式；它是否允许阅读滚动或二维平移，需要按内容确认，不能宣称所有 C 类都能强行一屏化 |
| D：多个比较单元 | 魔方、标签、进度作为完整单元等量分配；精简重复信息，优先保持比较对象同屏 | 不能用左右分页或轮播替代需要同时观察的比较，也不把额外进度拆离所属魔方 |
| F：纯图文 | 普通图文按实际可用宽高整体等比例缩放，完整居中呈现（已确认，详见 F 类规则） | 图片、文字和间距一起缩放，导航及翻页按钮保持原尺寸；独立流程图保留已确认的二维拖动。手机端实施与验收另行处理 |
| G：练习 | 操作魔方、题目及必要按钮优先同屏；详细帮助通过既有按需入口查看 | 不把关键提示、反馈和提交操作藏进折叠区；不改练习行为来迁就布局 |

时间线视频沿用镜头编排处理信息密度：当一个镜头无法在可读尺寸下完整展示时，按教学意义拆镜头或调整主次，不添加多个需要观众滚动查找的区域。必须同时比较的信息仍同屏。

### 明确滚动归属与验收边界

- 在支持尺寸内，A 类及核心播放画面以无阅读滚动为验收目标；B 类完整列表阅读、C/F 的完整资料和流程图是需要单独明确的交互，不与无意的布局溢出混为一谈。
- 同一正文不允许父子层级重复承接同一方向的滚动。确有阅读滚动时，只指定一个明确的容器；二维图仍由同一个画布承接两个方向。导航自身的列表浏览与正文分开检查。
- 明确“正常支持尺寸”和“极端缩窗／文字放大兜底”，不能以隐藏滚动条或强制全屏掩盖溢出。全屏可作为可选观看方式，不能成为正常学习的前提。
- 后续实施先选 A、B、C、D 各一个代表画面验证共同布局，再迁移其余模板；最终验收仍覆盖全部正式／隐藏小节及时间线分支，不能用代表画面的通过替代全量覆盖。
- 桌面验收应连续拖动窗口，而非只查几个固定分辨率；分别测试只减宽、只减高、宽高同时减小，并覆盖侧栏展开／折叠、中英文与文字放大。记录每一个可滚动区域的用途、正文剩余尺寸和内容是否完整。

待讨论决定：紧凑 B 类采用单阶段浏览是否合适；C/F 的完整资料是否保留明确的独立阅读入口；正常支持的最小窗口及极端尺寸兜底边界。确认这些取舍后，再修改现行规则与共用实现。

### 当前讨论范围：普通桌面小窗口（2026-11-16）

维护者明确：先聚焦电脑端，以消除滚动条为目标；未最大化、较矮但不极端的浏览器窗口也应能正常学习。本目标不是要求用户最大化、全屏或缩小浏览器字号。以下实施方法和具体尺寸仍是建议，本轮只记录讨论，不修改页面代码。

- **先以小窗口设计，再扩展大窗口**：建议首先验证网页可用区域 1000×600、900×500、1280×500，再检查 1440×900。尺寸单位为 CSS 像素，不含浏览器标签栏与地址栏；这是拟定的验收起点，不是已通过的支持声明。500px 高的普通桌面窗口不能未经分析就归为极端场景。
- **高度独立触发布局收紧**：窗口即使很宽，只要高度不足也要进入紧凑布局；优先保持左右排列，减少顶底留白，限制导航及辅助内容的总占高。正文依真实剩余高度分配，移除与这份预算冲突的固定高度、最小高度和重复预留。
- **导航也纳入无滚动目标**：短窗口的左侧目录不能保持大行距后自行出现滚动条；优先采用紧凑导航，仍放不下时使用明确的小节选择入口。全部小节必须可访问，不靠裁掉菜单项解决。此建议会调整现有“目录过长可独立滚动”的规则，确认后再落实。
- **当前教学信息一屏完整**：A 完整短说明；B 当前完整阶段及查看前后阶段的操作；C 完整必要参照；D 两侧完整比较单元；G 必要提示及操作。内容原本就超过一屏时，按教学意义重排或拆成学习步骤，不能只加 overflow 或不断缩小字体。C/D 必须同时观察的信息不能任意拆开。
- **保留主动浏览的明确边界**：独立完整流程图的二维拖动是此前确认的功能，不等同于普通页面溢出；是否连其滚动条指示也隐藏、改用图形浏览控件，需另行确认。不能在消除滚动条时静默取消图的可达性。
- **先做一套共用骨架原型再迁移**：用普通小窗口验证导航、教学区和控件的共同空间预算，然后套用各类内容模板；完成后检查全部章节及画面，杜绝每节自行决定滚动兜底。正常支持范围内出现普通页面或教学面板滚动，应作为布局／内容组织问题处理，不标为正常通过。

下一步应先确认小窗口验收起点与 B 类单阶段呈现，再做共用布局原型；本讨论不授权立即重构，也不改变先前已确认的公式、播放与练习语义。

### Lesson 5 去右／去左的引导视频（2026-11-16）

### 普通桌面小窗口的视频舞台（2026-11-16）

宽度超过 760px、视口高度超过 500px 时，单主魔方视频应按导航和播放控件扣除后的真实剩余高度布局，不沿用固定 430px 舞台撑出滚动条。优先压缩留白和魔方，文字及播放按钮保持正常尺寸；“点击继续”放在说明末尾，与说明共用现有区域，不在舞台外另留位置。验收检查实际 scrollHeight 与 clientHeight，不能仅隐藏滚动条或裁切内容。此规则针对视频教学区；章节目录过长仍允许独立滚动。极矮屏幕与放大文字的可读性兜底继续有效。

A/B 区域独立适配（2026-11-16 最新要求，取代上一轮桌面 B 类右侧滚动方案）：桌面左右、手机上下。A 类魔方和说明分别适配容器，均不滚动；B 类魔方区同样不滚动，说明／公式区桌面独立缩放适配、手机允许独立滚动。基础字号在空间充足时不变，必要时只缩放说明构图，不缩放整页或播放按钮。不得隐藏溢出内容冒充适配；极矮视口和放大文字仍以可读性兜底。
