# 教程多端排版规范

状态 `REFERENCE`。这是 CubeRoot Web 教程的共用排版规范，覆盖 LBL、二阶 FL、F2L 及其隐藏章节。各章节的验收结果单独记录。

## 1. 按画面分类，不按播放器实现分类

新增或修改页面时，先按学习任务选 A–G 类，再复用同类画面的骨架、响应式断点与操作区。标题、案例数量和提示文字由各章节提供。非视频教学按整个教学单元固定一种布局。独立时间线视频可以按镜头切换类型。确需例外时，在画面分类清单记录适用场景和原因。

“1～2 行文案”指一句或两句简短说明，不是固定两行高度。英文或窄屏自动换行后，仍属于短句布局；不得截断文字或缩小字体来强行凑行数。

### 分类总览

| 类别 | 画面结构 | 桌面 | 手机竖屏 |
| --- | --- | --- | --- |
| A | 一个魔方与一两句短说明 | 左侧魔方，右侧短句居中 | 魔方在上，短句在下居中 |
| B | 一个魔方与分阶段公式、文案 | 左侧魔方，右侧阶段列表独立滚动 | 魔方和播放控件在上，阶段列表在下独立滚动 |
| C | 一个魔方与完整参考图文 | 左侧魔方，右侧完整参考卡、路径或流程图 | 魔方在上，整组参考在下，空间不足时允许阅读区滚动 |
| D | 多个同等重要的教学单元 | 各单元并排对照 | 各单元纵向排列，每组魔方、说明和控件放在一起 |
| E | 引言、概览、纯图文或公式列表 | 使用完整正文宽度，按内容组织图文或卡片网格 | 减少网格列数，长内容在阅读区内滚动 |
| F | 章节实操、练习或自由摆放 | 左侧可操作魔方，右侧题目、操作和反馈或参考 | 魔方在上，操作与说明在下，翻页区固定 |
| G | 独立交互流程图 | 单个可平移的画布，导航固定 | 触摸拖动同一画布，保持节点可读可点 |

先判断画面需要同时展示哪些内容，再判断能否分阶段呈现。独立流程图归 G，配合主魔方阅读的参考流程图归 C。含多个魔方示意的静态概览整体归 E，有独立演示内容且需要相互对照的教学单元归 D。

### 呈现方式

每个画面还要区分两种呈现方式：

- **教学 / 阅读**：用户决定阅读速度。A、B 按最新的区域独立适配规则处理：A 无滚动，B 说明区在上下和左右布局中均可独立滚动。C 的说明区滚动及 D/E 的各自阅读规则另行适用。
- **时间线视频**：独立时间进度驱动编排镜头，每个镜头分别分类。自动播放的 AlgPlayer、带步进控制的完整演示仍属于非视频教学，不因名称有“演示”或内部使用计时器就算视频。舞台与播放控件位置稳定，正常字号下不能依赖滚动才能看懂当前画面。先去掉重复信息、调整主次占比，仍放不下时拆成连续镜头。紧凑横屏的 C 类可独立等比缩放右栏。

时间线视频的 C 类可按“整体关系 → 魔方动作及当前参照 → 完整总结”编排。只需要当前公式段时按 B 类呈现，必须同时比较的内容应同屏。手机端保留镜头的完整正文，教学气泡按[共用规则](#教学气泡)显示。拆镜头时共享原始状态和播放进度，保留公式、动作次序和教学结论。结束后可停留阅读完整图文。

非紧凑横屏且宽度超过 760px 时，单主魔方视频以扣除导航和播放控件后的实际可用高度安排舞台。高度超过 500px 时优先缩减留白和魔方占高，保持文字可读和播放按钮尺寸。高度不超过 500px 时可使用舞台滚动兜底，播放控件留在舞台外。

极端小视口、浏览器放大文字时，可读与可操作优先于禁止滚动；允许说明区的兜底滚动，不能用 overflow 隐藏未能容纳的教学内容。验收时必须区分正常视口通过与此兜底。

逐章、逐镜头核对见 [画面分类清单](./responsive-layout-inventory.md)。分类完成不等于浏览器验收完成。

## 2. 尺寸与布局切换

尺寸单位是浏览器视口的 CSS 像素，不是设备物理分辨率。折叠屏、分屏和横竖屏按当前可用空间处理，不按设备名称判断。

| 尺寸类别 | 判定与用途 | 布局要求 |
| --- | --- | --- |
| 宽屏 | 通常为宽度 ≥ 1024px 的电脑或平板 | 左侧小节导航；正文可以左右并排。适当放大魔方，不把留白全部堆在一边 |
| 中等宽度 | 761～1023px | 保留可折叠侧栏；A、B、C 仍左右排列，并按剩余空间调整两栏宽度、魔方尺寸和说明 |
| 窄屏 | 宽度 ≤ 760px | 隐藏左侧侧栏，小节菜单放到底部翻页区；A、B、C 改为魔方在上、说明在下 |
| 小手机 / 短屏 | 例如 320×568、375×667；横屏也可能很矮 | 优先减少装饰间距和魔方占高，保证文字、公式、操作按钮可读可用；确实放不下时仅说明区滚动，主魔方与控件不滚动 |

**普通视口沿用 760 CSS px 的宽度断点。** 宽度大于 760px 时，A、B、C 类主魔方在左，说明在右。宽度不超过 760px 时，主魔方在上，说明在下。竖屏与折叠屏分屏同样按当前视口宽度判定。短横屏优先用下方规则。

### 紧凑横屏

视口宽大于高且高度不超过 **500 CSS px** 时，LBL、二阶 FL 和 F2L 隐藏侧栏，有小节目录的章节使用底部小节菜单。页面让出系统安全区，播放条和翻页区各自占用独立空间。极短的 F2L 横屏（高度不超过 **350 CSS px**）将页头和章节导航并排，章节导航可横向滚动。

- **A、B、C 的排列**由实际教学区决定。扣除安全区、顶部导航、底部操作和舞台外播放控件后，宽度至少 **480 CSS px**，且高度达到下限时左右排。F2L 时间线舞台的高度下限为 **104 CSS px**，LBL 和 F2L 其他单魔方教学区为 **120 CSS px**。未达下限时上下排，必要时仅在教学区内滚动，播放和翻页控件保持可达。
- **C 类右栏**将完整说明和参考卡或路径作为一个整体等比缩放，魔方、播放和翻页控件使用独立尺寸。缩放比例低于 **72%** 时，右栏恢复原字号，允许独立滚动。上下排时沿用下方说明区规则。能点击的流程图节点、公式和步骤仍可通过原入口操作。
- **D、E、F、G**按各自的对比、阅读、练习和流程图规则处理。横屏目录规则同样适用，共用底部导航的页面不得因字幕、列表或练习内容变化而移动翻页区。
- 旋转、折叠、改变分屏宽度时重新按可用空间排版，保留当前小节、镜头、播放位置及练习进度。

**A、B、C 的主魔方共用尺寸规则。** LBL 和 F2L 的桌面及手机布局均以 **350 CSS px** 为默认画布边长，同时受容器可用宽度和可用高度 **60%** 的上限约束。计算可用高度时先扣除导航、播放控件和底部操作区占用的空间。主魔方在同一视口、同一布局中使用稳定的尺寸预算，说明长短变化时保持画布和控件位置稳定。

**A、B、C 的桌面左栏共用垂直对齐规则。**

- 左栏只有主魔方时，魔方本身在左栏上下居中。舞台外的播放进度条和按钮保留在原位置。
- 播放进度条和操作按钮位于左栏时，将魔方与控件作为一组上下居中，播放和切换步骤时保持整组位置稳定。
- 指向主魔方或块位的教学气泡按下方[共用规则](#教学气泡)作为浮层显示。

### 教学气泡

LBL 和 F2L 共用同一套放置顺序，按主魔方所在区域的实际可用空间和气泡内容判断。

1. 指向特定棱块或角块时，按当前视角下可见贴纸的投影对齐尾巴。侧边气泡须能完整排成一两行。
2. 优先尝试原侧、另一侧和上方的对齐位置。空间无法容纳对齐方案时，允许气泡在可用区域内偏移，保留目标块高亮。
3. 气泡放不下时，保留目标块高亮和原有讲解。

气泡作为浮层，不占布局空间。出现、换字、换位置或隐藏时，主魔方、进度条与操作按钮保持原位。

**F2L 章节顶部师生对话**沿用独立规则，在视口宽度不超过 760 CSS px 或高度不超过 **600 CSS px** 时隐藏，为教学区腾出空间。

## 3. 共用导航与页面骨架

- 顶部章节导航统一使用 `ChapterNavigation`。`tutorial-chapters` 外层上下 padding 均为 **0**，电脑和手机一致；按钮内部间距另算，不因压缩外层留白而失去点击区域。
- 窄屏章节过多时横向滚动，当前章节保持可见；不换成多行挤占教学区。
- 桌面小节导航使用 `TutorialNavigationShell`。目录项只显示文字，最小行高为 44px，长标题换行时随内容增高。折叠时只显示顶部展开按钮。按钮沿用 Navigation Shell 默认尺寸，点击区域与目录条目左对齐，切换状态时保持水平位置。
- 展开时仅下方目录滚动，滚动区域上下各预留 28px 放置箭头。滚动条始终隐藏，上下方向仍有内容时显示对应箭头，可点击滚动约七成可视高度，滚轮和触控板仍可用。切换当前小节时仅在目录内部将其尽量居中，首尾受滚动边界限制；用户手动浏览时不自动拉回。缩窗、展开折叠和条目变化后重新检查溢出，尊重减少动态效果设置。
- 导航背景融入页面底色，选中和悬停状态使用站内主题样式。各教程共用导航组件及样式。
- F2L Lesson 3、Lesson 4 的分类导航只展示具体分类（如“层先”“顶同分离”“顶异分离”），桌面侧栏与手机菜单一致；不展示“入门”“顶层分离”等上一级分组标题。保留原有分类顺序、案例归属与跳转。
- 手机的小节菜单使用 `SectionMenu`，条目与桌面目录一样只显示文字。菜单入口保留展开箭头，与上一节、下一节、练习或示例切换按钮放在同一个底部操作区。
- **每次展开小节导航菜单，当前选中项都必须完整可见。** 如果只露出一部分或在可视区域之外，仅滚动菜单列表，将该项带入可见区域。展开后允许用户自由滚动。
- 翻页区保持在学习区底部，不随字幕长短或播放阶段上下跳动。固定操作区必须预留空间和安全区，不能遮住最后一行文字或公式。
- 魔方、控件、说明区应有稳定的布局位置。改变字幕、出现高亮或展开公式时，不应让魔方和翻页按钮跟着移动。
- 同一视口、同一教学步骤且滚动位置相同的时候，反馈、提示、勾选标记、按钮或补充说明的出现、更新和收起，都不得挤动已有文字、进度、控件和魔方。按钮从禁用变为可用时，位置和点击区域保持一致。优先使用浮层、预留可换行的反馈区，或把新内容放到已有内容之后并保持滚动容器稳定。主动换步、调整视口和手动滚动按各自布局规则处理。
- 正文沿用现有最大宽度；LBL 不超过 1180px。大屏适配不靠无限拉宽页面完成。

### 手机主魔方与滚动边界

- 单个主魔方在上、说明在下的画面，主魔方与播放控件固定。A 类说明独立适配，B 类下方说明和公式可独立滚动，C 类参考卡或流程图按各自规则处理。顶部章节导航和底部翻页区保持固定。
- 说明区占剩余高度，允许收缩；A 类独立缩放，B 类说明可独立滚动，不能再用 160px 等最小高度撑大外层、把魔方推离视口。短句在区域内安全居中；超长内容从顶部阅读，最后一行必须可到达。每个说明区只保留一个纵向滚动容器，不再在阶段内部嵌套滚动。
- 小手机或低高度先减少留白、缩小魔方占高，不回退到让主魔方随文字滚动。D 类多魔方对比、E 类纯图文仍按各自规则滚动；F 类练习遵守其操作与提示区域边界。
- 验收时实际滚动说明区，确认魔方、播放控件和底部按钮坐标保持稳定。

## 4. 布局类型

### A. 一个魔方 + 1～2 行简短说明

典型画面：观察一个棱角的位置、讲解当前动作、完整演示中的一句提示。对应 `tutorial-single-caption`。

| 宽屏 | 窄屏 | 小手机 / 短屏 |
| --- | --- | --- |
| 魔方在左，说明在右；说明在所属区域居中，与魔方视觉平衡 | 魔方在上，说明在下；文字水平居中，并在下方可用说明区内垂直居中；字号采用重点句档，默认 1.5rem（根字号 16px 时为 24px） | 保留可读字号，允许自然换行；先减少空白和魔方占高。文字自然换行后仍超过区域时，说明构图独立缩放到容器内，不滚动、不裁切 |

- LBL 和 F2L 以 LBL 引言的「格」「中心块」「角块」为字号基准。主提示用 1.5rem（24px），补充说明用 1.25rem（20px），单独展示的转动记号用 1.75rem（28px）。
- 没有第二句、备注或公式时，不保留一行空内容的占位。
- 不把一句话放在大块下半区域的左上角，也不为凑满高度添加无意义说明。
- 短句切换时预留合理稳定区域；当前样式的最小高度是实现参数，不应成为短屏溢出的理由。

“角块在底层”的引导短片（含“无论哪种情况，直接做右公式”结尾）属于 A 类：只展示简短说明，不重复列出公式和口诀；公式留在随后正式教学中。分类依据是画面的教学结构，不按实际换行数机械判断。

### B. 一个魔方 + 分阶段公式和文案

典型画面：每阶段包含动作说明、公式、口诀；播放时依次进入不同阶段。总内容可以很长，但同一时间只需完整展示当前阶段。当前阶段不是机械限制为一两行，公式与对应动作不可拆散。对应 LBL 的 `SegmentedInstructions`、F2L 的阶段列表。

| 宽屏 | 窄屏 | 小手机 / 短屏 |
| --- | --- | --- |
| 魔方在左，阶段说明在右；阶段按阅读顺序排列，当前阶段明确高亮。右侧说明区保留布局字号，超高时独立滚动并跟随当前阶段；左侧魔方独立适配容器，控件保持可操作 | 魔方和播放控件在上，阶段说明在下；下方是独立的可滚动区域，自动跟随当前阶段 | 先控制魔方高度，为说明区留出能阅读当前阶段的空间；阶段过高时在同一个说明滚动区继续向下阅读，不能只显示标题而把公式永久挡住 |

**共用教学字号**。LBL 和 F2L 使用相同档位。数值按根字号 16px 换算。

| 文字用途 | 宽屏 | 窄屏（≤ 760px） |
| --- | --- | --- |
| 步骤标题、公式 | 1.5rem（24px） | 1.125rem（18px） |
| 说明 | 1.25rem（20px） | 1rem（16px） |
| 口诀、备注 | 1rem（16px） | 0.875rem（14px） |
| 单独展示的转动记号 | 1.75rem（28px） | 1.375rem（22px） |

说明区长内容使用独立滚动，保留当前屏幕档位的字号。保留自然换行和浏览器文字缩放。导航、播放器按钮与其他排版类型沿用各自规则。

自动跟随与手动阅读规则：

**说明区垂直居中**。电脑端右侧、手机端下方的公式与文案作为一个整体，在所属说明区内上下居中。内容超过可用高度时安全回退到顶部起排，保留同一个滚动区及原有播放跟随／手动浏览，不能因居中导致首段不可到达。文字沿用各小节的水平对齐方式。

1. 使用播放器实际转动位置判断当前阶段，不另开定时器猜进度。拖动进度、步进、重播和点击公式后的高亮、滚动位置一致。
2. 阶段进入时，仅在当前内容不完整可见时滚动；内容已经可见就不移动。过高的阶段先对齐顶部，不强行居中。
3. 自动滚动只作用于说明区，不把整张页面和魔方一起拉走。
4. 用户触摸滑动、滚轮滚动、拖动滚动条或使用滚动键时，暂停自动跟随。播放器可继续播放，后续阶段不能抢回阅读位置。
5. 再次操作播放、步进、进度条、重播或点击教学步骤时，恢复跟随；仅重置魔方视角不恢复。不要几秒后自动恢复。
6. 切换教学案例或小节时重置跟随状态。尊重减少动态效果设置，使用即时滚动替代平滑滚动。

A 类说明区使用 `ReadingFit` 的 `pane` 模式。B 类阶段说明在左右和上下排列时均保留文档流，使用 `tutorial-follow-pane` 和 `useTeachingFollow`。

### C. 一个魔方 + 完整图文

典型画面：魔方配完整参考卡、状态关系图、动态流程图或转化路径。图文是有独立信息量的教学主体，不能当短字幕压缩。动态高亮只改变行为，不增加布局类型。

| 宽屏 | 窄屏 | 小手机 / 短屏 |
| --- | --- | --- |
| 魔方在左；右侧说明与参考卡分区，卡片位置稳定，当前公式段高亮 | 主魔方与控件固定在上，说明和参考卡放在下方同一个滚动区；卡片里的小魔方、名称、公式保持关联 | 下方整体允许滚动，优先保留当前讲解和对应公式；长公式按教学分组换行，不缩成难以辨认的小字 |

- **F2L 带流程图的公式教学**：公式教学的流程图缩到原尺寸的 **72% 以下** 才能放进参考区时，自动切换为 B 类阶段列表。视口增大后重新测量，空间足够时恢复 C 类。切换期间保留魔方与播放位置。
- 这类画面不能直接套用“单句说明垂直居中”，否则参考卡可能被挤出可用区域。
- 文案已经说明当前动作时，不在文案和卡片里重复堆放同一份公式。
- 如下方还有多阶段列表，按 B 类处理跟随；只有一张参考卡时，不凭播放进度无意义地滚动。

### D. 两个或多个同等重要的教学单元

典型画面：LBL 与 F2L 的同步还原对比。每个单元包含魔方及其标签、进度和补充说明，作为一组安排。同步比较优先同屏、等宽、相同魔方比例；不能为了放大一侧而隐藏另一侧。

| 宽屏 | 窄屏 | 小手机 / 短屏 |
| --- | --- | --- |
| 并排或按关系排列，统一魔方比例；说明和进度条有稳定位置 | 简单的两个小魔方可并排；每个魔方附带较多文案时改为上下排列，保持标签与魔方对应 | 优先保证关键贴纸、标签可辨认；不能把整组画面等比缩小成看不清的缩略图。普通教学上下排列后允许内容区滚动；连续比较保留两侧同屏，先压缩重复说明与进度的排版 |

- 时间线由多魔方切到单魔方时，不能造成进度条或翻页区跳动。
- 悬停放大不推动下方文案、进度条；触屏通过点击获得同等信息，不能依赖 hover 才能读到解释。

### E. 纯图文 / 案例列表

典型画面：概念介绍、公式记号、魔方结构、案例选择网格；没有持续播放的主魔方。

| 宽屏 | 窄屏 | 小手机 / 短屏 |
| --- | --- | --- |
| 使用完整正文宽度，按内容组织图文或网格；不保留空魔方栏 | 减少网格列数，图与对应说明靠近；多段正文左对齐，短图注可居中 | 保留字号，进一步减少列数；长内容在学习区滚动，末项仍可到达 |

纯阅读内容不启用播放跟随。不能因为它只有一个 `<p>` 就把整篇长说明按 A 类居中。

**图示对齐与手机竖屏适配。** 魔方图在所属图文单元内水平居中。手机端以扣除导航、翻页区和播放控件后的正文可用高度为准。空间够用时保留原间距与图示尺寸。只有高度不足时，才收紧留白并按需缩小图示，尽量一屏显示完整。内容仍放不下时，允许在学习区滚动到最后一项。

**桌面和紧凑横屏整体等比缩放**。需要整组同屏的 E 类图文使用 `ReadingFit`，按扣除导航、翻页和播放控件后的实际可用宽高缩放。紧凑横屏先收紧留白、调整图文排版，再等比缩放。低于 72% 时，恢复原字号并在学习区内滚动。章节索引和长公式列表使用可滚动的原字号网格，保证最后一项可读可操作。手机竖屏按表中的原生布局呈现。

静态图文概览与时间线中的纯图文镜头均归 E 类。视频概览逐镜头分类，公式轮播、交互教学和练习按各自内容分类。具体分支见[画面分类清单](./responsive-layout-inventory.md)。

### F. 练习 / 自由摆放

这类画面以用户亲自操作魔方为主。布局按实际可用空间决定，依次给可操作魔方、操作与底部导航、参考内容分配空间。

#### 章节内实操

二阶层先法的角块实操和二阶 FL「识别流程」共用 `LessonPane` 的 F 布局与 `InteractiveQuestionCopy`。步骤进度、标题、说明、操作和反馈按这个顺序放在同一说明区。提示和达标反馈复用预留位置，底部翻页留在教学区外。按钮按[教学按钮的位置](#教学按钮的位置)摆放。

| 场景 | 章节内实操排版 |
| --- | --- |
| 桌面 | 左侧魔方、右侧说明和操作。教学区至少宽 760、高 360 CSS px 且为横向时，魔方画布可扩至 480 CSS px，仍受可用空间限制 |
| 手机竖屏 | 魔方在上，说明和操作在下。常规魔方画布边长上限为 350 CSS px，并随教学区高度收缩。内容过长时只滚动说明区 |
| 短横屏与缩窗 | 横向教学区至少宽 440、高 120 CSS px 时左右并排。空间更紧时上下排列，优先缩减魔方画布与留白，目录和翻页入口保持可达 |

#### 独立练习页

LBL「练习本节」、F2L 公式练习和自由摆放按下表处理。

| 布局 | 页头与导航 | 操作魔方与参考内容 |
| --- | --- | --- |
| 桌面 | 保留练习标题和底部导航 | 左栏为可拖动魔方，右栏为参考和提示。主魔方最大宽度 **440 CSS px**，目标高度为视口高度的 **48%**，限制在 **280～460 CSS px**。先压缩留白和图示；桌面参考内容仍放不下时切换到紧凑手机布局，窗口增大后重新检查 |
| 手机竖屏 | 返回箭头和当前题名同排，左边位置、字号及间距参照主教程；有题号时放在右侧 | 魔方在上，重来与提示操作紧接魔方。剩余空间很少时正文只显示操作区，再宽裕时显示参考，空间充足时同时显示参考和详细步骤。可见的参考与步骤在操作区和底栏之间整组上下居中；空间不足时从顶部开始阅读，只滚动下方内容区 |
| 手机横屏 / 桌面空间不足 | 沿用单行页头，底部导航使用同教程的紧凑高度 | 左栏魔方用足可用高度，右栏把操作、参考和可见步骤作为一组上下居中，按钮水平居中；内容溢出只滚动右栏 |

- 手机练习底部导航按钮高 **44 CSS px**。LBL、F2L 的逐题练习竖屏底栏为 **57 CSS px**，短横屏为 **45 CSS px**。计算布局时计入浏览器工具栏占用后的可用视口和安全区域。重来按钮完整可点，翻页、展开参考和切换提示时，魔方与底栏保持原位。
- 独立的「转动提示」按钮直接开关魔方箭头。查看或收起参考面板保留箭头开关、已做动作和当前视角。详细步骤按剩余空间呈现。自主操作时只在步骤区内跟随当前动作，演示解法的多段公式按 B 类规则跟随。
- **LBL** 的参考是目标图和说明。短竖屏在魔方下保留「目标」入口，打开底部面板。竖屏高度足够时目标直接排在魔方下；横屏右栏默认显示目标。两种布局在空间足够内嵌完整提示框时，使用框内的开启和关闭入口，隐藏独立的「转动提示」按钮。题目目标、达标与复原判定见 [LBL 练习需求](./lbl/practice-requirements.md)。
- **F2L 公式练习** 以流程图作为参考。桌面显示完整分支和原有的「指定路线」交互。手机一次只显示一条直线路线，保留节点名称、魔方示意与当前进度。手机根据实际转动识别并切换路线，所有选路控件集中在桌面端。切换路线或旋转屏幕时保留魔方状态。内嵌和底部面板遵循 LBL 的参考区规则，空间充足再显示详细步骤。路线较长时只横向滚动路线自身。
- **F2L 自由摆放** 沿用操作魔方优先的规则，保留「演示复原」「重新摆放」「使用方法」及对应公式区。三步基态的播放演示依内容使用 B 类布局。

### G. 独立流程图

独立流程图使用一个二维浏览区域，同时承接横向、纵向和斜向拖动，不再由内层横滚、外层竖滚分别处理。顶部章节导航和底部翻页区保持固定；图中节点轻点仍可预览或跳转，拖动后不得误触。保留滚轮、键盘滚动与浏览器双指缩放。独立流程图按画布尺寸显示，通过平移查看完整内容。正文视口变小时保留节点的文字和点击区域，避免整图自动等比缩小。

## 5. 播放与文字的共同要求

- LBL 和 F2L 的魔方播放按钮组均使用无外框样式，省去椭圆框和外框内边距。
- 时间线演示复用 `VideoControls` / `VideoProgress`；普通魔方播放器保留各自的步进等控件。
- 暂停状态拖动进度后仍保持暂停；播放状态拖动后的恢复遵循播放器现有契约。到结尾不自行开始新一轮。
- “返回选择”“开始练习”、左右手切换等操作放在当前说明末尾，在说明区内水平居中。左右排版时以右侧说明区为准，上下排版时以下方说明区为准。释放未显示操作的占位时，已有内容的位置必须保持稳定。B 类手机端随说明滚动。
- 需要用户继续的引导动画，在同一次画面切换中显示最后一句和「继续」，并让进度条到达终点。结尾画面停留，回拖或重播时撤下结尾文字和按钮。分步观察没有独立进度条时，也在结论就绪时同步显示按钮。
- 字号使用既有教学档位，具体 LBL 字号规则见 [LBL AGENTS](./lbl/AGENTS.md)。不能仅为挤进小屏持续降低字号；优先调整布局和滚动。
- **教程文案尽量用短句，尽量不用句号。** 概览、字幕、魔方旁的短提示和公式步骤优先一条讲清一个要点。多个动作按执行顺序分行，每行末尾省略句号。F2L 师生对话正文保留正常标点。
- 中文、英文都要检查。公式可按教学分组换行，保存的原始公式和播放器输入不变。
- 放大文字后仍能阅读、操作；切换横竖屏不重置当前播放进度或教学步骤。

### 教学按钮的位置

| 用途 | 位置与样式 |
| --- | --- |
| 继续 | 在当前步骤说明下方的操作区，文案统一为「继续」。设为主按钮并排在操作区首位。F 类章节内实操沿用说明的起始边对齐，其余类型沿用各自说明区的对齐方式 |
| 再练一次 | 与「继续」共用操作区，使用次按钮。两者同屏时放在「继续」之后，窄屏换行时保持顺序 |
| 提示 | 在当前步骤标题右侧的提示区，复用 `InteractiveQuestionHelpButton` |
| 作为提示的视频 | 与「提示」共用标题右侧的位置，使用带播放图标的 `InteractiveQuestionHelpButton`，按钮文案说明内容，例如「摆位示范」。该步骤答对后仍可在原处回看。进入下一步时，显示适用于该步的提示视频 |
| 播放、暂停、重播、进度条 | 在播放器的控件区。时间线视频的控件放在魔方和讲解组成的舞台下方 |
| 上一节、下一节 | 在固定的章节翻页区，沿用共用导航 |

## 7. 最小验收矩阵

### 必须适配的终端

按维护者要求（2026-11-17），LBL（层先法）和 F2L 两份 Web 教程均须覆盖以下终端：

| 终端 | 验收场景 |
| --- | --- |
| 电脑浏览器 | 正常窗口及缩窗，见下文桌面缩窗验收 |
| iPhone 18 Pro Max | Safari 竖屏和横屏 |
| iPhone Duo | Safari 折叠外屏、展开内屏，以及展开和折叠时的布局与播放状态 |

两台 iPhone 按实际 Safari 可用视口验收。记录时分别标注真机、模拟器或通用视口的结果，尚无真机证据的终端标为未验收。设备名称及屏幕形态见 [Apple 机型对比](https://www.apple.com/iphone/compare/)。

### 通用视口检查

在必验终端之外，可顺手抽查少见的视口和窗口大小，例如超窄、超矮、宽高比例特殊的窗口。抽查重点是教学内容是否被裁切、控件是否仍可操作。以下尺寸用于覆盖布局边界，不作为任何特定手机型号的规格声明。

| 场景 | CSS 视口示例 |
| --- | --- |
| 小手机 | 320×568、375×667 |
| 常见手机 | 390×844、440×956 |
| 横屏短视口 | 844×390 |
| 断点两侧 | 744、760、761、900px 宽，核对 A、B、C 排列方向、侧栏与正文可读性 |
| F2L 矮窗口 | 1000×600、1000×601，核对师生对话的显隐和镜头教学气泡 |
| 平板 / 折叠屏展开 / 分屏 | 768×1024、1024×768；拖动调整宽度 |
| 电脑 | 1280×720、1440×900 |

针对本次修改涉及的布局，覆盖其实际调用页面和阶段，检查：

- 页面无意外横向滚动；章节条、说明区、流程图的局部滚动各自正常。
- 单句居中且可换行；多段说明不被误居中或截断；公式和最后一段可读。
- 播放、暂停、跳转、结尾、重播对应的内容和滚动位置正确。
- 用户手动阅读后不会被后续播放阶段拉回，再操作播放器可恢复跟随。
- 底部导航不遮挡正文；切换长短文案时魔方、控件和翻页区不跳动。
- 对同一步骤中出现或消失的内容，在固定视口下触发操作并比较已有元素的位置和大小。二阶 LBL 的[布局检查脚本](../../../scripts/check-tutorial-layout.mjs)覆盖错答气泡、试转反馈及白绿橙角转体成功提示，检查魔方、正文、进度和原有按钮。桌面、手机横竖屏和紧凑窗口分别检查。
- 新接入共用布局的章节，用相同的 CSS 视口与现有同类小节对照，检查画布尺寸、说明与操作顺序、小节导航、滚动区域和底栏。手机横竖屏切换时复核当前题目和魔方状态。
- 中英文、文字放大、键盘焦点、触屏操作和减少动态效果符合本次修改范围。

仅修改文档时运行文档检查；修改布局时按受影响页面验证，不为本次任务启动无关平台构建。

## 8. 桌面缩窗验收与待确认项

普通桌面窗口的验收目标是让核心教学内容一屏可读、可操作。缩窗时先扣除页头、章节导航、翻页与播放控件，再按实际可用宽高分配学习区。分别缩宽、缩高和同时缩小，检查侧栏展开和折叠、中英文及文字放大。测量各滚动容器的 `scrollHeight` 与 `clientHeight`，核对当前教学内容是否完整可读。同一正文只设一个纵向滚动容器，二维流程图使用独立画布。

待确认：

- 普通桌面窗口的最小验收尺寸。候选为 1000×600、900×500、1280×500 CSS px，并用 1440×900 对照。
- 紧凑 B 类是否允许逐个浏览完整阶段，及手动浏览与播放跟随的衔接。
- C／E 类在空间不足时是否提供独立阅读入口，及独立流程图的滚动指示形式。
