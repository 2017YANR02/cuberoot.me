# LBL

- 修改“练习本节”前读取[练习需求与验收对照](./practice-requirements.md)；其中历史差异与待确认项不视为自动修改其他会话内容的授权。

- LBL 位于 tutorial/lbl；旧版已删除，原存档地址返回 404。全站公共播放器、绘图器和基础组件仍复用。

- 普通公式演示和完整演示在进度条标记内部的教学分段边界；保留拖动、步进和播放控制。
- 公式说明的步骤以细线分隔，不显示序号；保留有序列表语义。
- 动作演示默认自动播放，等待播放器就绪并显示后约 1 秒再开始，避免漏看第一转；纯视角展示保持慢速环绕。
- 演示默认略露出 R 面。自动播放以 L 面起手的公式前，轻转视角至略露出 L 面，不加说明文案。
- 有播放器的小节：演示区主要放播放器，说明区主要放公式、口诀与解释；大屏左右并排，小屏上下排列。
- `.lbl-content` 内的教学内容字号只用 `lbl.css` 定义的四档：`--lbl-text-small`（`1rem`，序号、口诀、备注）、`--lbl-text-body`（`1.25rem`，正文、图注、概览步骤）、`--lbl-text-emphasis`（`1.5rem`，重点句、步骤标题、公式字母）、`--lbl-text-display`（`1.75rem`，单独展示的转动记号）。相似内容用同一档，响应式布局也不另设字号。共享播放器控件沿用自身样式。
- 无播放器的小节不保留空演示栏；图文区同时适配大小屏。
- 翻页区固定在学习区底部，章节切换不随内容高度移动；长内容在上方独立滚动。
- 页面最大宽度沿用旧 LBL 教学页的 1180px，大屏放大内容时不得另行扩大页面宽度。
