# LBL「练习本节」需求与验收对照

整理日期：2026-11-09。范围：LBL 教程的练习视图，不含主教程演示区。

本文记录本会话已确认的需求，并对照整理时的本地源码。其他会话正在修改练习内容，验收应以当前文件为准；本文不表示代码已提交、部署或完成浏览器实测。后续需求变更应更新本文件，不另维护互相矛盾的清单。

## 1. 入口、URL 与练习切换

| 项目 | 要求 |
| --- | --- |
| 主教程 | `/tutorial/lbl`，保留主教程章导航 |
| 练习视图 | `/tutorial/lbl?view=practice`，练习上方不放章导航 |
| 分享当前题 | `?view=practice&step=corners&case=2`；`step` 为章节 ID，`case` 为本章展示顺序中的题号，从 1 开始 |
| 白棱归位额外题 | 使用 `step=cross&case=white-edge` |
| URL 状态 | 进入、退出练习写入浏览器历史；练习内换题使用 replace，不让后退逐题倒退 |
| 恢复 | 刷新、直接打开分享链接应恢复对应章节与题目；无效参数回到有效默认题 |
| 标题 | 统一为「章标题：小节标题」，例如「底层角块：白朝左」 |
| 进度 | 右上角显示本章当前题号 / 本章题目数 |
| 底部栏 | 从左至右：上一个练习靠左、回看本节教程居中、下一个练习靠右 |
| 对称按钮 | 上一个 / 下一个使用同一套外观，包括背景、边框、圆角、尺寸及禁用态 |
| 跨章 | 本章末题的下一题是下一有效章首题；本章首题的上一题是上一有效章末题；跳过没有练习的章节 |
| 全局边界 | 全局首题的上一个按钮灰色且禁用；全局末题的下一个按钮灰色且禁用，不首尾循环 |
| 空格 | 与点击下一个练习完全同义，包括跨章；全局末题不再切换。编辑输入、组合输入及对话框不应被快捷键打断 |
| 左右方向键 | 左键与上一个练习按钮一致，右键与下一个练习按钮一致，支持跨章；全局首尾不循环。沿用空格的输入区域、组合输入与对话框保护，忽略长按重复触发及 Ctrl / Alt / Meta 组合键 |

历史变更：最初要求空格在本章首尾循环，后来已明确改成与“下一个练习”一致；不要恢复旧行为。

## 2. 布局与基础操作

- 用户直接拖 AlgPlayer 转层；字母操作、文字操作及对应动作按钮暂时注释保留，不显示。
- 拖色块转层，拖空白或使用播放器已有方式调整视角。
- 所有练习达标后禁止继续转层，但仍允许调整视角。
- 达标时必须保持用户完成后的魔方状态及当前视角，不重置、不重新挂载播放器。
- 重来、换题后恢复转层能力。
- 页面使用固定的视口高度；标题区、练习区及底栏位置稳定，长内容内部滚动。切题、跨章不因内容高度不同导致整页跳动。
- 右侧上方目标说明与完成示意图左右排列：图在左、文案在右，垂直居中，整体向下留出 24px 间距；目标行固定高度，长文案内部滚动。目标图已从 112 调整为 140。
- 不显示“黄心朝上，绿心朝前。”这行重复文案。
- 提示区应预留空间，展开、收起不能把目标说明等内容向上顶；保持紧凑，不用隐藏的长说明和大块错误列表占位撑高提示框，错误文案覆盖在字幕区，不额外占行。
- 目标图保持显示，提示框放在右侧目标文案与示意图下方的独立行，不遮挡魔方；收起提示仍预留空间。实际大小屏布局仍需目检。

## 3. 目标文案

目标描述以简短的完成结果为主，不统一使用“转动魔方，让重点色块与目标图一致”。只在必要时补充必须保留的成果及允许的变化。

| 练习 | 目标表达 |
| --- | --- |
| 做小花 | 完成小花。 |
| 白朝左、白朝右、白朝上 | 完成底层。 |
| 角块在底层 | 目标角块到顶层；保留底十字和其他已复原的底层角块 |
| 中层棱取出 | 目标中棱到顶层；保留完整底层；顶层位置和朝向不限 |
| 顶面十字：点 | 保留下两层，先变成横线，而非直接要求完成十字 |
| 二灰、四灰 | 变成左小鱼或右小鱼，保持下两层复原 |
| 无墙：先造墙 | 保持下两层复原、顶面全黄，让顶层侧面出现一面墙 |

用户可见文字同时维护简体中文与英文，复用站点 i18n。文案不得与实际完成条件相矛盾。

## 4. 完成状态与目标图

### 通用原则

- 检查魔方的真实状态，而不是用户是否逐字执行指定公式。
- 目标图是一种参考结果。已经明确允许的等价结果不能因为位置、朝向或左右手不同而被拒绝。
- 展示遮罩、紫色标记不能替代用于保存、运算和校验的原始状态。
- 每道题从初始状态执行新提示区实际展示的全部公式，应能达到该题完成态。公式、初始态或判定改变后，应核对受影响的题。
- 不要用改变初始状态、自动转动或放宽其他阶段的保护条件来掩盖判定问题。

### 逐类要求

| 范围 | 展示与完成条件 |
| --- | --- |
| 角块在底层 | 目标图中的目标角块为紫色；指定物理角块进入顶层即可，位置、朝向不限；底十字及其他原先已复原的底角仍须复原。左右手镜像取出都应接受 |
| 中层：原地翻转、放错 | 指定物理中棱进入顶层，位置、朝向不限；完整底层不受破坏；其他中棱的显示按当前遮罩约定 |
| 顶面十字：横线、三点半、点 | 初始状态和目标图的下两层取消灰化；完成时必须检查下两层没有被破坏。点这一题的阶段终点是横线 |
| 顶面朝向：全部练习 | 下两层取消灰化，且必须保持复原 |
| 顶面朝向：二灰、四灰 | 左小鱼、右小鱼均成功，顶层摆放位置不限；保持黄色十字及已复原的下两层 |
| 无墙：先造墙 | 保留下两层及顶面朝向；造出一面墙即可，后续对色在左、在右均可。当前源码已有专门墙状态判定 |

### 做小花的历史差异：待确认

本会话曾明确要求“一楼：压到二楼”“地下室：上上”只关注一条目标白棱，其他三条灰化，初始图、目标图与判定同步。

但整理时的 `daisy-practice.ts` 和 `Practice.tsx` 已采用完成整朵小花的统一目标，并调整了提示公式与练习初始态；这与上述单棱要求存在差异。不要把两种方案同时视为现行标准，也不要仅凭本文件擅自回退其他会话修改；需确认最终采用单棱练习还是整朵小花练习。

## 5. 提示（统一入口）

- 删除旧的“给我提示 / 收起提示”按钮，也不保留独立“逐步提示”按钮。
- 后续需求中的“提示”均指右侧下方的新提示区，唯一入口文案为“点击此处获取提示”。
- 展开后可通过提示区下方居中的“关闭提示”（灯泡加小叉图标）收起，并停止动作箭头；恢复原入口，保留提示区占位及当前魔方状态。关闭入口与开启入口使用相同的文字字号和颜色、强调色图标，不显示按钮底框或悬停底色，保留键盘操作。“重来”按钮保留文字，重置图标放在文字左侧。
- 下文“逐步提示”用于描述新提示的动态能力，不表示另有一个旧入口。
- 所有可进入练习视图的题统一启用三行动态提示、动作箭头、错误退回与上限、关闭提示及等价达标判定，包括白棱归位额外题；认识结构章没有练习入口。

### 逐步提示：所有练习

本题完整目标判定优先，包含所有受保护块。自由练习达到目标即可成功；开启提示时，如果当前偏离教程路径但已达到目标，也认可成功，即使错误栈曾达到 10 步。成功后提示区显示“已完成”，停止错误提示及箭头并锁住转层，保留魔方状态和视角操作。如果当前仍处于教程公式路径，则保留完整教学动作，例如“去右”提前复原仍需做最后一个 U。路径及公式完成以当前物理状态核对，不依据历史最高进度；曾经拧错但已退回教程路径的用户仍按教程继续。

移除独立的“逐步提示”按钮，右侧下方提示框始终可见，初始文案为“点击此处获取提示”；点击后所有练习统一开启逐步提示，关闭后恢复相同入口。取消原先仅中层“去右”的试用限制及旧静态提示分支。

提示区采用紧凑的中性底色与细边框，入口为灯泡图标与原有文案。公式字母突出、口诀次一级、分段标签使用轻底色；当前动作以下划线标记，已完成部分使用统一强调色。错误提醒以毛玻璃浮层覆盖三行字幕，不额外占行；提醒文字使用站点惯用棕色（--accent）、1.5rem、700 字重，模糊复用更强的 --glass-menu-filter（18px，遵循减少透明效果设置）；下方居中的关闭提示按钮保持可操作，初始占位与展开后的动态字幕使用同一布局，避免展开时高度变化。颜色复用站点主题 token。

展开区按用户示意图分三行：

1. 完整公式字母。
2. 与动作对应的中文口诀 / 英文提示。
3. 左公式、调整、右公式等分段标签，横向覆盖对应的公式片段。

提示区横向滚动跟随当前待做动作居中，两端按实际滚动范围钳制，不添加空白来强行居中；开始时保持最左侧。进度变化时平滑滚动，减少动态效果设置下立即定位；拧错期间保持位置，恢复后继续跟随。

已完成动作的字母和口诀逐步变色；第三行的分段标签区分未开始、进行中和已完成：进行中使用清晰文字及按已完成动作比例增长的底部细进度线，整段完成后使用强调色文字和浅强调色底。拧错时三行文字统一暂时变灰（包含已完成部分），退回正确状态后恢复进度颜色。偏离公式不继续推进；回到正确状态继续。重来或换题清零。等价记号、撤销抵消动作、将半转拆为两个四分之一转应合理处理。

### 视角拖动与 x / y / z

- 拖视角只改变观察角度，不提交公式，也不应被直接记成一次 y。
- 用户不方便输入转体，因此逐步提示不能一直等待公式里的 x、y、z。
- 当前方案：比较对齐中心后的物理状态，将后续转层动作换算到播放器的真实坐标；遇到转体时提示下一次实际转层。
- 仅拖视角不推进字幕；后续正确转层确认进度时，再越过前面的转体记号。
- 实际执行的 x / y / z 仍应兼容。
- 本方案不检测摄像机是否正好转了 90°，也不自动旋转用户视角；不要将其描述成已经识别用户的拖视角角度。

### 拧错后的退回栈

- 偏离提示路径后，提示区仅显示“有转动错误，按箭头恢复”，不显示回退动作字母或步骤列表；内部仍按后进先出顺序处理。
- 例：正确前缀后误拧 F、D，箭头先引导退 D′，再引导退 F′，界面不显示这些字母。
- 箭头指示当前应退的一步；退完一项便从内部栈中移除，恢复正确状态后撤去错误提示，继续原公式。
- 撤销动作应消掉已有错误，不能把撤销动作自身当成新错误，造成反复要求来回拧。
- 退回栈长度达到 10 时，停止显示回退步骤及回退箭头，显示可点击的“错误步骤较多，点击重来”；点击调用与左侧“重来”相同的操作，支持键盘触发。本题重来或换题后才恢复回退提示；但之后若通过其他方法达到完整目标，仍应正常成功，不能被错误上限阻止。
- R2 分两次 R 完成时，第一次 R 是未完成的半转，不能误报为拧错。
- 不自动重置、自动撤销或偷偷改动用户魔方。退回栈属于提示功能，不改变允许等价解法的目标判定。

### 魔方表面的动态箭头

- 正常逐步提示：每格一个固定箭头，绿色与纯白色沿提示方向依次交替，形成视觉滚动；不移动箭头、不每格放两个箭头。
- 退回栈非空：固定箭头改为红色与纯白色依次交替，方向对应当前需要撤销的动作。
- 退回正确状态后恢复绿色与纯白色；仅改变固定箭头的颜色，不移动箭头图案、不自动转动魔方。
- 用户开始拖层时立即隐藏箭头并停止换色，转层动画结束后显示更新后的箭头；单独拖动视角不隐藏箭头。关闭提示、换题或达标后清理箭头及动画资源。
- 系统开启减少动态效果时保留双色静态箭头。颜色每 750ms 交替一次（较初版 180ms 放慢）；视觉效果仍需浏览器目检。

## 6. 验收清单与实现入口

### 交互验收（需浏览器实际核对）

- [ ] 直接打开分享 URL、刷新、前进 / 后退，题目与 URL 一致。
- [ ] 跨章上一题 / 下一题以及空格行为一致，全局首尾按钮灰色禁用。
- [ ] 大小屏切题、跨章、提示展开收起、错误栈增减时，标题、目标说明及底栏不跳动；长内容可达。
- [ ] 达标后保留当前状态和视角，转层锁住，视角仍能转。
- [ ] 角块左右手取出均可过关，破坏受保护块不能过关。
- [ ] 二灰 / 四灰变成左右两种小鱼都通过，破坏下两层不能通过。
- [ ] 所有练习的逐步提示均为三行，可开启及关闭，长公式在提示区内部横向滚动；每步列宽按字母、口诀与标签的完整内容撑开，三行均不换行，不压缩重叠。
- [ ] 不输入 y、只拖视角并按换算后的正确层继续拧，提示与高亮可继续。
- [ ] 连错多步、逐步退回、退回途中再错、半转分两次输入均合理。
- [ ] 做小花单棱 / 整朵小花的差异已明确最终选择。

## 7. 仅讨论、尚未承诺实现

曾讨论根据用户任意操作后的真实状态，动态生成后续教学提示，并在“小目标独立练习”与“连续完成整段还原”间选择教学边界。目前没有确认完整的任意状态辅导系统；已有逐步提示是固定公式路径上的状态匹配和错误退回，不代表已具备该能力。
