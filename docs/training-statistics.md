# 训练统计

## 复用与覆盖

| 入口 | 记录方式 |
| --- | --- |
| `/predict` | 首次答错记错；全部目标答对且未播放/查看过程才记对；回看不重复计数 |
| `/color-test/relations`、`/color-test/positions` | 每题第一次提交；侧面顺序按顶色分组 |
| `/alg/3x3/cross` | Cross / XCross / XXCross / XXXCross 按阶段和模式分组；猜步数、智能魔方自动判定，最优解模式自评 |
| `/notation` 的训练组件 | 按拼图和模式记录首次作答，改正错误不覆盖首次结果 |
| `/alg/skewb-trainer` | 各模式停表记录次数与用时；未自动判定对错，不计入正确率 |
| `/alg/sq1/algorithm-trainer`、`/alg/sq1/train` | 公式/形状组合练习自评；新打乱和查看答案不会计数 |
| SQ1 奇偶练习 | 每题首次作答；重复答错或改对不重复计数 |
| `/alg/3bld/memo` | 每轮提交回想结果，全部编码（含多输入编码）正确才算正确；用时为记忆加回想，不含干扰任务 |
| 3BLD 打乱练习列表 | 共用 `ScrambleOutput`，逐条自评，不把生成的打乱条数当作完成数 |
| `/alg/3bld/timer` | 停表记录次数与用时；未自动判定对错 |
| `/alg/roux` | 各训练模式自评；追踪训练按模式、步数分组；分析器不记录 |
| 旧版十字/拓展十字/配对/EO、`/algTrainer`、`/alg-trainers` | `IframePage` 包装层提供开始记录、自评和取消；未改上游源码；取消不计数 |
| 公式计时与复习、识别训练、Stroop、知识问答、计时器、赛前训练 | 继续使用已有成绩、复习进度、识别结果、历史或最好成绩实现 |

## 单一实现

新增训练统计面板统一放在训练页面末尾；答题、自评和计时操作保留在训练操作区。

- `lib/training-stats.ts` 从原十字统计提取，继续使用 `cuberoot-timer.stage-training.stats.v1` 及原十字分组键，无迁移覆盖；旧累计值保留，用时从接入后开始采集。
- `hooks/useTrainingStats.ts` 使用 `useSyncExternalStore` 固定服务端首屏，支持同页更新、跨标签页通知；写入共用 `persistItem` 的配额恢复逻辑。
- `components/TrainingStatsPanel.tsx` 共用次数、对错、正确率、平均/最快用时、最近 50 条记录与分组重置确认；累计值不受最近记录上限影响。
- 自动判题、计时和自评分别接入已有的作答/停表事件；不根据页面访问或生成题目计数。页面的题目生命周期负责防重复，共用记录层另按事件 ID 去重。
- 没有判定的计时结果不进入正确率分母；没有用时的旧记录、逐条打乱自评不进入平均用时分母。
- 自评用时从题目出现计到评分，含观察和实际操作；智能魔方从首个还原动作计时。错误题用时截止首次错误提交。
- 新增统计仅存本浏览器，不伪装成账号云同步。存储失败时本次访问仍可记录，并显示未能保存提示。现有教学任务证据上报保持独立。

## 验证

`tests/training-stats.test.ts` 覆盖旧数据兼容、重复作答、无判定/无用时口径、最近记录上限、分组重置、跨标签更新、存储失败和损坏数据。训练页面还需通过实际浏览器检查答题、回看、刷新和手机布局；智能魔方接入需另做真机验收。
