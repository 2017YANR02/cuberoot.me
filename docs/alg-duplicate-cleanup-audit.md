## 判定与输入约束

同一 case、同一朝向的公式先对齐公共打乱，再忽略分组圆括号、全角圆括号和排版空白比较。大小写、撇号（包括 `2'`）、转动顺序、层数、交换子和指法记号仍有意义；重复组的指数边界以及箭头旁表示手别的空格也保留意义。只比较转动终态相同不会被当成重复。

单一规则在 `core/packages/shared/src/alg_notation.ts` 的 `duplicateAlgKey` / `findDuplicateAlgs`。社区新增、编辑及管理员编辑器会提示重复；补齐收尾 AUF 后再次检查。社区输入同时比较标准条目、原文、当前显示角度和其他投稿；编辑自身时排除自身 ID。

API 的标准公式新增/编辑及社区新增/编辑使用相同规则，重复返回 JSON `duplicate_alg` / HTTP 409。写入在事务内按公式集串行化，防止两次并发提交同时通过查重。管理员将投稿移动到另一个 case 时检查目标 case；标准写入也检查已有投稿。

管理员校验报告及社区已有重复行显示重复提示。CMLL 合并 OH CMLL 时，5 条对齐后重复的派生行合并标签，原文仍在 OH CMLL 数据源。`U2` 和 `U2'` 不再被该合并器错误地当作同一写法。
