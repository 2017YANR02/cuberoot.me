# Space Blender 迁移跟踪

2026-09-08：本地迁移与基础验收完成；未 push、未上传资产、未启用生产环境。工作方式已切换为后台 Blender Python 和无头浏览器，不激活用户窗口、不发送鼠标键盘输入。所有批处理隐藏窗口、低优先级、最多 14 线程，预览使用 CPU。

## 交付与编辑边界

- D 盘仓库 `design/space/scenes/` 有 25 份可编辑 `.blend`：8 种风格各 3 个环境，加上海城市工程；源文件约 1.21 GB，不含 `.blend1` 备份。
- `core/packages/client/public/assets/space/blender-v1/` 有 25 个 GLB；首次迁移合计 1,481,293,792 字节，金茂精修后合计 1,486,872,988 字节；共享纹理约 34.5 MB。清单记录大小与 SHA-256。
- 本地开发加载 Blender 静态产物，魔方转动、天气、水面、交通、时间和相机仍由 Three.js 实时运行。日常导出读取已保存的 `.blend`，不会重新抓取旧程序或覆盖源工程。
- 打包器校验 GLB 并去重纹理，写入临时文件后原子替换正式产物。此前磁盘满导致的 ENOSPC 已解除，全量复验已重新完成；按用户要求不增加磁盘余量门槛。
- 网页中英文“来源与致谢”已列出 Blender / Khronos glTF 插件和迁移用途；统一维护 `credits_data.json`。操作步骤、文件位置、场景属性、备份与发布条件见[编辑说明](../design/space/README.md)。

## 预览相机与三轮卫生间审图

24 套住宅/公司源工程的预览相机已修正，上海城市工程保持原相机。住宅补充庭院、车库、影音室和健身房视角；公司只保留适用的室内视角。网页与 Blender 采用同一份室内相机坐标，轴向转换由导入脚本完成。

意大利卫生间后台 Cycles 预览进行了三轮：第一轮发现旧相机指向楼梯，改用网页实际机位；第二轮发现室内过暗，把已导入的面光源元数据转换为临时 Blender 灯光；第三轮已能看清浴缸、淋浴区、双台盆和马桶。结果为 `italian-original-bathroom-preview.png`。功率换算与网页专用反射不等价，该图用于检查编辑工程，不代表网页或电影级验收通过。

修正仅更新仍匹配旧导入位置/朝向的预览相机，保留手工修改过的机位，并生成 `.blend1`。没有操纵或保存用户正在打开的 Blender 窗口。若窗口内容比磁盘文件旧且有未保存修改，应先另存副本再比较，不能直接重新加载或覆盖任何一份。
