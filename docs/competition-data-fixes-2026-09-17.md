# 比赛名称、纪录快讯和排名修复

## 根因及处理

- 中文名称：线上静态名称文件与 API 兜底均返回空映射。cubing.com 改为 Nuxt 数据后，旧 HTML 表格解析器没有提取到比赛，生成器又发布了空对象。在线兜底和离线生成器现在共用解析器，优先读明确的 WCA ID；未知页面或空刷新报错，保留历史译名。
- 纪录快讯：比赛详情只使用人工快讯和自动新人纪录。现复用全场纪录汇总，为所有比赛自动生成有效 WR、FWR、洲际和国家纪录快讯，保留已有报道及其当时名次，去除重复。
- 排名：线上数据库已包含沈懿 4.24，但世界／国家排名仍使用入库前的 24 小时缓存。现监测导入事务的已有版本标记，同时失效排名和去重缓存；HTTP、浏览器内存缓存缩短到一分钟。另将近期比赛的普通个人成绩纳入候选，避免只收地区纪录而漏掉 PR；入库后按选手去重，不重复计数。

## 验证

- 实际读取全部 13 页上游列表，791 场比赛全部匹配，生成 871 条名称映射；原有译名无删除。
- 实库确认快于 4.27 的三名选手最佳成绩为 3.51、3.67、4.24，因此该值排名是 WR4；确认导入版本标记存在。
- 回归覆盖：上游新结构、空数据禁止覆盖、历史译名保留、任意新比赛自动快讯、旧报道去重、PR 入库前后排名均为 WR4、入库触发三种地区排名刷新、浏览器缓存到期刷新。
- 本地浏览器确认广州详情出现 4.27 FWR 快讯，390px 窄屏快讯宽 351px。页面原有成绩表存在横向溢出，未将其计作本任务新增快讯的通过证据。
- Client、API、统计任务类型检查在本次改动后通过；后续 API 检查被并行 MCP 工作的类型错误阻塞，未修改该任务文件。
- 当前交付为本地代码和生成数据，未发布，线上仍需部署后复验。
