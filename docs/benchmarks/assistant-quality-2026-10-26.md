## 已修复

1. **三个规则摘要来源，中英文同步。** 对照 [WCA 完整规则](https://www.worldcubeassociation.org/regulations/full/)及本站中英条款：多盲 9f12c 是净分负数或只成功一块，不是所有零分都 DNF；FMC E2a1 只允许提前填写身份信息，打乱纸须写另一面，保留无获利时代表例外；速拧 A3d/A4b1 区分启动前放垫子与启动后拿起还原，不能压在计时器上。
2. **动态页面正文读取队列。** 旧代码只从固定目录创建 HTML 读取占位；索引里只有标题、链接的动态页面即使经导航找到，也没有进入队列。现在从通过 schema 验证的公开索引中解析选中的同语言页面，复用已有时限、体积限制和固定来源读取器。仅有模型编写的 `page:/...` 不足以触发读取；开发文档过滤和私有路径边界保持。
3. **评测来源记录。** 真实评测记录执行 bundle 的 SHA-256、实际题集及非秘密配置指纹。未打包的诊断不声明完整代码身份。汇总缺少指纹或指纹不一致时，不输出“仅检索策略改变”的配对结论；旧记录仍可单独分析，不能补造身份。

## 测试输入和边界

语料来自已有冻结公开快照，保留前一阶段计时器公共帮助覆盖层，替换本次本地渲染的六个中英文规则页面。另抓取共轭中英文 HTML 做可读性检查，但**没有**将其正文灌入测试索引：共轭仍是导航占位，真实问答必须走按需读取。不是全站重新构建，也未运行 Next build。

本地共轭页面抽取正文为中文 2,247 / 英文 4,478 字符；API 正文读取器也能提取。只能证明这两项有正文，不能据此宣称其余 126 项均已验证。

使用现有 `deepseek-flash` 配置、真实 API handler、真实账号校验和只读公开工具，顺序运行。题集是既有 G03、S03、N01、D06 加 [5 道开发边界题](assistant-quality-cases.json)。原 20 道保留题没有运行。首轮最长 360 秒，修复后复查最长 90 秒，诊断 Node 堆限制 768 MiB。首轮记录峰值 RSS 400 MiB，复查 394 MiB；这些是远程进程数据，不是本地 swap 保证。

线上 PG 索引代际与此覆盖层不同，遥测明确记录 `index_mismatch → local_lexical`，没有本轮 embedding 或 rerank 调用。因此这轮能验证来源修正、词法回退、真实模型和按需页面读取，**不能验证新向量索引质量或重排收益**。动态正文、公开数据库和供应商缓存没有冻结；不把这组耗时作为 SLO。
