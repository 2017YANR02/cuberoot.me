# 聊天助手：对话连续性、导航与计算结果

本轮从截图中的长尾零、表格换行和周末日期错误扩展到助手回答质量。维护者已明确授权真实模型评测、提交与部署。首轮提交 `1953ee019f` 已发布 API；本文保留隔离诊断、首次公网中断和稳定后的七题结果。七题虽全部 HTTP 200，F1 仍答错对象；后续行号修复需要以新提交重新发布验收，不能由授权或本地代码推定完成。

日期按维护者时区 America/Los_Angeles 记录为 2026-11-03；诊断日志的 UTC 时间为 2026-11-04。

## 确定性缺陷与实现

- **计算结论丢失**：已通过分析复核的模型回答仍被 `finish()` 的工具通用摘要覆盖。现在保留已复核回答中的结论、范围和假设；空回答才回退摘要。固定工具未经复核的统计摘要和错误/未完成分析保护仍保留。
- **下一轮看不到上一轮表格**：历史原来只有正文，用户看到的表格行序、姓名、成绩与链接未发送给下一轮。现在复用答案导出器携带这些已展示内容，限制每条历史长度，明确标记截断。历史用于解析指代，不作为本轮事实证据。
- **追问范围丢失**：有历史时不再直接走终身参赛国家/总数快捷回答。真实诊断又暴露了模型主动调用终身工具的问题，因此继续加入参赛范围上下文与工具调用校验。用户可以明确切换范围；短追问不自动清空年份和项目。
- **导航把指南当成练习入口**：公开目录将 `/recognize/pll` 命名为“观察”，而子指南有“PLL 识别指南”完整标题。导航复用真实父子目录关系补充搜索别名，区分入口与指南；明确找单一入口时只返回匹配目标，不追加相关训练或原始 URL 路径。
- **辅助来源失败丢掉已有回答**：已有独立可用证据时，部分暂时读取失败可返回已支持的部分与缺口，同一失败调用不再重复读网络；用户取消和访问验证失败保留原停止边界。
- **截图问题**：分析输出按数据库实际 numeric 类型去冗余尾零，不经 JavaScript Number 丢精度；手机表格避免拆开 ID/成绩；“上周末”解析完整短语并限定周六、周日。分析指引要求选手/赛事名称、决赛和冠军口径。
- **赛程条数不等于全量或冠军数**：比赛工具区分匹配总数、返回行数和截断状态；赛程不能支持谁夺冠，冠军需查询正式决赛结果。
- **冠军查询扫描历史结果**：只读执行计划显示决赛第一名查询扫描历史成绩表后再关联比赛日期。`0310_wca_final_winners_index.sql` 新增 `(event_id, comp_id)` 部分索引，只收录 `pos=1` 且轮次为 `f/c` 的结果。本地 PostgreSQL 13 已验证重复执行幂等；迁移保留 5 秒锁等待、3 分钟执行上限和 32 MiB 维护内存。生产性能收益必须在部署后验证，不能从本地成功推断。

以上包含程序约束与模型指令。程序测试通过不代表自由文本语义始终正确，后续实测保留了尚未满足验收的回答。
