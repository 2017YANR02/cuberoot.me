# 双底 ZBLL

训练入口：`/zh/alg/3x3/zbll/run`（英文 `/alg/3x3/zbll/run`），训练设置中的「双底」。

## 题库口径

472 个情况的有序配对，共 222,784 组，包含相同情况的上下配对。
每组在顶底各选一个固定、可复现的随机 pre/post AUF，相位随机种子为 20261009。
这是每个情况组合一个代表状态，并非全部相位组合的穷举。
若顶底各展开 4×4 个 pre/post AUF，未经对称去重共有 472²×16² = 57,032,704 个组合。
中层保持还原，顶底分别为 ZBLL。解完顶层后 x2 翻转继续练另一层。

每组把两层组合成完整状态，再用现有原生 nissy-core H48 h10 求全局最短 HTM。
浏览器不拼接两条单层最优打乱，也不追加会改变最优性保证的 AUF。
生成端将每条解逆序为打乱，逐条比对完整棱、角排列和方向后才导出。

## 计算、续算与内存

在 `core/` 运行：

```sh
pnpm --filter @cuberoot/alg-build double-zbll
pnpm --filter @cuberoot/client double-zbll:install
```

第一条完成全部计算并导出 `.tmp/double-zbll-v1/export/`；第二条由前端所属的安装器校验哈希并安装公共资产。

读取已有 `solver/tables/h48-nissy-core/h48h10.dat`（30,336,314,216 bytes），不建表。
线程数采用机器可用并行度。原生求解器只读映射表，浏览器不用这张大表。

工作目录 `.tmp/double-zbll-v1/`：

- `source.json`：冻结的公共公式库；`identity.txt` 校验情况顺序、规范状态与种子。
- `corpus.csv`：固定的全部输入状态。
- `solutions.csv`：逐条追加的最优解，重启按 ID 跳过已完成项；每 100 条进度刷新时同步落盘。
- `owner.pid`：防止两个任务重复计算。
- `progress.json`：状态、已完成数量、内存峰值、最低余量、启动时交换写入计数。

重新运行同一个命令即可续算。正常中断保留完成记录；若异常退出留下末尾半行，
下次启动先保存完整 recovery 副本，再舍弃半行补算，不丢弃任何完整记录。
中间已写入的损坏行或重复 ID 会报错，不伪装为完整结果。

Mac 启动要求可回收内存至少 34 GiB 且内存压力正常。运行中监控：
新增 swap-out、内存压力升高、原生 RSS 超过 32 GiB，或扣除求解器驻留页后的
保守余量低于 **2 GiB** 时停止。2 GiB 是用户指定阈值。
既有交换占用不作为新写入；不修改系统交换设置。监控无法承诺阻止系统的第一笔换出，
检测到增长即停止，不能声称已禁用 macOS 的交换机制。

2026-10-09 本地实证：50 组约 18.08 秒，1000 组约 55.56 秒，峰值 RSS 约
28.26 GiB，swap-out 计数 953258 未增长。全量实际吞吐随配对难度变化，不能按
1000 组样本保证完成时间。全量任务已实测从 8,638 条、17,267 条检查点恢复。
最终完成数量和校验结果以 `progress.json` 的 complete 状态为准。

## 分发与离线

服务器只分发预计算静态资产，无在线求解 API 和重型表依赖：

- `manifest.json`：版本、哈希、数量与格式，短缓存。
- `pairs-<hash>.bin`：每条 21 bytes，总计 4,678,464 bytes。
- `cases-<hash>.json`：完整公开 ZBLL 情况与公式，用于离线选题和展示。

文件位于 `core/packages/client/public/data/double-zbll/`，普通 Next 静态资产发布即可。
浏览器校验 SHA-256、全部记录范围及情况键，再激活题库。Hash 资产不可变，manifest 最后写入。

「下载离线包」另缓存当前语言的 run/select 页面与必要脚本、字体，并注册只控制
该 ZBLL 路径的 `double-zbll-sw.js`。不替换旧 `/sw.js` 退役脚本，不缓存账号或 API 响应。
必须在该设备和该域名下载后再离线使用；浏览器清理站点数据会清除下载。
公共训练情况在在线加载失败时回退到已校验的离线版本。

两层都遵循当前已选情况/分组。随机训练两层独立抽取；覆盖训练每组消耗两项，
奇数末项重复一次但仅记一项覆盖进度。双底成绩独立保存在 `trainer:3x3/zbll:double`，
双层总用时不会计入单个情况的 SRS 时间评级。

首版适用于本地训练和覆盖，支持计时与三条一屏。记忆、分屏、联机房间、智能魔方
自动判定和打印入口在双底模式下不提供，避免沿用单层语义生成错误题面。
