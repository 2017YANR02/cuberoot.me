# 魔方根助手：真实模型优化前后对照

后续年度排名、规则证据与长尾响应修复进度见[回归修复复测报告](assistant-regression-evaluation-2026-11-12.md)。本页保留首次评测结果。

**结论：整体有小幅收益，但不适合直接上线。** 候选版完整通过 46/58，原版 43/58；完成耗时中位数略降、标准化 Token 成本下降约 15%，但 P95 变慢，并引入年度排名口径和中心盖判罚回归。应先修这些问题，再做针对性复测。

本轮只在本地评测，没有提交、推送、部署，也没有写生产数据库。日期为洛杉矶 2026-11-12；正式对照运行于 UTC 2026-11-13 01:30–01:40。

## 主结果

30 道构造题 × 两版 × 两轮，共 120 份正式回答。综合资讯题 C02 因全站 SQL 数据覆盖不足，两版两轮统一排除；主比较为 **29 题、每版 58 份回答**，包含两道显式故障题。不挑选每题较好的一轮。

| --- | ---: | ---: | --- |

| 部分通过 / 失败 | 9 / 6 | 7 / 5 | 失败包含错误回答、无有效答复 |

同题同轮配对中，候选评分 **10 份提高、42 份持平、6 份下降**。去掉两份较主观的训练建议回答后，完整通过为 **43/56 → 44/56**；因此不应把这组小样本解释成稳定的线上质量提升。评分是执行助手依据预先写下的规则逐项审阅，不是独立人类评审。

排除两版任一请求报错的配对后，两边均为 56 份，完成耗时中位数仍为 3.750 → 3.530 秒，P95 仍为 8.157 → 10.957 秒；整体提速并非通过删掉慢失败请求得到。

## 具体回答体现了什么

**有效改善：**

- R02：原版两轮虽然答出“17 秒 DNF”，解释却错误地说“超过 15 秒即 DNF，+2 与观察超时无关”。候选两轮正确给出 15–17 秒 +2、达到 17 秒 DNF，并引用正文。
- R03：原版把抓取摘要未提耳机，推成规则没规定、交给代表自由裁量。候选承认现有正文不能确认，没有编造许可，但仍未回答用户所问的例外，所以只记部分通过。
- F02 / F04 / F05：候选直接复用已保存的表格身份、年份，当前值问题重新读取排名。六份回答无需生成模型。这些本地 fixture 调用仅 1–5 ms，**不能当作线上响应速度**，生产业务源还有网络延迟。
- D02：候选两轮月度去重比赛数都正确。原版第二轮未给出结果。独立真值为各月 2、1、2、4、2、4、1、1、1、2、5、1 场，全年 26 场。

**阻止直接上线的问题：**

1. **F01：年度排名口径回归，两轮重现。** 正确数据是截至 2025 年末的累计排名，Max Park 的 2023 年 3.13 秒可以位居该榜第三。候选两轮都因为成绩日期不是 2025 年而否定第三名，甚至声称数据筛选错误，同时又展示包含第三名的表格。原版两轮正确。
2. **R04：中心盖例外处理错误。** 候选第二轮明确把单个中心盖彻底丢失套为 DNF。官方 5b5+ / 5b5b 允许单个只有一个有色面的部件缺失仍视为还原；不能把缺棱块的例子泛化到单个中心盖。[WCA 第 5 章](https://www.worldcubeassociation.org/regulations/#5b5)
3. **D03：统计答案稳定性不足。** 真实记录独立计算为 DNF 2 次 / 尝试 245 次 = 0.82%，排除 DNS 和空缺。候选第一轮正确，第二轮因统计口径核验没有给出结论；原版两轮正确。
4. **E01：成功的部分结果仍可能被格式错误丢掉。** 候选第二轮最终输出校验失败，没交付百科已查明的 TPS 定义；本轮不能宣称已验证“部分来源失败也一定保留成功答案”。
5. **R01：两版均未充分澄清开表与首次转动。** “15.5 秒才转动”不等于“15.5 秒才启动计时器”，不能无条件判 +2。[WCA A4d](https://www.worldcubeassociation.org/regulations/#A4d)

**资料本身也需要修正。** 当前公开索引收录的是规则摘要，没有抓到耳机限制和中心盖例外的完整条文。速拧摘要还把计时器准备条件误写成要等检查时间走完，和官方 A4d 不一致。应分开保存权威条文、例外和站点解说，不能只要求模型“更忠实于摘要”。电子耳机、非电子耳罩与医疗设备的处理在官方 2i 中有明确区别。[WCA 选手条款](https://www.worldcubeassociation.org/regulations/#2i)

## 实验边界与可复核性

- **真实联网部分：** 两版均使用配置中的 `deepseek-flash`，返回的模型名也为该别名；thinking 为 auto，使用实际 AI SDK、流式回调、工具执行和真实 text-embedding-v4。没有用模拟模型答复替代。别名背后的供应商模型修订未独立锁定。
- **冻结业务来源：** 21 份公开响应快照；1796 页导航元数据、其中 24 页正文；四名选手完整公开成绩历史；历史排名、RSS、赛事日历及中文名称。业务 HTTP 读取由冻结响应替代，分析 SQL 在本地 PG 16 + pgvector 执行。没有读取生产私有对话或用户账户信息。
- **同条件：** 相同模型配置、依赖、问题与公开数据；按问题交错 AB/BA，第二轮反转；连续追问用各版本上一轮真实输出及表格，未手工塞入正确答案。旧版 61 个分块，候选 101 个分块；有效样本两版各记录 17 次 hybrid 检索，旧版另有一次本地词法回退。
- **尚未验证：** rerank、广域 web search 未启用；本轮没有新 HTML section 导出语料，全是旧公开正文上的新分块；未覆盖全站知识、长会话压缩、跨会话/重启记忆、浏览器流式渲染、认证或生产 HTTP 入口。因此这里的速度是本机 assistant 调用边界，不是线上端到端延迟。
- **C02 排除理由：** HTTP 赛事日历完整，但模型进一步调用全站赛事 SQL，而本地 SQL 表仅有四名选手的关联赛事。该题两版两轮统一排除主统计，费用仍计入总支出，不将该数据覆盖缺陷算作模型差异。
- **评分：** 2 分完整通过、1 分部分通过、0 分失败。逐项看答案、可见表格、来源以及范围约束；先隐藏版本标签审阅，完全相同的回答结构可复用已有内容判断。评分协议、每份理由和未筛选原文均保留。两轮不足以证明统计显著性，也不是按线上流量分布抽样。

## 准备失败、重跑及总费用

这些开销没有藏入主比较，也没有当作产品失败计分：

1. 初次 embedding 索引请求超时，已保存分块后续复用。已知用量约 ¥0.004129，另一次失败请求没有返回 usage。随后只给离线索引准备使用每请求 30 秒、最多两次瞬态重试；问答产品超时未改变。
2. 原候选在公开计时精度页面的重复数字段落上报 `Duplicate knowledge section`。评测前审阅并复用了工作区已有的段落位置 ID 兼容修复；6 项知识库测试通过。原失败 bundle 留存。

## 后续优先顺序

1. 先区分排名快照年份与成绩发生年份，防止通用时间过滤规则否定合法历史成绩。
2. 补齐并校对官方规则全文、父条款及例外，修正错误摘要；加入单中心盖/双中心盖/棱块、15 秒/17 秒/首次转动等边界验收。
3. 缩小故障后的重复检索与复核轮数，让已验证百科内容在最终 JSON 出错时仍能安全交付；同时复测 P95 与首字延迟。
4. 对 DNF 分母、月度去重数的核验增加诊断，区分查询真的错与模型误拒绝，不以放宽统计安全约束换通过率。
5. 补齐全站 SQL fixture 后重测双日期资讯；再单独验证新 section 语料、rerank 和长会话记忆。完成这些后才讨论上线。
