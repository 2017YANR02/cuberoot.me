## 首轮错误、修正及复测

- **R03 / R04**：把复盘编号 2763 当成 2763 秒，调用了列表查询。拆分列表与详情工具说明；明确编号先读取对应公开复盘，避免让模型误改成成绩。复测 R03 返回 4.72 秒、50 STM、10.59 TPS 和原始 7 行步骤；R04 按原始 ZBLS/ZBLL 注释回答，没有冒称独立 OLL/PLL 标注。
- **R06**：把比赛记录概括成“均为练习复盘”。列表回答改由已读取的数量和原始场景生成；来源标题补齐 rawTime 回退。R01—R06 全部复测。R06 原始记录仍有空场景与 `#REF!`，这是公开源数据质量问题，本轮不改写成猜测的比赛名称。
- **S71**：模型只传分表 key、遗漏统计 ID，重复获取了目录。schema 现在拒绝缺少 ID 的分表调用，提示模型补齐；复测已读到三阶对应分表的前五项。
- **既有统计适配器问题**：仅因一行同时包含选手和比赛链接，就套用“个人在一场比赛”的说明，导致 S66/S69/S77 等整轮统计描述错误。现在只对真正使用该口径的统计添加说明，全部相关题目复测。这是应用约束问题，不能归咎于 DeepSeek。
- 共做 **34 道定向复测**，不是第二轮完整 100 题。最新汇总取每题最后一次结果；首轮与全部复测都保留。完整来源、指定分表、数量、表头宽度、对象单元格检查：未发现问题。语义复核仍不等于对任意用户问题的正确性证明。
- 新增确定性回归覆盖编号/秒数/年份区分、复盘分类、遗漏统计 ID 及整轮/个人口径。4 个相关测试文件共 **58 项通过**；API typecheck 通过。
