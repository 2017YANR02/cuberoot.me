## 代码、资源及验收

- `space-shanghai-architecture.ts` 按对象 ID 覆盖普通底模，保留内院和同一关系的附属多边形；`space-shanghai-bridges.ts` 生成独立桥型与道路纵坡。`space-shanghai-geometry.ts` 将相同材质几何合并，避免逐窗/逐索单独 draw call。
- `build-shanghai-space.mjs` 保留合法道路宽度、车道数推算和 layer 字段。生成资产 5,912,486 字节，点线面数量未因本轮建模膨胀。模型几何本地生成，不依赖外部模型 CDN。
- 几何验收覆盖真实全部 8,646 条道路、共有节点一致性、最大异常坡度、南浦桥下步道、三桥主桥面尺寸、引桥底面和和平饭店三处内院。测试是防几何回归，不能代替视觉与测绘验收。
- 每栋/桥最终需：至少正面、侧面、三分之四、桥下或屋顶机位；上午/傍晚/夜间及阴雨对照；尺度、轮廓、材质与同机位参考实拍一致；街区接缝无穿插；桌面及窄屏交互、资源释放通过。实体手机帧时间和发热另验。
- 当前优先：第五批已为表内其余 20 栋历史建筑及外滩 15-1 号补独立立面和屋顶，继续逐栋校准开间、层高、柱头、雕刻、侧后立面与夜间灯光；取得汤臣裙房和花园资料。街道背景仍存在重复立面、缺实测楼高、绿地/岸线粗糙等问题，完整地区尚未达标。

2026-09-07，在现有本地 dev 服务实测；没有运行 Next build。截图为本地渲染结果，未用概念图替代。
