# AI 聊天监控

入口：管理员登录后访问 `/zh/admin#chat-monitoring`。前后端及 migration 0277 必须一起发布；旧的未记录聊天无法恢复。

## 统计口径

- 北京时间自然日；每次发送、编辑重问、重新生成分别计数。登录失败、参数/图片错误、配置缺失单列匿名入口计数，浏览器未发送的输入不在服务端覆盖范围内。
- 请求成功只代表技术完成。成功率分母为成功、失败和异常中断；取消、限流、进行中不算技术失败。耗时分位数仅统计成功请求，首段正文耗时仅统计实际流式输出。
- 浏览器在新对话/换号时重建会话 ID。服务端请求 ID、上一轮、重试来源用于关联；上一轮与重试 ID 必须属于同一用户、同一会话。管理员按会话及用户筛选，分页查看全部请求。
- 用户可点赞、点踩并标原因；仅本人可修改最近 30 天的记录。重复提交不重复计数。推荐页面/引用点击只接受服务端已返回的 ID，点击不代表完成训练。
- 管理员可筛选差评并标记待复核、已确认、已改进或无需处理，保存复核备注。列表/正文读取与复核留下管理员身份审计；API key 通道以 `__api_key__` 标记，不能区分共享该密钥的个人。
- 检索记录包含模式、降级原因、索引版本、最终片段 ID/路径和混合排名分数；不复制检索问题或资料正文。检索命中不证明相关性，需结合评价和人工复核。
- 请求的 `metrics.policy` 保存策略版本和用户选择的 `auto/fast/deep`；每次模型调用另记实际是否启用思考，不能把自动模式或用户选择直接当成实际思考调用。历史数与图片数记录压缩后的实际输入。

## 记录与恢复

调用付费模型前必须完成请求入库；数据库不可用时返回服务暂不可用，不消耗模型调用或每日额度。完成记录先在受限服务器目录写日志并同步磁盘，再更新数据库；成功后删除日志。重启后每分钟重放，幂等更新，不插入已删除的用户记录。

目录为 `SITE_ASSISTANT_OUTBOX_DIR`，Linux 默认 `/var/lib/cuberoot-assistant/outbox`，由建库服务的 systemd StateDirectory 提供专用可写目录，API 与建库进程共用；本地默认 `$HOME/.local/state/cuberoot/assistant-outbox`。自定义目录时须同步调整建库服务的可写范围。目录位于部署产物目录之外，目录 0700 / 文件 0600。最多 256 个完成文件、单个最多 256 KB。故障使用每进程绝对计数文件，重放不重复累加。磁盘和数据库同时不可写时仍可能丢失最终记录，由服务日志及外部心跳暴露；不能宣称物理故障下绝对零丢失。

问答正文/复核备注保留 30 天，读接口即时隐藏过期内容；每分钟分批清理。个人请求记录与管理员审计保留 90 天。每日匿名汇总保留 730 天，保存前先汇总完整日，禁止将部分删除后的旧日覆盖已有汇总。每日独立用户数不可相加作为年度独立用户数。账号注销级联删除请求，磁盘重放不能恢复已删除记录。异常退出的聊天在 2 分钟后标为中断，离线建库为 20 分钟。

正文上限与对话契约一致：问题 8,000 字符、回答 12,000 字符。完成记录按 UTF-8 字节控制附件与检索明细的体积；超限时保留正文、费用、调用计数及来源摘要，并标记附件或检索明细已截断。图片和完整历史不进入监控记录。

## 费用

聊天每一轮以及在线/离线向量调用均记录用量。输入含缓存 token，输出含思考 token，不重复累加。未返回用量或未知模型记为未估价，不能视为免费。

2026-10-26 起，已支持价目的聊天调用另保存 `cacheAdjustedCny: {min,max}` 与缓存价目快照；后台问答详情显示这些调用的合计区间和覆盖数量。DeepSeek 用已核实的高峰/低谷标价给区间，避免猜测中国节假日；百炼已知缓存价目可给相同上下界。缓存用量缺失或不合法时不补造优惠估价。该区间只含已估价模型调用，不含其他工具费用，也不是账单实付。已有 `grossCny`、每日汇总与费用提醒继续使用保守标价，不回写历史。模型用量表同时纳入重排序调用。

策略记录更新为 `2026-10-26`，可用于区分本轮上下文去重、计算复核和检索范围调整；需要发布后才会出现在生产新请求中。

可选重排序另记 `metrics.reranks`（模型、候选数、tokens、耗时、状态、价目快照）和 `stages.rerank`。2026-10-26 按[百炼官方价格](https://help.aliyun.com/zh/model-studio/model-pricing)核实北京 `qwen3-rerank` 每百万输入 token 0.5 元，保存 `bailian-rerank-beijing-2026-10-26` 快照。缺少用量或未知端点仍保持费用 `null` 并计入 `unpricedCalls`，不能因返回 RRF 原结果而把失败调用算成免费。403、超时、非法响应会保留原排序；请求被取消则终止。该能力默认关闭，启用条件及评测边界见 [第一阶段记录](benchmarks/site-assistant-phase1-2026-10-26.md)。

联网搜索另记 `metrics.searches`；北京百炼 turbo 搜索按 [官方联网搜索文档](https://help.aliyun.com/zh/model-studio/web-search/)的每千次 3 元保存 `bailian-web-turbo-2026-10-23` 价目快照。供应商返回的是搜索意图次数，只用于估算，不宣称与账单调用数一致。搜索内部模型 token 与搜索服务分别计费；缺少搜索计数时保持未估价，不记为零。

价目快照 `bailian-beijing-2026-10-15`：按[百炼官方价格](https://help.aliyun.com/zh/model-studio/model-pricing)核实北京服务的 `qwen3.8-flash` 输入/输出 0.8/2.7 元每百万 token，`text-embedding-v4` 输入 0.5 元每百万 token。另按 [DeepSeek 官方人民币价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)保存 `deepseek-cny-peak-2026-10-15`：Flash 输入/输出 2/8 元每百万 token，V4 Pro 为 9/27 元；使用高峰未缓存标价，故未扣低谷和缓存优惠。快照保存在每次调用记录中，未知供应商不套用这些费率。展示未扣缓存折扣、免费额度和合同优惠的标价估算，实际支付以服务商账单为准。更换模型/地域/费率需更新估价规则及测试；旧记录不重算。

## 告警

服务每分钟检查并持久化告警：

- 最近 15 分钟至少 10 条已完成请求，失败/中断比例 ≥20%。
- 同样最低请求量下，成功请求 P95 >30 秒。
- 存在待补记，或最近 15 分钟有记录故障。
- 当天已知用量的标价估算 ≥ `SITE_ASSISTANT_DAILY_COST_ALERT_CNY`（默认 20 元，仅提醒，不停止付费）。
- 最近 15 分钟至少 5 个请求存在无法估价的调用。

异常与恢复使用管理员站内通知及其已启用的邮件通道，稳定事件键避免重启重复通知。未配置邮件不会影响站内通知。

独立 GitHub Actions `Assistant Monitor` 每 15 分钟通过现有部署 SSH 通道检查受管理员保护的 `/v1/admin/assistant/health`，后台心跳超过 5 分钟或有活动告警则失败。沿用 `BARK_KEY`，仅在检查结果从正常变异常或恢复时推送；GitHub 定时运行可能延迟，不是实时 SLA。服务自身或数据库完全不可用仍可被外部检查发现。通知不携带问答正文。

## 验证与发布

- `core/` 中运行目标 server/client typecheck。
- API 的 `site_assistant` 回归覆盖 SDK、图片、身份、流式请求、指标隔离、估价和故障准入。
- 独立本地 PG 测试 `apps/api/tests/fixtures/site_assistant_monitor_pg.ts` 验证真实 migration、时区边界、权限、反馈、复核、会话、日汇总、告警去重/恢复、日志重放及删除后不复活。只能连接明确命名的本地测试数据库。
- 发布后确认 Deploy Core 自动迁移、Deploy Next/Vercel 部署及受保护 health；发送维护者自己的验证问题，检查问答/评价/点击/费用记录。不要把演示样本当作真实用户指标。
