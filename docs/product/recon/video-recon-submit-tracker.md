# 上传视频生成复盘草稿

添加复盘页原有的已知打乱上传流程已通过本地验收，并于 2026-11-21 推送至主分支。

- 上传继续走[复盘视频 API](recon-api.md)，原始文件同时交给视频工具的识别工作区。弹窗保留同一份表单，沿用视频工具的选段、自由裁剪、回放和起手朝向操作。
- 三阶视频在 30 秒以内自动开始。较长的视频先选择一把还原的区间。打乱留空时，可用同一份视频从结尾的还原局面倒推。其他项目仍可上传附件。
- 只有能完整还原、且分段记谱与识别局面一致的结果可以回填。已有打乱用于校验；空打乱表单可同时收到解法和普通打乱栏的「由视频推定的等价打乱」。已有解法需要主动选择替换。比赛资料、成绩、官方与最短打乱、起表和拍表由原表单管理，提交动作由用户完成。
- 本地识别和附件上传各自报告结果。确认旧版 `/video-recon` 下线需要单独授权。

## 验收

- [x] 实现前对抗性审查。确认文档隔离、官方数据优先级、解法回填与上传边界。
- [x] 实现后对抗性审查。修正异步上传归属、弹窗关闭、回填标记和重裁剪。
- [x] 在内置浏览器中上传 3.48 秒的三阶录像。表单自动填入通过还原校验的解法，保留 WCA 单次和纪录，并在视频栏收到模拟附件地址。
- [x] 模拟上传接口返回 503。识别结果仍可手动使用，原先填写的解法保留。31.2 秒录像进入选段界面。
- [x] 验证添加复盘页的 WebGPU 识别。测试附件都由本地模拟接口处理，未创建真实复盘记录。
- 已通过对抗性审查核对过期结果。账户和草稿入口决定附件归属，活动场次和生效的打乱额外决定解法是否可写入。
- 无打乱上传的新增分支先回放识别出的原始转动，逐段比对显示出的记谱，再用原始起始局面复核完整解法。通过后复用模拟器生成等价打乱并再次验算。推定打乱只进入普通栏。比赛打乱在等待期间返回、切换分组或关闭弹窗都会使旧结果失效。
- [x] 在内置浏览器中两次上传遮住字幕的 6.98 秒视频并留空打乱。空草稿自动收到推定打乱和分段解法。已有手写解法 `R U` 的草稿在识别完成时保留原文，点击「使用这份解法」后才写入分段解法，并切换到普通打乱栏。两次测试均使用本地模拟附件接口。视频核对见[拍摄与无打乱复盘跟踪](video-recon-capture-tracker.md)。
