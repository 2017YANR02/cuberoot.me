# 上传视频生成复盘草稿

添加复盘页原有的已知打乱上传流程于 2026-11-21 推送至主分支。开放本地识别和会员主动保存的流程已通过本地验收。

- 「选择视频复盘」交给视频工具在浏览器内分析。游客可以查看和复制结果，登录后可以把结果填入复盘表单。弹窗沿用视频工具的选段、自由裁剪、回放和起手朝向操作。
- 会员选择文件后可勾选「保存视频到本站」，默认不勾选。通过表单校验后，提交时才调用[复盘视频 API](recon-api.md)上传，并把返回的链接随复盘提交。仍沿用 200 MB 上限。更换视频需要重新勾选。上传失败时保留草稿，可以重试或取消勾选后提交。上传成功但复盘提交失败时，同页重试复用上传结果。
- 选择三阶视频后先预览并选择还原区间，点击「开始复盘」后再分析。弹窗复用表单中的打乱。表单打乱留空时，从视频结尾的还原局面倒推。其他项目仍可上传附件。
- 只有能完整还原、且分段记谱与识别局面一致的结果可以回填。已有打乱用于校验；空打乱表单可同时收到解法和普通打乱栏的「由视频推定的等价打乱」。已有解法需要主动选择替换。比赛资料、成绩、官方与最短打乱、起表和拍表由原表单管理，提交动作由用户完成。
- 本地识别和附件上传各自报告结果。旧版 `/video-recon` 已退役，自动复盘的独立入口是 `/frame-count?mode=detector`。

## 复盘字幕视频

在视频区选择「嵌入复盘字幕」，可将当前解法逐段写入 MP4 画面。可以选择已有视频，也可以直接选择文件。浏览器优先使用已应用的识别阶段时间；手写解法读取注释末尾的阶段用时（包括识别与执行用时之和）。用户可定位还原起点、编辑区间，或导入 LosslessCut 的 LLC、秒数或时间码 CSV。缺少用时时提供可调整的初始分配。

本地生成和下载复用视频工具的 Mediabunny 转码流程。会员可将成片选为当前附件，勾选「保存视频到本站」后随复盘提交。更换文件或解法会使旧成片失效。
