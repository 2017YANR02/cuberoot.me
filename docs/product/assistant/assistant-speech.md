# 回答朗读

入口为回答工具栏的「朗读」。支持标准 DashScope 协议、浏览器逐帧播放、音色与语速选择。北京 workspace 模型已通过本地真实聊天页全链路验收，使用独立本地测试账号、已完成回答和 PostgreSQL 测试库；生产部署与真实播放验收分别记录，主观音色偏好仍由试听判断。

## 调用与播放

`POST /v1/site-assistant/speech` 复用聊天的账号与 WCA 资格校验。请求携带 messageId（优先）或旧 requestId、清洗后的预期回答、语言及分段序号。服务端只读取本人已完成的持久回答；旧问答从监控的 answer 与 response 组合恢复，已清理的历史记录不可合成。服务端复用 shared 的 `assistantAnswerText` / `assistantSpokenText`，逐字比较预期朗读内容，拒绝内容已变更或任意文本代传。

整条回答不超过 30,000 UTF-16 码元。首段最多 80 个 Unicode 字符，从约 20 字符处开始优先寻找完整句末，避免为了凑长度多等几句话；第二段最多 160 字符，后续每段最多 320 字符。分段保持原文和顺序，不拆开代理对。客户端及路由允许最多 200 段，覆盖最大文本在自然断句后的情况。

北京 workspace 协议使用 `X-DashScope-SSE: enable` 直接接收 MP3 数据帧，省去音频文件 URL 的额外下载连接；验证每个数据帧后立即转发，只有收到完成标记才写入缓存；截断、错误和超限音频立即终止，不把部分音频当成成功结果。标准 `qwen3-tts-flash` 协议及供应商返回普通 JSON 时仍使用受限的 OSS 下载路径，不因失败自动重试付费合成。

浏览器支持 `MediaSource.isTypeSupported('audio/mpeg')` 时，请求增加 `stream: true`。workspace 路由在鉴权、归属与文本校验后返回私有 SSE：`meta` 给出 MIME 和总段数，`audio` 逐帧携带 Base64 MP3，`done` 表示合成完成，`error` 表示中途失败。响应禁止缓存及代理缓冲；断开连接会取消上游请求。响应头发送后的失败通过 `error` 事件通知客户端，不能只按 HTTP 200 判断成功。

客户端用 MediaSource/SourceBuffer 按序追加数据；首批可解码音频到达即可播放，后续数据在播放过程中继续追加，不等待整段生成完成。当前段生成完成且已开始播放后，仅预取下一段；不会并发合成多段或提前生成整篇回答。预取失败先让当前段播完，再显示失败回退；停止、切换回答或播放错误同时取消预取。供应商尚未完成下一段时仍可能有等待。

不支持 MP3 MediaSource 的浏览器不请求流式传输；标准 Qwen-TTS WAV 即使收到 `stream: true` 也继续返回完整段 JSON。两者使用原有 Blob 分段播放。浏览器及时释放 Blob/MediaSource URL；部分音频已经播出后发生错误不会自动重新合成或从头朗读，用户仍可主动选择系统语音。

点击停止、播放另一条、切换回答或卸载组件会取消请求与播放；浏览器禁止自动播放、服务未配置或合成失败时，显示「使用浏览器朗读」，由用户点击后启用原有系统语音，不自动重播全文。停止本地请求不能保证供应商已执行的合成不收费。

## 音色与语速

回答工具栏的朗读按钮旁提供音色菜单和语速菜单。偏好保存在本机浏览器，所有回答同步使用，刷新后保留；切换音色停止旧朗读，下次点击朗读时使用新音色。系统语音回退仍使用浏览器自身音色，不将百炼音色映射为系统音色。

`GET /v1/site-assistant/speech/options` 在相同账号/WCA 鉴权后返回当前模型的默认音色和可选音色，响应为 `private, no-store`。客户端仅按需请求，合并并行请求并短暂缓存 60 秒；模型变更后，不再支持的本地选择回到当前模型默认音色。`POST /v1/site-assistant/speech` 可传 `voice`，路由和合成器都按当前模型白名单校验，在付费请求前拒绝不支持的音色。既有缓存键包含最终音色，相同文本的不同声音互不混用。

音色菜单使用便于辨认的声音特点名称，底层 ID 不变：workspace 3.1 Flash/Plus 的龙安欢显示为「活泼女声」，龙安灵心为「温柔女声」，龙安风悦为「知性女声」，许南川为「磁性男声」；标准 Qwen3-TTS Flash 的芊悦显示为「明亮女声」，苏瑶为「温柔女声」，晨煦为「阳光男声」。这些是产品展示名，参考官方试听定位，不是新增模型或官方音色 ID。显式配置的默认音色保留为可选项，未登记模型仅提供已配置音色。依据为百炼的 [Qwen-Audio 音色列表](https://help.aliyun.com/zh/model-studio/qwen-audio-tts-voice-list) 与 [Qwen-TTS 音色列表](https://help.aliyun.com/zh/model-studio/qwen-tts-voice-list)。

语速提供 0.75×、1×、1.25×、1.5×、2×。使用播放器 `playbackRate` / `defaultPlaybackRate`，开启 `preservesPitch`，在流式播放和 Blob 回退中都能即时调整并延续到下一段。语速不发送给模型、不重新合成、不增加缓存变体。浏览器系统语音使用同一倍率；由于已开始的系统 utterance 不能即时变速，调整时停止，重新朗读后应用新速度。

本地验收已验证四种 workspace 音色的真实合成、聊天页换音色停止旧播放、1.5×→2× 即时变速且无额外合成、刷新后偏好恢复和 390px 宽度菜单无横向溢出。证据位于 `.local-data/assistant-tts/voice-speed-acceptance/`；标准接口音色映射仅做契约测试，未使用标准接口凭据实测。

## 配置

在 API 运行环境配置（模板见 `core/apps/api/.env.example`）：

- `SITE_ASSISTANT_TTS_ENABLED=1` 开启，默认关闭。
- 生产部署在该开关尚未配置、且已有可复用的北京百炼密钥与地址时自动初始化为 `1`；显式 `0` 始终保留。初始化仅追加开关，原 `.env` 私有备份为 `.env.before-assistant-speech`，不复制或输出密钥；模型权限仍由线上真实朗读验证。已有独立 TTS 配置优先，后续部署不覆盖。
- `SITE_ASSISTANT_TTS_BASE_URL`：北京标准接口 `https://dashscope.aliyuncs.com` 或北京业务空间 HTTPS origin，不含 API 路径。留空复用 `SITE_ASSISTANT_BASE_URL`（支持 `/compatible-mode/v1` 路径）；两者均空时使用标准接口。非百炼聊天地址不能自动复用。
- `SITE_ASSISTANT_TTS_API_KEY`：可独立配置；留空依次复用 `SITE_ASSISTANT_API_KEY`、`DASHSCOPE_API_KEY`，须具有同地域的语音模型权限。
- `SITE_ASSISTANT_TTS_MODEL` 留空自动选择：标准接口为 `qwen3-tts-flash`，业务空间为 `qwen-audio-3.1-tts-flash`。
- `SITE_ASSISTANT_TTS_VOICE` 留空自动选择：前者为 `Cherry`，后者为 `longanhuan_v3.1`，自定义音色需与模型匹配。

若聊天 Key 没有语音模型权限，可在仓库 Actions Secrets 配置 `SITE_ASSISTANT_TTS_CONFIG`，内容为上述五个 TTS 字段的私有 env 文本（必须包含独立 Key 与北京 origin，不接受聊天、数据库或其他字段）。`Deploy Core` 通过 SSH 标准输入同步，仅替换这五项，原配置私有备份为 `.env.before-assistant-speech-secret`；保留运行环境的显式 `0` 停用开关。密钥不得写进源码或日志。`Assistant speech diagnostics` 可只读查看最近 20 条语音状态码与耗时，不输出密钥、正文或音频地址。

标准 `qwen3-tts-flash`（含日期快照名）使用 `/api/v1/services/aigc/multimodal-generation/generation`，发送 `text`、`voice` 和 `language_type`；中文回答使用 `Auto` 支持中英混读，英文回答使用 `English`。原业务空间模型继续使用 `/api/v1/services/audio/tts/SpeechSynthesizer`。标准域名下不接受业务空间专用模型，避免发送不匹配的协议。

供应商地址仅允许北京标准 DashScope 或 workspace；音频仅允许北京 OSS HTTPS 地址，供应商返回 HTTP OSS 链接时先升级为 HTTPS 再下载，禁止重定向。按实际供应商返回域名验收，不能为绕过失败开放任意下载地址。官方依据：[标准 Qwen-TTS API](https://help.aliyun.com/zh/model-studio/qwen-tts-api)、[HTTP API](https://help.aliyun.com/zh/model-studio/qwen-audio-tts-http-api)。

## 缓存与用量边界

音频内存缓存按账号、地域、模型、音色、语言和分段文本哈希隔离；内容变化后重新生成，相同分段可复用。缓存最长 10 分钟、最多 128 段/32 MiB；响应一律 private, no-store，不提供公开音频链接。每次请求重新验证归属和回答内容，缓存不能绕过鉴权。

每账号每分钟最多 30 次请求；每进程每账号每天最多请求合成 30,000 UTF-16 码元（UTC 日界，失败也计数），同一账号最多 1 次在途合成，全进程最多 4 次。单段请求与下载共享 45 秒期限，音频上限 4 MiB。限流与日用量是进程内保护，重启会重置，多进程不共享，不能视为持久账单硬限额；正式启用时应配合百炼账户预算。

`assistant_tts` 结构化日志记录模型、输入码元数、总耗时、首个音频数据帧耗时、处理阶段、上游 HTTP 状态及受限错误码，不记录文本、密钥或音频地址。首帧到达不等于浏览器开始播放。该记录不等于供应商的计费字符数或实付金额，尚未并入助手数据库费用报表。

## 验证

服务端测试覆盖鉴权、回答归属/内容变化、分段、缓存隔离、下载地址、标准协议、凭据复用和并发取消；客户端测试覆盖 WAV/MP3 按序播放、首音先于流完成、逐帧追加、截断/错误流、停止后不续播、URL 释放及播放失败；真实页面另验证手动系统语音回退。真实凭据、目标模型权限及浏览器音质/首音延迟需在启用前完成实测；本地测试不能替代该验收。

当前逐帧版本本地单轮实测：672 字长文首音 569 毫秒，首段上游合成耗时 934 毫秒，四段自然播放完成、三次衔接均约 54 毫秒；50 字短文首音 567 毫秒，收到流完成标记为 1144 毫秒。停止、切换互斥、注入 1.5 秒等待时取消、503 手动系统语音回退及禁用 MediaSource 能力后的 Blob 回退均通过；6 项真实 API 权限/参数校验、20 项服务端测试、11 项客户端测试和两端类型检查通过。证据在 `.local-data/assistant-tts/browser-stream-acceptance/`。测量为浏览器 `playing` 事件，不包含声卡输出延迟；测试使用本地种子回答，未调用新的聊天模型生成。全仓文档检查仍有 136 处与本次修改无关的历史本地产物链接缺失。

## 本地真实接口验收入口

在 `core/` 执行 `pnpm --filter @cuberoot/server exec tsx scripts/check-assistant-speech.ts` 只检查配置；加 `--run` 才发起真实合成。默认私有配置为仓库根 `.local-data/assistant-tts/config.env`，要求普通文件、权限 `0600`。可通过 `--env-file=/已有私有配置文件路径` 直接复用聊天配置，仅加载百炼相关字段，不加载数据库或账号密钥。

固定中文短句、中英混读及长文本样本逐段执行一轮，复用实际合成适配器和分段函数，失败即停止、不自动重试。记录供应商响应头耗时、完整音频就绪耗时及内存缓存耗时；音频与记录保存至 `.local-data/assistant-tts/` 的独立时间戳目录。不把响应头耗时或音频就绪耗时称为浏览器首音延迟，音质另需试听。

2026-11-17（洛杉矶时间）优化前实测：`qwen-audio-3.1-tts-flash` / `longanhuan_v3.1`，中文短句 39 字符音频就绪 2.298 秒，中英混读 96 字符 1.872 秒，长文本两段 486/186 字符分别 13.931/4.615 秒。4 段均为 24 kHz 单声道 MP3，完整解码通过。独立本地验收页另测短句：点击到 `Audio.play()` 成功 1.299 秒、缓存重播 15 毫秒。

同日优化后，原 672 字符长文本分成 66/142/318/146 字符四段。实际聊天页使用正式的 HttpOnly 会话交换、账号/WCA 资格校验、回答归属 SQL、百炼合成和播放器，未模拟语音返回。首段音频就绪 2.325 秒，较原 13.931 秒减少约 83%；朗读操作触发至浏览器 `playing` 事件 2.363 秒。四段自然播放完成，三次段间切换为 54/56/57 毫秒，后续音频均在前段结束前返回。缓存首段再次触发至播放约 25 毫秒。

本地验收覆盖播放结束复位、停止、切换回答互斥、503 错误提示及手动系统语音回退；另注入 1.5 秒网络等待，确认首段请求和下一段预取均可取消，随后没有续播。真实 API 验证未登录/无效会话返回 401，他人回答/不存在回答返回 404，内容变更返回 409，越界分段返回 400。测试账号及完成回答为本地种子数据，未生成新的聊天模型回答或修改线上数据。独立验收服务运行于 4319/4320，验收后关闭；原 3000 开发服务保持运行。证据保存在本地 `.local-data/assistant-tts/chat-acceptance/`。

以上均为单轮样本，不是分位延迟基准；浏览器播放事件不包含声卡的实际声学输出延迟。首音优化不改变模型或音色，发音准确度和自然度仍可使用留存音频人工试听。

同日第二轮优化改为 workspace SSE 音频直返，并将长文本首段提前到 22 字符的完整句末。原样本成为 22/146/318/186 字符四段；独立真实合成首段音频就绪 0.762 秒，7 段中文/混读/长文样本均成功且完整解码通过。聊天页在新启动的 API 进程中实测，首段音频就绪 0.897 秒、操作触发至播放 0.918 秒，比上一版 2.363 秒减少约 61%；首个段间切换 54 毫秒。该次页面复验确认连续分段与停止后结束，没有重复宣称整篇播放完成。数据与截图保存于 `.local-data/assistant-tts/stream-probe/`，独立合成样本保存于 `.local-data/assistant-tts/2026-11-18T03-43-52-157Z/`（目录使用 UTC）。本轮服务保持运行，供用户试听。
