# Agent 十条剩余问题与七条退步复测

日期：2026-11-15，America/Los_Angeles；原始日志使用 2026-11-16 UTC。本会话只修改项目 Agent，未修改 Codex，未暂存、提交、推送或部署。其他会话的统计、恢复测试及 CI 修改保留，其独立发布不属于本轮发布。

## 结论

上一轮 9 条部分达标与 1 条校验失败涉及 8 个场景。本轮这些场景共 16 条回答从 **4/16 → 15/16** 完整达标；优先处理的 7 条退步涉及 C05、C13、N01、D01、T02、R03，这 6 个场景的两次重复均达标，合计 **3/12 → 12/12**。

最终生效路径覆盖为 **55/76 → 73/76 完整达标**。仍有 **2 条部分达标、1 条词数校验失败**，逐对评分 **20 升、53 持平、3 降**。因此不能宣称全部问题已解决：整体质量改善、平均及中位耗时门槛通过，但预先要求的 D02 两次全部成功未通过。

这是按修改范围组合的最终路径覆盖，不是最终整版的一次连续全量运行。完成完整主测后，对所有受影响的计划场景进行双方、全部重复的定向补测；每条记录有 provenance，没有挑选更好的重复，也没有把失败请求删掉。

## 实现与边界

- 将魔方计划按当前任务区分为普通观察、已给配色、遮挡、慢拧、已准备图示。普通观察围绕同一个角块的可见信息进行记录、回忆和复核，避免自行增加归位、未知配对及准备状态。已给配色只比较实际颜色集合；当前位置不当作已知。
- 慢拧包含原定时长内的准备，后续观察承接刚插入的同一组；当前明确要求两项慢拧时，两项都必须实际转动且各自准备。图示分别检查角扭转、棱翻转和排列奇偶，区分扭转值之和与扭转角块数量。
- 修复将“至少一个扭转角块”误当作“恰好一个”的校验；补充活动名中的 vocabulary/revision 与“substeps and a reason under each”结构识别。`mm:ss — 动作` 支持精确时长解析，非法秒数、父子和不符、动作中提及的钟点仍不接受。
- 英文词数上下限保持不变，按预算给出每个动作块的长度目标；失败返修隔离旧助手文字，长度返修重新生成而非照抄失败草稿。自然语言词数合同置于系统指令末尾。试过的思考式计数返修耗时明显增加，已撤回；最终仍是有限次数的快速返修，不能保证次次满足词数。
- 仅在没有任何检索证据/来源、没有图片/引用消息、没有站点资料义务的普通计划中，且模型明确为 `general`、答案没有引用或链接时，把**缺失**的 `sourceIds` 补为 `[]`。已有非法值不修补，有证据和非 general 输出仍严格拒绝。主输出 schema、来源 ID、来源支持范围、词数、数量和时长校验保留。
- 词汇练习继续在既有子步骤内提供空集合/数量不足兜底，补充“弱词、记号”等表达，并要求每个子步骤各自给出理由、后续读写材料必须已产生。当前仍有一条口述后要求读回的语义缺陷，不能把提示词视为完整语义证明。

主要变化在 API 的 `site_assistant.ts`、`site_assistant_memory.ts`、`site_assistant_model.ts`，对应回归在 contracts/model 测试。原有八层上下文、保护系统提示词与当前需求、资源/RAG 链路及来源闭合逻辑继续保留；本轮没有新增包、改数据库或客户端。

## 剩余与逐对退步

- **T03 / 第一次**：纠正 PLL 时，从只有名称和翻译的词条延伸到“不做朝向处理”，超出来源支持范围；引用完整不能证明这句话正确。
- **R01 / 第二次**：先口头说出句子，后续要求读回并修改，未先产生书面记录。
- **D02 / 第二次**：快速返修后仍未满足 180–230 英文词范围，返回 `model_output_invalid`。第一次最终回答 183 词、2.546 秒；第二次失败耗时 4.527 秒。没有放宽词数或填充固定句子冒充达标。

这三条也就是最终逐对评分下降的样本。D02 从本轮开始版本的 0/2 到 1/2，仍未完成“两次都成功”的目标。人工语义评分由同一 Agent 非盲复核，未做独立人工验收；表中得分与上一轮 66/76 使用的随机输出不同，不能把跨轮样本直接当作固定基线分数。
