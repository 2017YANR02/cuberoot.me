# Agent 缩写展开与首次答案复测（2026-11-15）

状态：仅本地，未提交、推送或部署。承接[约束与百科核验复测](assistant-context-followup-2026-11-15.md)，本轮只改变项目 Agent 的词条证据和受限计划输出方式。系统提示词、当前用户需求的保留规则及最近强／弱相关窗口不变，未修改 Codex。

## 改动与边界

- **有来源的缩写展开**：实际词条 `wiki:439` 是 `OLL (Orientation of LL)`，`wiki:482` 是 `PLL (Permutation of LL)`；另一个真实词条 `wiki:348` 才是 `LL (Last Layer)`。同一次百科读取内补入唯一、明确的一跳依赖，生成 `expandedEnglish` 和 `expansionSourceIds`，保留原始标题，并要求同时引用两个来源。不新增 HTTP 或模型调用，不修改百科原文。
- **限定展开范围**：最多补入 4 个关联词条；缺失、重复含义、未提供展开、循环引用均不猜测。证据压缩裁掉依赖词条时，同时移除派生全称，不能留下没有支撑材料的展开结果。
- **减少校验前的生成时间**：有分钟总额的计划默认直接列编号行动，每项一句可执行说明，省去开场、重复限制和结尾总结。用户明确要求详细解释或嵌套子步骤时仍保留。继续在展示前核对顶层时长，不提前展示尚未校验的正文，也不以进度提示冒充首次答案。

实现：`core/apps/api/src/utils/site_assistant_tools.ts`、`site_assistant_evidence.ts`、`site_assistant.ts`；回归覆盖在 `tests/site_assistant_tools.test.ts`。沿用现有服务端工具、预算和来源契约，无新增依赖、数据库表或跨端改动。

## 首答收益与仍然慢的场景

简单受限计划 C05/C13/C14/C15 每版 8 条，候选全部符合本题要求，均一次模型调用后校验展示。首答中位数 **2.061 → 1.502 秒（−27.2%）**，平均完成时间 **2.334 → 1.496 秒（−35.9%）**，输出 token **2,058 → 774（−62.4%）**。该组基线有一次额外修正调用；其余收益主要来自减少重复文字，不是去掉守卫。

供应商缓存未受控：输入缓存占比约 **95.8% → 93.8%**，未缓存输入 **33,725 → 50,013**。总 token 包含缓存、推理、修正及重试；没有据此计算费用节省。全部样本保留，未剔除慢回答，usage 完整，资源快照未漏取。
