# Agent 剩余语义问题与两项退步复测

日期：2026-11-15，America/Los_Angeles（原始日志为 2026-11-16 UTC）。本轮只修改项目 Agent；本会话未暂存、提交、推送或部署，也未修改 Codex。其他会话的统计修改保留。

## 结论

上一轮 8 条部分达标涉及 P01、P02、T01–T04。本轮优先的 P02（不合法 OLL 示例）、T04（错词数量不足）最终均为 **2/2 完整达标**。六个目标场景共 12 条：**4/12 → 10/12**，T02 的隐藏颜色与配对推断仍未解决。

最终生效路径覆盖为 **59/76 → 66/76 完整达标**，复杂计划 **10/20 → 14/20**；预设平均及中位耗时不超过基线 110% 的分组门槛通过。仍有 **9 条部分达标、1 条输出校验失败**；逐对评分 14 升、55 持平、7 降，不能宣称无单例退步或全部语义问题已修复。

这不是最终整版的一次连续全量运行：完成 152 次主测后，对最后修改影响的 6 个案例进行 24 次真实模型补测；按事先登记的范围，替换这些案例的双方、全部重复，形成 76 对最终路径覆盖。完整主测独立保留，未删除慢请求或失败请求。

## 实现

- 显式颜色信息投影：仅解析用户给出的角块/棱块颜色和十字色，三色角块与双色棱块分别检查；不从当前位置补隐藏贴纸。
- 保留原有计划格式，向当前任务提供可用数量、状态衔接和合法性要求；有限规则检测错词选择和单角扭转示例。否定说明按活动段落理解，避免把“描述错误状态后指出违法”误拒。
- 词汇练习的空集合/不足兜底写入既有子步骤，不增加活动、时长或模型调用；随后继续校验结构、英文词数及父子时长。兜底服从显式输出语言；字数限制中的 `words` 不等于词汇任务。
- 百科仅有标题/翻译时，检测未请求、未读取的额外缩写解释；一次快速返修后仍检查来源范围。使用完整派生英文名时，从已读 `expansionSourceIds` 补齐引用和来源，不新增事实或读取。
- “不添加操作步骤”不再触发页面操作资料义务；独立页面功能问题仍需要页面证据。

主要源码为 API 的 `site_assistant.ts`、`site_assistant_memory.ts`、`site_assistant_tools.ts`，回归用例在 `site_assistant_contracts.test.ts`。原有分层上下文、来源检查、结构和时长校验继续生效。正则检查不是通用语义证明，词汇兜底也不覆盖任意物料集合。

## 剩余问题与逐对退步

候选的 9 条部分达标：C05 两次仍在 F2L 完成后要求继续新组而未准备状态；C13 一次混淆当前位置和归属槽；N01 一次配色表述不成立；D01 一次要求固定 3 角 3 棱但未处理可见数量不足；T02 两次仍有角块筛选或根据位置推断配对问题；R02 一次混淆角扭转与棱翻转两个独立守恒条件；R03 一次把已知颜色与当前相邻中心匹配当作既成条件。

D02 第一次补测在返修后仍未通过英文词数校验，返回 `model_output_invalid`，未放宽校验来计为成功。

逐对评分下降为 C13/1、N01/1、T02/1、R03/1、C05/2、D01/2、T02/2（斜线后为重复轮次）。这些样本应作为后续重点；随机模型的单次退步不能直接证明全部由某条规则造成，但不能从报告中排除。人工判分由同一 Agent 非盲复核，未做独立人工验收；引用 ID 存在不代表每一句受支持。
