# Agent 约束、百科核验与耗时优化复测（2026-11-15）

状态：仅本地，未提交、推送或部署。本轮承接[首次分层上下文评测](assistant-context-evaluation-2026-11-15.md)，比较的是**上一版 Memory Graph 与修复候选**，不是重新比较无记忆的旧版本。两版均包含本轮开始时已有的统计元数据相关修改，这些已有修改未被覆盖或归为本轮优化。

72 条核心真实模型对照中，完整达标从 **29/36 提升到 34/36**，总 token 减少 **17.2%**，平均完成耗时减少 **23.0%**。收益主要来自消除百科问题的错误页面要求和额外复核；普通成功问题的平均耗时基本持平。受限计划须在展示前检查，因此首次答案中位数变慢。

实现位于 `core/apps/api/src/utils/site_assistant_memory.ts`、`site_assistant_model.ts`、`site_assistant.ts`、`site_assistant_policy.ts` 和 `site_assistant_algorithm_request.ts`。没有新增数据库表、依赖或跨会话用户档案，也没有更改 Codex 的配置、提示词或记忆。

时长守卫的确定性范围是**可识别的阿拉伯数字分钟上限与显式编号／项目符号的顶层时长**。其他单位、无数字的限制、隐藏在正文的额外活动和一般语义约束仍由模型处理，不能宣称已经全面强制执行任意自然语言约束。子项不重复记账，不代表已经逐项验证所有子项的内部算术。当前更正、总额与每项上限的区分另有回归覆盖。

## 核心对照结果

18 个固定场景，每版每题 2 次，共 72 条回答；按题交替 AB/BA，第二遍反转顺序。前 12 题沿用上次评测，新增 6 题检验中英文限制、更正、话题切换及混合来源。部分新增题参与了首轮诊断，因此整组属于开发验证，不能称为独立留出集。

| 指标 | 上一版 Memory Graph | 修复候选 | 变化 |
| --- | ---: | ---: | ---: |
| 完整达标 | 29/36（80.6%） | 34/36（94.4%） | +13.9 个百分点 |
| 部分完成 | 7/36 | 2/36 | 剩余两条都是 OLL 全称未完整展开 |
| 评分 | 65/72 | 70/72 | 36 对：5 胜、31 平、0 负 |
| 请求错误 | 0 | 0 | 正常返回不等于任务完整完成 |
| 输入 token | 769,463 | 638,440 | 包含命中缓存的输入 |
| 输出 token | 6,200 | 4,011 | 包含推理、复核与重试 |
| 总 token | 775,663 | 642,451 | **−17.2%** |
| 模型调用 | 51 | 44 | −7 次 |
| 平均完成耗时 | 2.13 秒 | 1.64 秒 | **−23.0%** |
| 完成耗时中位数 | 1.37 秒 | 1.33 秒 | −2.6% |
| 完成耗时 P95 | 7.21 秒 | 4.13 秒 | −42.8% |

| 输入缓存命中率 | 94.4% | 98.5% | 缓存未受控，不能将全部加速归因于实现 |

36 对中候选有 21 对更快，配对完成耗时差中位数为 −108 毫秒。P95 用 nearest-rank，样本少，不是线上 SLA。供应商 usage 全部完整，正式轮没有资源快照缺失，没有剔除慢样本或部分完成的回答。

只看两版都完整达标的 29 对，总 token 减少 **3.6%**、平均完成耗时减少 **0.6%**，这一组 P95 反而从 3.47 秒升至 4.13 秒。排除 C11/C16 两类百科题后，总 token 减少 **3.4%**、平均耗时约 1.58 → 1.56 秒。因此，本轮主要修复了错误路径导致的慢响应，不能外推为所有问题明显提速。

首次答案时间为进程内第一个 `answer` 事件；没有流式正文时取最终返回时刻。本轮 8 条受时长约束的计划均在校验后一次展示，实际各只调用模型一次，未增加普遍的评委调用；其首字等待增加是防止先展示违规计划的取舍。它不同于供应商原始首 token 时间，也不包含浏览器渲染。

## 补测与版本边界

核心 72 条运行期间两版构建均冻结。随后只对 `site_assistant_memory.ts` 的时长解析做两项边界修正，未修改题库答案、模型提示词或检索链路：

1. 8 条嵌套列表对照：基线 3/4、修复后 4/4 完整达标；基线一次重复计时导致 `model_output_invalid`，修复后没有错误。中文例子同时暴露“每项”格式说明可能使总时长识别失效。
2. 4 条总额分句补测：前后各 2/2；最终候选在“总时长最多 6 分钟，给每项添加子项目”的要求下仍识别总额，父项和子项均正确。不把本次无错误结果说成另一次质量提升。
