# 抽奖

入口：网页 `/lucky-draw`（中文 `/zh/lucky-draw`），原生小程序 `pages/lucky-draw/index`。首页「工具」组统一从 `site_directory.ts` 提供入口。

## 能力与规则

- 一行一项，`#12 姓名` 保留编号；相同显示姓名仍是不同票，重复提示与去重需用户选择。
- 批量抽取最多 100 项；一批不重复，开启允许重复时仅在批次之间放回。默认抽过的票退出候选池。
- 三维卡牌与简洁展示、历史与剩余数、编辑、重开、名单耗尽禁用、本机持久化、命名名单、复制/导出。
- 三维展示采用集中悬浮的立体卡牌池，两端共用 `drawStageCards` 的位置、深度和倾角；最多展示 16 张候选卡，不限制实际抽取池。卡面保持可读，抽取时聚拢，完成后独立展示结果并淡化背景；动画期间历史不提前揭晓。减少动态效果时保留静态空间布局。
- 比赛搜索与报名导入复用 `cubing_source.ts` 缓存和公开已接受报名接口，含没有 WCA ID 的选手。先预览，再选择替换或追加；会清空进度的操作需确认。失败不覆盖旧名单。
- 盲拧模式：字母范围、同源参考词库、自定义 `KP = 联想词`、揭晓、主观会/不会、按最新评级筛选复习。参考词不作为判错依据。
- 网页和原生页共用 shared/draw 的规则与控制器，各自适配存储、网络、确认、复制和界面。存储不跨设备同步。网页使用 crypto 随机源，小程序使用运行时随机源；不提供公开可验证开奖证明。
- 原生文件分享 API 不可用时降级复制结果。网页提供文件下载。

网页比赛搜索复用 `CompPicker` 的搜索、清除、自动补全和比赛信息展示。`GET /v1/draw/competitions?picker=1` 提供完整粗饼候选目录（原始 alias、英中名称、地区、日期和项目），限定可导入来源，避免全球 WCA 目录与粗饼报名覆盖范围不一致。选中后沿用共享控制器的导入预览、替换与追加流程；原生小程序继续使用原有搜索接口。

本地验证：目录接口返回 1267 场，哈尔滨公开赛 2025 报名接口返回 180 人。浏览器通过临时请求拦截接入本地 handler 的真实响应，验证中英文搜索、原始 alias、导入预览和 390px 下拉不溢出；未发布到线上。
