## 本地修改

- 判罚先检查用户说的动作是否为规则的触发点。仅给出首次转动时间时，开头即说明无法直接判罚，再按实际开表时间给出条件结论。复用现有规则全文页识别与条款依赖读取，确保 A3 检视条款连同 A4 开表条款进入官方证据。[WCA A3b5 / A4d](https://www.worldcubeassociation.org/regulations/#A4d)
- DNF 统计接受 `count(attempt_number)` 与已有 `count(*)`、`count(value)` 的等价表达式：公开 attempts 视图使用 `WITH ORDINALITY`，序号非空；分子、分母仍必须使用正确的状态过滤。仍拒绝 DISTINCT、窗口、不明字段和错误分母。给模型统一的 FILTER 计算示例，要求数据库返回分子、分母及比例，保留身份、项目、年份与独立语义复核。
- 读取 analysis schema 前不向模型发送完整 analysis_query 结构；只生成最终答案或修复格式时不发送工具 schemas。保留工具执行侧的原校验。
- 对已读取但未说明某项能力的页面，优先回答“资料无法确认”，避免为证明不存在而重复导航和页面检索。此项最终效果尚未完成全套复测。
- 复测暴露 ao5/mo3 混淆，且提示词修正后仍出现 `42/3 = 13.50`。最终改为：对完整、明确秒数列表和单一 ao5/mo3 计算请求，直接复用 `@cuberoot/shared/timer/stats` 的计算与舍入，绕过模型、embedding 和数据库。缺单位、FMC、附加罚秒、多问题或存储成绩查询仍走原流程。没有修改共享统计引擎，也没有为固定题目写死答案。

最终计算路径通过 17 项单元及集成检查；冻结 bundle 的原题冒烟返回 **14.00 秒，0 次外部读取，8 ms**。这是本地程序检查，不是最终真实模型全套对照。
