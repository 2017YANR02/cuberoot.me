# 产品使用分析

## 查看与范围

管理入口：`/admin/product-analytics`（中文 `/zh/admin/product-analytics`），位于后台侧栏「产品使用分析」。仅管理员可读，接口独立校验权限，响应 `private, no-store`。可选择最近 7 / 14 / 28 / 30 天和公开用户、登录用户、匿名会话、管理员；默认排除管理员。页面支持数量或比例排序、每页 50 行、手动刷新，以及加载失败、无数据和结果上限提示。

默认统计正式域名的 Web 活动，包括匿名访客和登录用户；不再按主动授权筛选。不代表全站 HTTP 请求量或精确 UV。不启用 Vercel Analytics，不恢复已退役的 `pageviews` / `traffic_daily`，也不混入 nginx 请求日志。部署后才能开始积累这套数据，不能补出历史曝光与点击。

## 默认采集与身份

- 不再提供全站分析授权开关，也不请求 status / consent；旧的浏览器选择和授权记录不影响默认采集。不会伪造用户授权：新事件的 consent_id 留空。
- 登录用户事件关联账号，用于跨日使用频率；匿名访客使用标签页内的随机短期会话，30 分钟无活动后换新。服务端仅保存主体标识的 SHA-256；匿名会话数不等于人数。
- 切换账号丢弃旧身份队列，避免事件串号。登录凭据尚未刷新时暂存队列，不降级成匿名，不主动触发登录续期；正常刷新后继续发送。
- 只在 cuberoot.me / www.cuberoot.me 顶层页面采集；排除开发/预览域名、iframe、角色预览，并尊重 DNT / GPC。NEXT_PUBLIC_PRODUCT_ANALYTICS_DEV=1 仅用于隔离验证，不能在日常开发中开启。

## 事件口径

| 事件 | 含义 |
| --- | --- |
| `web.page_view` | 进入页面；查询参数变化不算新访问。复用页面目录保留已知静态子页，动态段使用模板，未知细节归并为 `:detail` / `/other`。 |
| `web.page_engaged` | 页面累计可见 30 秒，且有真实键盘、指针或滚动交互；不是功能成功事件。 |
| `web.entry_impression` | 首页/首页搜索的已登记入口至少 50% 可见且连续 1 秒；主动点击也证明曝光。按页面访问、入口、位置去重。 |
| `web.entry_click` | 同一入口位置在该次页面访问内首次真实点击；包含中键点击，但跨标签页不建立使用归因。 |
| `web.feature_interaction` | 页面 main 内容区内的真实指针或键盘交互，每次页面访问最多一次；不包含导航、全局页头/页脚，不等于操作成功。 |
| `web.feature_use` | 已接入的核心操作，每个操作类型在一次页面访问内最多一次；不是原始操作次数。 |

首批功能操作：

| 操作 | 当前接入点 / 边界 |
| --- | --- |
| `timer_solve` | Web 单人计时保存一次成绩；竞赛专用分支和其他计时模式未接入。 |
| `scramble_generate` | 打乱生成页主动点击重新生成并成功获得结果；首屏自动生成不计。 |
| `solver_result` | 共享批量求解面板获得结果；自动单条计算未接入。 |
| `sim_move` | 模拟器的用户操作进入公式输入记录。 |
| `alg_play` | 公式库中的播放/重播；自动播放不计。 |
| `recon_play` | NxN/镜面复盘播放器主动播放；其他异形播放器未接入。 |

首页管理员入口、编辑状态、禁用入口不纳入曝光。搜索仅统计目录中的功能入口，不采集搜索词或个人结果。私密管理、账号、聊天、文档等路由不采集页面事件。站外和上游 iframe 内部操作不在这套覆盖范围内；低计数不等于低价值。

事件只接受共享白名单中的页面、功能、语言、屏幕分类、操作类型和入口位置；不存输入、完整 URL、查询参数、referrer、IP 或 User-Agent。页面访问和来源访问使用随机 ID，入口布局版本固定为 `home-2026-11-03`；调整首页编排时更新版本以便分组比较。

## 报表指标

- 默认展示功能总览：按功能跨页面、语言、屏幕聚合 PV 与去重访问会话、交互会话、已接入的完成操作会话。匿名访客包含在其中。交互率 = 交互会话 / 访问会话；未接入完成事件的功能显示「—」，不伪装为零。

- 页面：PV、会话数、有效阅读会话数、使用会话数；使用率 = 使用会话 / 访问会话。页面统计保留屏幕和语言维度。
- 入口：曝光、点击、CTR = 点击 / 曝光，以及使用转化。使用必须属于同一会话，并匹配来源页面访问、入口位置、对应功能，发生在点击后 30 分钟内；同一点击最多计一次转化。
- 频率：仅对执行过功能操作的登录账号，按 UTC 统计人均活跃天数、人均使用会话。匿名人群不提供此指标。
- `subjects` 是登录账号与匿名会话的混合去重单位，不是 UV；管理页不把它显示为人数。未接入功能操作的项目显示「—」，不把缺少埋点显示为零使用。
- 报表最多返回 1,000 行页面维度和 1,000 行入口维度；达到上限会提示缩小范围。事件过期后立即从报表排除，清理任务每分钟最多删除 5,000 条过期事件。

## 与核心功能隔离

核心功能只导入 `lib/analytics-signal.ts` 的轻量信号桥；同步路径仅做内存去重和调度，不生成 ID、不读写存储、不调用网络，也不等待 Promise。事件在浏览器空闲回调（最长延迟约 2 秒，降级为定时任务）中整理，回调和信号桥均隔离异常；延迟回调保留操作发生时的页面和时间；导航后仍归入原页面，离站发送前整理尚未执行的回调。

自动统计只使用已有的内存访问令牌，不发起或等待业务登录续期；正常登录刷新完成后继续发送。首页卡片的 DOM 观察器不挂到计时、求解和播放页面，键盘/指针事件更新活动标记，并在公开页面内容区记录每次访问至多一次的交互事件，不读取输入值。

浏览器每 10 秒触发批量上报，成功后连续排空剩余批次；离站时延续 keepalive 标记，单批最多 20 条，内存队列最多 200 条，无磁盘事件队列。请求低优先级、8 秒超时、最多两次延迟重试，重试复用 UUID；后端按 UUID 去重。页面离开时只做尽力发送，不阻止导航。统计失败不弹提示、不修改工具状态，优先丢失统计而不是阻塞用户操作。

服务端使用 `platform_analytics_events`，默认采集不读写授权表；migration `0309` 仅添加查询索引。采集同进程并发上限 2，超额返回 503；写入事务语句最长 2 秒、锁等待最长 250 ms。报表同进程最多一个、使用一个只读连接、每条语句最长 2 秒。无需 Redis、独立消息队列或新增收费分析服务。

## API 与维护

| 方法与路径 | 用途 |
| --- | --- |
| `POST /v1/platform/analytics/events` | 批量事件；正文 `subjectToken, sessionId, events`，最多 24 KiB。 |
| `GET /v1/platform/admin/product-analytics?days=28&audience=public` | 管理员聚合报表；不返回账号 ID、会话 ID 或原始事件。 |

事件、页面和报表契约在 `core/packages/shared/src/product_analytics.ts`。页面标题/搜索/统计复用 `page_catalog.ts`，功能 ID 复用 `site_directory.ts`。新增核心操作时扩展动作白名单，并在业务成功后的宿主层发轻量信号；不要在动画帧、转动流或算法循环中上报，不给共享播放器引入 Web 后端依赖。

验证包含浏览器采集边界、异常与超时隔离、账号切换、真实 PostgreSQL 中的无授权默认入库/去重/交互与完成事件独立聚合/过期清理，以及管理页权限和状态展示。浏览器报表验证使用隔离的模拟数据，不代表线上真实使用数据。
