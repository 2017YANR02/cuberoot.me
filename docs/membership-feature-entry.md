# 会员功能入口与支付回跳

Web 会员功能在用户主动操作时调用 `useRequireMembership(hasAccess)`（`core/packages/client/hooks/useRequireMembership.ts`）。返回 `true` 才继续功能操作；返回 `false` 表示已导航到登录或会员页，调用方立即退出。不再各自拼登录链接或增加会员提示条。

- 未登录：账号页的 `next` 指向带来源的会员页；登录后由会员页读取服务端权益，已是会员直接返回来源，否则留在会员页开通。
- 已登录无权益：直接去会员页。
- 已有权益：当前页面继续操作。
- 来源保留 pathname、query、hash；会员页通过 `membership-return.ts` 校验同站目标并禁止账号／会员页面回环。
- 外部支付服务使用固定回调 URL；来源在当前标签的 sessionStorage 中按账号保存两小时，消费后清除。浏览器禁用存储时，同页支付仍可使用 URL 中的来源，外部支付回调可能停留会员页。
- 订单支付成功会重新查询会员权益；只有服务端确认权益生效才回跳。重新聚焦会员页也查询，支持外部签约应用返回。取消、失败和仅完成签约不等于获得会员权益。

模拟器自定义 logo 是首个接入点。返回模拟器后用户再次选择自定义以打开系统文件选择器（浏览器需要真实点击，不能在支付回跳后自动打开）。原页面已有本地设置继续保留。

这是会员权益准入，不是所有商品付款的统一授权判断。未来单次购买商品可复用安全返回地址约定，但必须由其订单与权益接口确认成功，不能用会员状态替代商品支付状态。

## 已接入的功能

模拟器自定义 logo、音乐上传／下载及上传管理、图库照片上传、复盘视频上传、老师关系登记与添加学生、私密资料库的新建与管理入口均使用同一会员准入 Hook。公开浏览、资料库接收分享／查看／导出、既有关系的撤销，以及管理员专属操作仍遵循各自原有权限。

复盘在离开前将当前表单及成绩输入暂存到当前标签 sessionStorage，按账号和完整页面路径匹配，两小时内返回恢复并删除暂存；保存失败时留在原页面。私密资料库不暂存解密内容或密钥，返回后需要重新解锁。
