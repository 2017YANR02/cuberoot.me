# 网站主导航与子页面接入

状态：ACTIVE。2026-11-16，按维护者要求先分析子页面，再落地首页与栏目汇总。导航为首页、训练、工具、学习、社区与探索、仅管理员可见的管理栏目。

## 本轮边界

首页保留论坛之前的内容；论坛预览、四个目录板块、会员名单和管理员目录移入对应栏目内容。入口数据、权限与排序继续共用现有目录。按维护者后续明确要求，各栏目在首页内切换，地址始终保持 `/zh` 或 `/`，不新增路径或查询参数。现有卡片的子页面 URL 完全保留。栏目状态仅在当前浏览器运行期保留，进入子页面后返回可恢复；刷新默认首页，身份变化清理状态。此用户要求是页内状态默认使用 nuqs 规则的当次例外。

桌面导航占用现有品牌与账号所在的头部；移动端使用左侧抽屉。普通用户快捷入口只保留会员、日历、账号；管理员额外保留顶部编辑、商店、下载。窄屏按钮组靠内容右沿，320px 管理员头部隐藏品牌图标以容纳全部操作，首页仍可从抽屉进入。AI 输入框只在首页展示，保留 landing.css 的窗口底部定位和原有安全间距；切换栏目保留草稿。栏目标题与论坛／会员分组标题区分层级。页脚短页贴底、长页跟随内容，不固定覆盖视口。管理员导航及其目录内容均检查权限，不只隐藏菜单。目录锁定依旧是入口展示规则，不替代目的页与 API 鉴权。

## 子页面审计与接入决策

扫描了 `core/packages/client/app/[lang]` 下全部 387 个 `page.tsx`（含动态模板、历史入口，不等于线上 URL 数量）。同目录 TSX/CSS 检索有 24 个页面出现视口高度、60 个出现 fixed、41 个出现 sticky、113 个出现共享返回组件、5 个出现导航壳。命中可能来自弹窗或相邻组件，数量仅为风险筛选，不代表逐页视觉验收；未命中也不能证明安全。机器清单保存在本机 `.local-data/site-navigation-20261116/routes.json`。

| 页面族与源码入口 | 布局风险 | 接入方式与当前决定 |
| --- | --- | --- |
| 首页、新栏目汇总 | 首页品牌与账号原为 absolute；通知条存在额外 top 偏移 | 同次替换为正常文档流头部，接入新导航；不沿用旧绝对定位补丁 |
| 普通内容／列表：about、careers、wiki、regulation、math、WCA 列表、论坛阅读等 | 自有标题、返回箭头、正文宽度与吸顶表头；需区别顶层页与详情页 | 候选为正常流头部；保留返回来源语义。需逐族确认标题密度与滚动，再接入，当前不统一注入 |
| 教程：tutorial、tutorial-legacy；公式 alg | 教程目录、移动菜单、练习运行页并存；同前缀不是同一种布局 | 阅读页和训练页分别适配，不能按整个前缀直接套壳 |
| frame-count/frame-count.css | 根节点 `height:100dvh`、`overflow:hidden`，视频与控制区瓜分剩余高度 | 将全局入口并入现有 fc-header 或重算可用高度；当前保留专用布局 |
| calendar/calendar.css | 根节点 `height:100dvh`；移动端还有 fixed 定位 | 合并 cal-topbar，检查日／周／月视图与移动抽屉；当前不叠加头部 |
| paint/paint.css | 根节点 fixed/inset:0，仅为 page-notice-h 留位 | 新流式头部会被画板盖住；应并入画板顶栏或集中处理视口偏移 |
| sheets/edit/spreadsheet.css、docs 编辑器 | 视口工作台、内部滚动、表头与工具栏 | 保留编辑器空间，使用已有菜单接入；当前不叠加 |
| timer、sim、训练 run、comp-sim | 操作键、专注／全屏、设备与高度适配；sim/embed 是外部嵌入 | 默认保持专用布局；embed 禁止显示网站导航和页脚 |
| contact、workspace 类工作台、account、admin、platform、org | 已有 NavigationShell 或业务导航；额外一层会重复导航或影响侧栏高度 | 复用现有壳的入口与高度合同，先确定全局与局部导航职责 |
| music、space、gallery、meet | 沉浸模式、媒体画布或通信操作；状态间布局差异大 | 普通浏览与沉浸状态分别处理，不按前缀粗放接入 |
| cstimer、blddb、solver、alg-trainers | 上游 iframe／静态工具有独立布局 | 仅可改本站包装层，不改上游；当前保留 |
| 认证回调、分享、支付续程、静态资源 | 有专门跳转、嵌入或协议语义 | 不注入全站壳 |

结论：当前没有足够证据支持在语言 layout 一次性插入全站头部。本轮仅首页和新栏目接入；其他子页面保留现状。后续按上述布局族推进，先确认宿主、可用高度和返回路径，再验桌面、窄屏、长标题、深浅主题、通知条及全屏。不以源码扫描代替浏览器验收。

## 实现原则

共享目录与排序仍由 `lib/landing-sections.tsx`、`lib/home-layout.ts` 及服务端快照负责。导航菜单复用 `@app-foundation/navigation-ui`，业务标签与权限属于 Web。不新增路由、metadata 或重定向；保留首页原有静态 metadata 与 ISR。
