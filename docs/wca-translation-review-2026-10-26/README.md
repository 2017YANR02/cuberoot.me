# 2026-10-26 全量译文校正

范围为 639 份唯一译文：451 篇公告、144 条意外事件、44 篇纪律公告。公告列表中的 44 篇纪律公告复用日志真源，不重复维护。另核对 4 篇专题文章及 1 篇归档论坛补充全文。

## 证据与节省重复工作

- `baseline.json` 固定本轮来源与输入译文哈希，保留每日新增公告。
- `posts-a/` 和 `posts-b/` 是 451 篇公告的逐篇全文英中对照结论。相同模板复用固定段落判断，逐篇核对变动字段。
- `logs/` 对 138 条相同哈希的既有独立审校保留证据；37 条术语修改核对全部差异及原文上下文；13 条原文疑点全文复查并重新读取官方来源。各条记录明确实际范围，不把复用说成重新全文审校。
- 修改稿再由另一位审校者核对，`cross-rechecks-posts.json` 与 `correction-rechecks-logs.json` 绑定修正后的标题和正文哈希。`curated-recheck.json` 绑定专题组件版本。
- `event-name-sources.json` 保存本次官方术语命中及同步版本。官方项目词使用斜转、五魔方、金字塔、魔表；Square-1/SQ1 保留官方和本站既有名称；比赛专名不机械翻译。
- `final-report.json` 绑定集成后的每篇译文哈希。pass 指译文忠实性；`sourceConcern` 单独保留原文自身的数字、日期、编号或措辞疑点，不代表原文事实已确认。外链报告、附件不属于本轮扩展翻译范围。

## 集成与验证

`apply.mts` 默认只检查；`--apply` 需全部审校齐备、输入未变化、所有修正均有另一位审校者的通过记录，才归档旧版本并更新真源和账本。普通公告的审校状态属于既有译文哈希对象，状态更新也产生新版本；不等于每篇正文都改写。该脚本不提交或发布。

集成后运行两份原账本校验器，再按顺序执行 `build-wca-logs.mts`、`build-wca-posts.mts`，最后运行本目录 `verify.mts`。后者核对最终审校绑定、项目名、公告列表/正文和复用纪律文章的一致性；它不代替语义审校。

后续只复核发生变化的来源/译文及必要上下文，不重复审阅整个历史语料。任何新变更均使旧哈希上的审校失效；保留原文、历史版本、来源疑点和检查点。
