# CubeRoot 商业计划书

唯一对外入口：中文 `/zh/partnership`，英文 `/partnership`。原 `/overview` 路由已合并移除，不加旧址跳转。页面可由链接阅读，noindex、排除 sitemap；noindex 不代表访问控制。现有会谈准备页 `/partnership/talking-points` 保留作为单独准备资料，不从对外 BP 链接。首页卡片原有显示设置本轮未修改。

## 内容结构

摘要与目录后为完整章节：行业与高频需求、竞品、优势与壁垒、产品与已有使用、创始人/团队/主体、个人与企业订阅、客户与市场切入、获客/转化/续费、阶段规划、技术与服务交付、经营指标、收入与财务模型、成本与资金用途、风险、合作安排与资料来源。

内容支持中英双语、手机阅读和浏览器打印/PDF。财务部分提供单位经济、订阅周期、现金与收入区别、情景和资金缺口计算逻辑；没有虚构收入预测或市场规模。

## 本轮用户确认（2026-10-02）

- 自媒体平台合计约 50 万关注，未跨平台去重，不当作网站用户或付费人数。
- 经本人介绍已有选手使用网站、计时器及训练器中的多项功能；按本轮要求不展开姓名、推荐或具体选手案例。
- 方向是个人订阅与企业订阅，日常训练带来反复使用场景。
- 从个人独立推进转为约 3 人固定团队：创始人加合作伙伴侧投入的两位成员。伙伴整体约 10 人，但不能计为 CubeRoot 团队人数。
- 当前全职投入，已有个人独资主体，计划调整为新的有限公司或科技公司；名称、主体调整与人员职责不写成已完成事实。
- 已有真实付费会员；微信支付与部分资质审核尚在推进，会员尚未正式全面开放。目标在两个月内推进规模化订阅，明确审核、支付与交付条件，不保证审批时间或订阅结果。
- 当前诉求沿用直接项目资助、非借贷，未来股权另谈。本轮不公布任何资金或价格金额。成本类别与设备仍展示，金额不展示。

## 公开证据与复用

- `/membership` 及公开 `GET https://api.cuberoot.me/v1/membership/plans`：本轮读取到个人 monthly/yearly、enterprise_monthly/enterprise_yearly。会员页仍标注测试状态与自动续费未开放；API `payEnabled` 为 true 不代表微信及全部资质完成，不进行真实下单。
- `lib/membership-perks.ts`：从原会员页提取原文，供会员页与 BP 共用。个人包含云端求解、高手复盘，会员页另有个人视频复盘；企业增加师生展示、企业页、资料存储和课程方案。提取未改会员支付逻辑、价格、权益或额度。
- `/about/ruimin`：南开数学/金融数学与物理、乔治华盛顿数学硕士、数学竞赛获奖、2017 年起参赛、著作与内容积累。没有读取私有访谈。
- `/achievements` 与现有工具入口：原创求解、交互、复盘、统计；开源和数据边界链接 `/about`。
- `lib/infrastructure-costs.ts`：成本类别与用途、设备名称复用原清单，本页不渲染价格、总额或汇率；设备记录不等同于本项目累计实付，不重复列为新采购。
- `docs/teaching-saas-plan.md`、`docs/mobile-app-roadmap.md`：只用于核对研发基础与未来方向，不把文档中的本地实现直接说成已完成机构商用或所有端发布。

## 经营计划边界

现有使用与付费为经营起点，不再采用未确认的“3 个专题、30 人试用、3 位老师访谈”作为固定目标。阶段计划围绕上线条件、服务交付、推广、续费与机构服务展开。月度/季度报告区分访问、练习、付费、续费、服务完成和现金支出；永久权益若存在则与周期订阅收入分别核算。

新增权益与服务改进明确为建议，正式权益以会员页实际发布为准。人工复盘/课程定制需要容量与质量管理；新功能要核算成本，不能擅自收缩已发布权益。本轮没有修改会员产品定价或对外权益承诺。
