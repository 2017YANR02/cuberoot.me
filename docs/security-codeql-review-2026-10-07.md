## Remaining boundaries

- The payment adapter keeps the provider-mandated legacy signature described in #89. It is a compatibility exception, not a cryptographic fix.
- Trusted generated worker runtimes (#62–69), local timer grouping identifiers (#55–61), and fixed numeric array rotations (#75–86) were reviewed for actual input paths. Their reasons are specific to current call sites and must be reconsidered if exposed to arbitrary messages/keys.
- HttpOnly cookies reduce persistent credential theft from JavaScript storage. They do not make same-origin script execution harmless: an injected script could still act as the user while it runs. The parser-based HTML fix and server authorization remain necessary.
- The browser short token is barred from authentication mutation/ticket minting; same-origin account operations use the matched HttpOnly-session bridge. Native durable-bearer behavior remains unchanged.
- The user's unrelated homepage/recon work was not changed. Final commit, push, deployment and new CodeQL results must be recorded by the coordinating task.
