# 聊天助手的回答与工具设计

核对时间：2026-10-23。实现入口为 `core/apps/api/src/utils/site_assistant.ts`，工具输入契约在 `site_assistant_tools.ts`，模型适配在 `site_assistant_model.ts`。本页描述设计与能力边界，不以文档替代线上配置或实测。

## 采用的通用架构

同一个对话模型负责理解问题，并按需要选择直接回答、站内检索、结构化数据工具或联网搜索。解释、翻译、写作、一般交流不必先查知识库。网站入口、用户成绩、最新事件等外部事实必须通过对应工具取证。工具能力以可复用的数据操作定义，避免为每种问法添加分支。

RAG 是获取站内资料的一种工具。数据查询承担筛选、去重、聚合和计算；联网搜索负责公开站外信息。工具输出保留来源与范围，空结果、失败和缺少资料分别处理。对话历史用于理解追问，身份由认证上下文提供，不根据模型猜测用户身份。用户停止、时限、调用次数与成本预算贯穿整个请求。

## 思考、上下文与交互

| 用户选择 | 调用策略 | 总请求时限 |
| --- | --- | --- |
| 自动（默认） | 首轮快速；模型选择深入推理、结构化分析、联网证据综合，或回答进入核验/修复时启用思考 | 60 秒 |
| 快速 | 保持非思考请求；需要真实数据时仍调用工具 | 30 秒 |
| 深入 | 支持该能力的供应商从首轮启用思考 | 90 秒 |

模式偏好保存在当前浏览器。主对话与首页入口使用同一配置；监控区分用户选择和每轮实际调用参数。DeepSeek 与受支持的百炼 Qwen3.8 配置分别适配；未知兼容供应商不假装启用思考。思考过程不作为正文或监控内容展示。自动模式由实际工作触发，而非按一串问句关键词硬分流。

SSE 每 15 秒发送一次不可见的协议保活注释，避免深入思考期间没有正文而触发代理空闲断开；完成、失败或取消时清理。保活不会重置请求时限，也不会被算成首段回答。

历史按真实的用户/助手角色顺序传递，最多保留最近 10 条消息和 40,000 字符；移除最旧的完整消息并避免从孤立助手消息开始。问题最多 8,000 字符，单次回答最多 12,000 字符。超长写作给出有实质内容、自然结束的第一部分，明确剩余内容，由用户继续触发下一段；不通过截断 JSON 伪造成功。已有图片、停止、编辑重问、重新生成和评价能力继续复用，旧图片超出上下文预算时明确标记省略。

客户端按最终 JSON 的 UTF-8 字节数控制 3,300,000 字节请求预算。超限先移除旧历史，不改写本轮问题和图片；仍超限则发送前明确报错。兼容旧服务的重试只在 `400 invalid_question` 且未进入付费调用时移除新增字段；已接受的请求不会隐式重发。

实际网站行为必须读取页面内容，导航目录只证明目标入口存在。尚未取证的站内解释不会先流式展示。来源由数据适配器提供，模型只能选择来源 ID；无效来源不会回退成“引用全部已读资料”。对话、检索、失败、用量及搜索费用继续写入现有管理员监控，详见 [监控口径](assistant-monitoring.md)。

## 官方实现对照

| 产品或框架 | 官方文档核实的机制 | 在 CubeRoot 中的取舍 |
| --- | --- | --- |
| OpenAI | 网络搜索作为工具，返回独立搜索调用与 URL 引用注释；展示结果时要求引用可点击。[文档](https://developers.openai.com/api/docs/guides/tools-web-search) | 按需搜索；来源由工具元数据产生，模型只选择来源 ID。 |
| Anthropic Claude | 模型按时效性需要决定搜索；来源含 URL、标题等；工具错误可能在 HTTP 200 的响应体中返回。[文档](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-search-tool) | 检查结构化结果而非只检查 HTTP 成功；限制工具预算。 |
| Google Gemini | Google Search grounding 返回搜索与引用映射元数据，支持可核查来源。[文档](https://ai.google.dev/gemini-api/docs/generate-content/google-search) | 区分模型叙述和真正获得的检索证据；日期未知时不补造。 |
| Vercel AI SDK | 工具使用输入 schema，支持多步工具循环、停止条件和工具错误处理。[文档](https://ai-sdk.dev/docs/ai-sdk-core/tools-and-tool-calling) | 复用已安装的 SDK 与单一 Zod 工具契约，不更换框架；调用循环保留有限步数。 |
| 阿里云百炼 / Qwen | 原生 DashScope 可返回 `search_info.search_results`；OpenAI 兼容聊天接口不返回此来源列表。Qwen3.8 需多模态原生接口与流式搜索。[文档](https://help.aliyun.com/zh/model-studio/web-search/) | 复用已有百炼凭据，以单独的原生搜索适配器保存来源；未返回来源时明确不可用。 |
| Perplexity | 独立 Search API 提供搜索结果，并支持查询、来源、语言与检索内容预算控制。[文档](https://docs.perplexity.ai/docs/search/quickstart) | 保留独立搜索工具边界，但当前不新增服务账号、订阅或依赖。 |

这些是具体接口机制的对照，并不表示各产品采用完全相同的内部实现。CubeRoot 的单一工具循环与预算选择，是基于上述机制和现有站点架构作出的工程判断。

## 联网搜索适配器

`site_assistant_web.ts` 仅调用固定受信的百炼北京端点，使用 `qwen3.8-flash` 的原生 `multimodal-generation` SSE 协议。发送短公开查询，不发送账号资料、完整聊天历史、图片或站内私有数据；明显凭据、邮箱、电话号码、图片数据及私有 URL 在请求前拒绝。当前账号标识与上下文中可识别的凭据只用于服务端拒绝列表，不发送给搜索供应商。该检查是有限的模式保护，不能宣称能识别所有自然语言中的私密信息。网页内容作为不可信数据处理，不具有操作指令权限。

一次搜索最多等待 16 秒、读取 512 KB、生成 1,200 tokens、保留 6 个有实际引用的安全 HTTPS 来源。请求同时受整个聊天的取消与截止时间约束；不抓取模型提供的任意 URL，不跟随带凭据请求的重定向，不自动重试付费搜索。来源必须同时存在于供应商 `search_info` 和引用标记中，不能用模型编造的 URL 充当来源。未引用的段落、引用不安全或已被裁剪来源的段落会丢弃，随后清除未再使用的来源。另要求供应商返回结构化的相关性判断：没有直接匹配问题的证据时丢弃综述和来源，不用其他话题填充；这个判断仍由模型完成，不等同于独立事实核查。

百炼此接口返回的是搜索来源元数据与模型整理的带引用综述，不是逐条原始网页片段。出版日期和原文片段没有结构化返回时保存为 `null`；检索时间不能冒充发布时间。Qwen3.8 的 `recency` 是搜索偏好，不是强制日期过滤。需要确定某周的 WCA 官方公告时，已有官方 RSS 工具可按真实发布时间筛选；广泛新闻检索不得把日期不明的旧闻标成当周消息。

配置默认复用完整的 `SITE_ASSISTANT_VISION_API_KEY` / `SITE_ASSISTANT_VISION_BASE_URL` 或 `SITE_ASSISTANT_API_KEY` / `SITE_ASSISTANT_BASE_URL` 百炼组合。可用 `SITE_ASSISTANT_WEB_API_KEY` / `SITE_ASSISTANT_WEB_BASE_URL` 显式指定；`SITE_ASSISTANT_WEB_MODEL` 选择适配器支持的 Qwen 多模态模型；`SITE_ASSISTANT_WEB_ENABLED=0` 禁用。配置、模型权限、来源返回中的任何一项不满足时，返回明确的不可用结果，不把内部配置或供应商错误正文暴露给用户。

模型 tokens 与搜索调用分别记账。百炼北京 turbo 检索的文档标价为每千次 3 元，另计模型 tokens；`usage.plugins.search.count` 是搜索意图次数，不代表结算次数，故只能用于保守费用估算，正式费用以账单为准。该事实与接口边界来自上述百炼官方文档，变更供应商或策略时需重新核对。

## 持续验证边界

回归覆盖一般聊天、连续追问、工具选择、站内导航、原始数据计算、搜索来源真实性、失败与取消、输入隐私及成本记录。模型每次输出并不完全确定，有限回归通过不等于所有问题都能回答；模型或供应商配置升级后，应运行相同任务集并结合已有问答监控里的失败、耗时、费用、差评和复核结果持续改进。

2026-10-23 使用既有服务器百炼配置执行了小型真实供应商验证，没有重启或部署服务。以下是单次接口耗时，不是性能分布或服务等级承诺：

| 查询 | 耗时 | 实际返回与边界 |
| --- | --- | --- |
| `TypeScript latest stable release official` | 10,839 ms | 返回 Microsoft TypeScript 博客等相关来源，但综述混合了正式发布、RC 与旧版本资料，出现日期矛盾。不能把来源存在当成结论正确。 |
| `今天上海浦东天气预报` | 8,706 ms | 返回中国天气网浦东预报等相关来源；该测试确认中文公开检索与引用链路，不代表独立核验了每个天气数值。 |
| 英文发布查询在收紧综述后复查 | 3,021 ms | 仍得到相关官方元数据；供应商仍未完全消除日期矛盾。主模型必须核对综述内部一致性、来源权威性，冲突时保留不确定性。 |

这组结果确认通用搜索已接通，也暴露了供应商综述的事实质量边界。当前没有逐页原文读取，因此不把生成综述伪装成原始网页片段或独立核查结论。检索结果不足、缺少引用与明确不相关时分别返回可识别的不可用原因。
