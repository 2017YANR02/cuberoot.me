## 验证方式

- 前端：可控延迟的请求回包、账号切换、画稿切换、首次创建、保存队列、学习标记重置与上传；另解 API 原始版本传输与冲突反馈。
- 后端：临时 PostgreSQL 中的真实并发事务，通过 `pg_stat_activity` 确认请求等待锁，再释放锁并检查最终数据；新迁移也在该临时数据库应用。
- 文件发布：仅临时目录与离线命令替身，检查交错上传、过期基线、重试、符号链接与哈希冲突。没有执行真实统计计算或生产发布。
- 缓存清理：临时缓存树验证文件范围、真实权限失败、目录/父级符号链接、缺失路径和独立并发写入进程；未对生产缓存执行清理。
- 类型与结构：Client/API typecheck、架构边界守卫、workflow 路径与队列契约、变更工作流语法检查。

后端 8 个目标测试文件共 72 项通过，其中 22 项为真实 PG 回归；前端保存/会话/学习标记的 5 个文件共 40 项通过。运维两份工作流的 14 个 run 块和 11 个远端 heredoc 均通过 Bash 语法检查，8 项隔离目录场景验证了范围限制、缺失目录、已有目录创建失败和非法前缀拒绝。
