## 两个问题及已有修复

### 普通微信网页被误判为小程序

原 `isMiniProgramCommerceRestricted()` 直接采用 `mayUseMiniProgramBridge()`，把包含 `MicroMessenger` 的普通微信浏览器也认作小程序，导致会员页显示「小程序内暂不提供会员购买服务」。

提交 `6b616c865b`：明确小程序标识直接判断；没有标识的候选环境通过既有 SDK `miniProgram.getEnv` 核实。会员页、账号页和平台订单页等待判断完成再展示相关购买入口。普通微信网页恢复网站购买界面；已确认的小程序仍保留限制。登录、账号绑定和会话流程不变，账号流程说明已同步。

### 微信内打开 H5 收银台报错

微信官方 H5 支付面向微信客户端外的手机浏览器。在微信内打开 H5 支付链接会提示「请在微信外打开订单，进行支付」。这与小程序识别问题是两个独立问题，开启 H5 配置不能让它变成微信内 JSAPI 支付。

提交 `dcffb94df7`：会员支付弹窗在移动端微信浏览器内显示「在浏览器打开」指引和复制会员页链接按钮，不创建无法使用的 H5 订单。复制链接保留当前站点和语言，不携带支付查询参数或凭据；失败会提示。外部手机浏览器的 H5 和电脑端 Native 扫码入口保留。

**该修复提供外部浏览器付款路径，尚未实现微信网页内直接调起付款面板。**用户希望的最终体验仍是会员页点击微信支付后直接出现微信付款面板。

## 微信内直接付款的可选路线

### 自有公众号 + 直连 JSAPI

对普通经营主体，通常准备已认证服务号。官方还支持符合要求的政府或媒体类型公众号；不能据此认为普通个人订阅号也具备相同权限。

1. 注册或复用符合条件的公众号，完成认证和网页授权能力核对。
2. 将公众号 AppID 与现有商户号关联，并在公众号后台确认授权绑定。
3. 配置公众号网页授权域名、商户 JSAPI 支付授权目录，部署域名校验文件。实际生产域名、`www` 与开发域名按使用场景分别核对，不默认主域配置覆盖所有子域名。
4. 实现公众号网页授权，取得对应 AppID 下的付款人 OpenID；不以此替换或误绑定现有 CubeRoot 登录账号。
5. 服务端创建 JSAPI 订单并签名，网页通过 `WeixinJSBridge` 调起付款；仍由已验签的服务端支付结果核对订单、金额及商户后开通会员，不能把前端回调当作到账证明。

已有商户号、小程序和 H5 能力可以保留。网页 JSAPI 需要新增适配，不能简单把 H5 URL 或小程序参数换个名称使用。

### 服务商网页收银台

微信官方服务商模式支持使用服务商的 `sp_appid` 和 `sp_openid`，子商户 `sub_appid` 并非所有场景都必填。因此不一定要商家自己持有服务号，但前提是服务商确实提供该网页场景、完成商户接入及授权，并支持本业务。

不能把「有聚合支付 API」直接等同于「可免自有服务号，在微信内完成网站会员购买」。尚未选定或签约任何服务商，也没有取得针对 CubeRoot 的可执行报价。

网站跳转小程序付款是另一种产品流程，不等于当前网页直接调起付款；会员销售是否能在小程序开展，还需单独核对类目、审核和平台规则。本轮不据此解除现有小程序会员购买限制。

## 费用与本轮建议

| 项目 | 自有服务号直连 | 服务商收银台 |
| --- | --- | --- |
| 固定费用 | 通常先按公众号认证 **300 元/年**预算；这是参考预算，最终以该主体的官方认证收费页为准。 | 可能有开通、年费、套餐或其他技术服务费；没有统一报价。 |
| 交易费用 | 微信官方公众号支付指引给出一般 **0.6%～1%**，按经营类目和实际签约费率执行；未核对本商户的真实费率。 | 按具体合同确认总费率，以及报价是否已包含微信通道费，不能默认重复相加或必然更便宜。 |
| 开发与维护 | 网站自己维护授权、支付和回调；现有支付后端可复用部分基础。 | 仍需接订单、回调、查单及退款，并维护服务商集成。 |
| 控制与依赖 | 自己掌握公众号、商户关联和接口流程。 | 依赖服务商接口、服务条款和后续收费。 |

仅用于量级估算：年微信收款 10,000 元，按 0.6%～1% 为 60～100 元交易费，加上 300 元认证预算约为 **360～400 元/年**。不含开发维护、服务器等费用，不是本商户的核定价格。

本轮建议：CubeRoot 已有商户号和自有后端，长期优先考虑自有认证服务号直连；若主要诉求是不自行注册和维护服务号，再询价服务商。此建议不是用户已作出的采购决定。

服务商询价需要明确：没有自有服务号、网站会员商品、微信内网页直接付款，以及开通费/年费/总交易费率/退款费用/结算周期/是否需要新商户或重新进件。没有报价前不承诺价格或接入时间。
