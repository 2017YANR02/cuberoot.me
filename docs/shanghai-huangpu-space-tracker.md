# 上海黄浦江双岸场景跟踪

更新：2026-09-07。状态：真实河道与双岸建筑底模已接入本地 `/space`，可以沿江连续巡游，范围已向西扩至徐家汇、宛平南路；南浦、卢浦、外白渡、汤臣四塔及和平饭店已有独立细化版本，整片 1:1 与电影级写实尚未通过验收。关联：[魔方空间总跟踪](cube-space-tracker.md)、[技术来源索引](space-sources.md)、[逐栋与桥梁复刻清单](shanghai-replica-tracker.md)。

## 用户要求与边界

- 从北外滩出发，沿黄浦江向南，经陆家嘴、徐汇滨江至前滩；全程必须同时覆盖浦西、浦东两岸，能够连续切换视角和漫游。
- 延续现代写实、电影质感和多轮网页截图迭代要求；保留魔方摆放、移动、转动及天气系统。
- 2026-09-06 完成调研；用户随后授权自主继续海面打磨并实现上海。本轮包含城市代码、本地地理资产、交互与浏览器验证，没有安装另一套渲染器。
- “向南”描述镜头游览方向，不据此推断江水流向。徐汇滨江与前滩在黄浦江两侧，不能当成同一岸上的顺序站点。

## GitHub 候选与选择

2026-09-06 通过 GitHub 官方仓库及 API 核实星数，后续会变化。软件负责渲染，不等于附带上海模型。

| 项目 | 2026-09-06 星数快照 | 能解决什么 | 对现有项目的判断 |
| --- | ---: | --- | --- |
| [CesiumJS](https://github.com/CesiumGS/cesium) | 15,678 | 地理坐标、地球/地形、大范围 3D Tiles 流式加载与相机 | 最成熟的地理场景备选；换主渲染器需重新适配现有 Three.js 魔方、镜面与 ABYSSAL 天气 |
| [MapLibre GL JS](https://github.com/maplibre/maplibre-gl-js) | 11,555 | 矢量底图、地图交互，可作为路线与数据覆盖检查工具 | 适合地图视图；单靠建筑拉伸不满足写实近景目标，暂不新增第二套地图运行时 |
| [NASA 3DTilesRendererJS](https://github.com/NASA-AMMOS/3DTilesRendererJS) | 2,451 | 在 Three.js 中加载、调度与释放 3D Tiles，支持大模型分块 | 当前优先验证；星数少于前两者，但与现有 Three.js 最直接兼容 |

实际采用已有 Three.js、OSM 本地地理数据及 Three.js 官方 Water 着色器，保留现有魔方、镜面和 ABYSSAL 天气。尚未取得可用的上海全段精细 tileset，因此没有安装 NASA 3D Tiles、CesiumJS 或 MapLibre；取得真实模型样本后再验证 NASA 加载器。上述星数为历史调研记录，本轮未重新核实。本轮没有找到并核实一个同时满足“热门仓库、该河段双岸完整数据、写实精细建筑、开箱即用”的上海开源成品。

## 数据与运行时实现

- 本地资产：[huangpu.json](../core/packages/client/public/assets/space/shanghai-v1/huangpu.json)，5,912,486 字节；共 17,347 个多边形，其中建筑 16,409、水域 115、绿地 823，另有 8,646 条道路折线、43 个江心航线点。建筑与水域几何来自 OSM，不是随机生成的楼群和河岸。
- [SOURCE.json](../core/packages/client/public/assets/space/shanghai-v1/SOURCE.json) 记录采集范围、原点、来源、快照时间与高度统计。获取日期为 2026-09-07，各 OSM 对象/响应时间不同，不能称为全城同日实测数据。地理数据按 ODbL 保留来源，页面显示 OSM 致谢，统一登记到 `/about`。
- 16,409 个建筑底模中，342 个有高度字段，1,527 个由楼层乘 3.2 米推算，14,540 个使用默认高度，约占 88.61%。当前高度推算不能支持逐栋 1:1 或准确天际线的声明。独立地标外形覆盖四座核心塔楼的普通底模。
- WGS84 经度/纬度投影到局部米制，原点 `[121.4991, 31.2534]`，东为 X 正方向、南为 Z 正方向；未混用 GCJ/BD 坐标。地面与水面高程为视觉设定，未接入真实垂直基准、地形测量或水位站。
- 数据生成入口：[build-shanghai-space.mjs](../core/scripts/build-shanghai-space.mjs)。在 `core/` 运行 `node scripts/build-shanghai-space.mjs .tmp/png/shanghai-osm`，读取本机忽略目录中的 40 份已缓存响应，不发实时请求。缓存包括 34 个矩形数据块、五个完整水域关系及补齐内环的徐家汇建筑关系 `16242360`；当前生成结果无未闭合关系。缓存不随仓库发布，重新采集时须按 SOURCE 清单准备数据。
- 客户端入口：[space-shanghai.ts](../core/packages/client/app/[lang]/space/space-shanghai.ts)。加载前检查数据版本、有限坐标/高度、非零航线及道路类型；失败显示重试提示。生成按约 2 公里范围合并网格，每处理 700 个多边形让出主线程；切换环境可取消加载，销毁时释放网格、材质、纹理及水面反射目标。
- 当前主要模型是东方明珠、上海中心、环球金融中心、金茂、南浦大桥、卢浦大桥、中华艺术宫及梅赛德斯奔驰文化中心的程序化外形。夜景增加分组亮窗及塔楼轮廓灯，由 00:00–23:59 场景时间连续驱动；更换房间风格保留当前时间。未取得这些建筑的精细 glTF/摄影测量模型。
- 黄浦江使用有实际岸界的 Three.js Water 着色器，反射目标复用可显式释放的 Reflector；法线图来自 Three.js r183，已本地保存并记录哈希。江水颜色、短风浪随天气变化，不套用外海长涌浪和冲岸泡沫。12 艘实例化船沿航线移动，尚无尾流。
- UI 提供“上海黄浦江”环境、十三个区域/建筑/桥梁机位及“沿江巡游/暂停巡游”。“徐家汇”为内陆区域机位；沿江巡游仍采用连续江心路径，速度 95 米/秒，末端停止，不绕进住宅区。拖动、滚轮或缩放滑块接管镜头后停止巡游。巡游是用户显式操作，独立于天气动画开关。
- 上海远裁面增至 100 公里，阴影范围随镜头移动，降低城市尺度的雾密度。闪电和龙卷风锚点跟随远离住宅的城市机位，避免南段天气仍只发生在北外滩原点。雨幕屋顶遮挡仍只覆盖当前住宅/公司，未覆盖全城建筑。

## 后续资产候选与缺口

| 层级 | 已核实的来源能力 | 上海目标河段仍须核实 |
| --- | --- | --- |

| 地标近景 | 支持独立 glTF/GLB 地标覆盖底模；模型来源尚未确定 | 东方明珠、上海中心、环球金融中心、金茂、外滩历史建筑、白玉兰广场、南浦/卢浦大桥及西岸/前滩重点建筑的准确外形与材质 |
| 实景重建 | 3D Tiles 可承载摄影测量模型；[Google 官方覆盖说明](https://developers.google.com/maps/documentation/javascript/3d/coverage) 区分全球地形与有限的精细表面覆盖 | 尚未实测上海具体覆盖，也未取得全段可用 tileset；不承诺接一个 API 就有整段写实上海 |
| 滨水细节 | 当前仓库已有海水与天气渲染 | 江水色、短风浪、岸墙、水位、码头、船只、尾流及桥下阴影；大洋长涌浪与沙滩冲浪不能直接套给黄浦江 |
