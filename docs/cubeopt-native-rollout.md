## 已有证据与边界

Linux 内核对照见 `solver/experiments/cube48opt-rust/x86-simd.md`。目前 AVX2 内核比 AVX-512 更快；内核耗时不能当作完整求解提速。正式选择以同一服务器、相同输入、相同线程数的完整求解为准。

Opt8 继续使用 `h48prun31h8.dat`（7,782,727,680 字节）及对应 818,008 字节小表。发布版本共用大表，不复制生成另一份。沿用不可变 bundle 和 `current.json` 切换；保留可用旧程序与表链接，失败可恢复。

服务器程序由 GitHub Actions 发布。Mac 统计计算沿用正式入口及资源保护，保护触发时保存结果并停止，不重设基线重跑。代码完成、验证、推送、部署及统计发布分别记录，不互相代替。
