BLD Algorithm DataBase

BLDDB (blddb.net) is a comprehensive Rubik’s Cube Blindfolded algorithm database including 3‑style corner (all buffers), 3‑style edge (all buffers), corner twist, edge flip, etc. It provides many options for each case, so the users can select algorithm based on their own preference.

What's New?

In Version 2, we've made significant improvements to enhance users' experience.

Streamlined Navigation

We've optimized our navigation for a smoother and more intuitive experience, ensuring that you can find what you need quickly and easily.

Dark Mode Support

We've added a dark mode option to reduce eye strain and provide a more comfortable viewing experience, especially in low-light environments.

Direct Linking to Specific Cases

We've introduced the ability to link directly to specific cases, making it easy to share and reference with others. For example: /corner?position=UFR-UFL-UBL&mode=manmade

Wildcard Matching Support

We recently launched support for wildcard matching, which allows users to see a complete set of cases at once. For example: /corner?position=UFR-UFL-*&mode=manmade

Easy Maintenance and Scalability

Version 2 is designed for easy maintenance, featuring a clean codebase built with Next.js and Tailwind CSS.

Enhancements and Compatibility

We've resolved several legacy bugs and implemented significant updates that were challenging in Version 1, while ensuring compatibility with the previous version.
