## 1. 先排列、后稳定子：完整角 96 商的稠密坐标

沿用 G、C、H、H_C、M 的记号。令 A=M×〈I〉，I(c)=c⁻¹。
这是集合 C 上的 96 元群作用；这里没有把 I 当成群乘法的自同构。
写角状态为 c=(p,o)，其中 p∈S₈、o∈V={o∈F₃⁸:Σoᵢ=0}。
自然投影 ρ:C→S₈ 对 A 等变：空间对称作用于 p 是共轭，I 作用于 p 是取逆。

### 1.1 纤维与稳定子定理

对 S₈ 的每个 A 轨道选最小排列 pᵢ，并对每个 p 选一个 transporter τₚ∈A，使 τₚp=pᵢ。
令 Aᵢ=Stab_A(pᵢ)。则有集合的双射

\[
C/A\;\cong\;\bigsqcup_i \rho^{-1}(p_i)/A_i.
\]

证明：先把任意 (p,o) 用 τₚ 搬到 pᵢ 的纤维。如果改选 transporter，两种搬运之差属于 Aᵢ，
所以该纤维中的稳定子轨道不变。反过来，若两个搬运后的状态属于同一个 Aᵢ 轨道，
用两个 transporter 的逆组合即可把原状态互相映射，故它们属于同一个 A 轨道。
不同排列轨道的纤维不会相交。这同时给出映射的单射性、满射性和与 transporter 选择无关的性质。

因此，不必为每次查询枚举 96 个完整角状态。可以提前储存排列的 transporter，
再查询该排列代表的朝向稳定子轨道。

### 1.2 排列轨道恰有 654 个

空间对称在八个角顶点上的排列 σ 有下表循环类型。普通共轭的不动数为中心化子阶 z(σ)。
带取逆的不动方程 p=σp⁻¹σ⁻¹ 等价于 (pσ)²=σ²，故不动数等于 σ² 在 S₈ 中的平方根数。

| σ 的循环类型 | 重数 | z(σ) | σ² 的平方根数 |
| --- | ---: | ---: | ---: |
| 1⁸ | 1 | 40320 | 764 |
| 2⁴ | 13 | 384 | 764 |
| 4² | 12 | 32 | 12 |
| 1²3² | 8 | 36 | 8 |
| 2·6 | 8 | 12 | 8 |
| 1⁴2² | 6 | 192 | 764 |

例如单位元的平方根数，即八点上的 involution 数，为

\[
\sum_{j=0}^{4}\frac{8!}{2^j j!(8-2j)!}=1+28+210+420+105=764.
\]

2⁴ 的平方根必须把四个二周期两两合成四周期：三种配对，每对有两种选择，给 12。
1²3² 的平方根可分别保留两个三周期或把它们合成六周期，给 1+3 种；两个固定点给 2 种，合计 8。
所以两个加权和为 47232 与 15552，Burnside 引理给

\[
\boxed{|S_8/A|=(47232+15552)/96=654.}
\]

基础报告已独立推得 |C/A|=934778。这不是简单的 |C|/96，因为存在非平凡稳定子。

### 1.3 实际朝向作用是仿射作用

不能只保存空间对称在八个角上的排列：角朝向的符号和偏移同样必要。
令空间作用为 Adₐ∘τ^δ，其中 a=(s,t)，τ 把所有 twist 取负，δ∈{0,1}。
考虑 Adₐ τ^δ(g^ε)，ε∈{+1,−1}。令 j=s⁻¹(i)，由源码乘法约定直接展开：

\[
o'_i=(-1)^\delta o_j+t_{p(j)}-t_j\quad(\varepsilon=+1),
\]

\[
k=p^{-1}(j),\qquad
o'_i=(-1)^{\delta+1}o_k+t_k-t_j\quad(\varepsilon=-1),
\]

全部运算模 3。固定 p 后，每个输出坐标只读取一个输入 twist，加上一个偏移，并可取负。
在 V 上这就是仿射映射。源码为每个查询编译一个这样的映射，应用到七个独立 twist，
随后进行一次局部类编号查询。

构造器逐个核对 transporter 和稳定子作用在 0 与七个基向量 eⱼ−e₇ 上的结果，
并与完整角乘法计算逐一比较。两边均为 V 上的仿射映射，因此这八点相等就证明它们在
全部 2187 个朝向上相等。这是完整的有限维证书，并非任取八个状态作抽样。

### 1.4 编号、储存与查询

对每个 pᵢ，按朝向编号递增扫描。第一次遇到的未标记朝向就是一个 Aᵢ 轨道的最小代表；
一次展开整个稳定子标记该轨道。设该纤维有 Nᵢ 个轨道，储存前缀和 offsetᵢ。
查询公式为

\[
\operatorname{id}(p,o)=\operatorname{offset}_i+
T_i\bigl(\operatorname{orientation}(\tau_p(p,o))\bigr),
\]

其中 Tᵢ 是一个长度 2187 的 u16 数组。由纤维定理，结果恰是 0..934777 的连续轨道编号。
排列代表和朝向代表均取最小值，所以它与基础版本的“完整角 rank 最小化”有相同的规范代表。
稠密 API 返回 rank 或 ID；它没有返回完整的解词还原标架，不能把一个 ID 当作标架凭证。

| 数据 | 元素与逻辑字节数 |
| --- | ---: |
| 40320 个排列的类号 u16 | 80640 |
| 40320 个排列的完整 transporter token u8 | 40320 |
| 654 个排列代表 u16 | 1308 |
| 654×2187 个朝向局部类号 u16 | 2860596 |
| 655 个 offset u32 | 2620 |
| 朝向代表 bitset | 178792 |
| bitset 的 select 前缀目录 u32 | 89400 |
| 索引合计 | **3253676** |
| 934778 个距离 u8 | **934778** |
| 索引与距离合计 | **4188454** |

这是数组长度乘元素宽度的逻辑大小。运行时 Vec capacity、对象本体、分配器、空间对称数组、
文件输入缓冲及其他求解器数据另计。`memory_bytes()` 返回当前各 Vec 容量所对应的缓冲字节数，
不是进程 RSS。

### 1.5 构建工作量的解析上界

设 kᵢ=|Aᵢ|。排列轨道有 96/kᵢ 个元素，因此

\[
\sum_i1/k_i=40320/96=420,\qquad
N_i\ge2187/k_i,\qquad \sum_iN_i=934778.
\]

排列整轨道标记只需 654×96=62784 个 token 像。朝向整轨道标记的动作数不超过

\[
\begin{aligned}
\sum_i k_iN_i
&=\sum_i\left[2187+k_i\left(N_i-2187/k_i\right)\right]\\
&\le654\cdot2187+96\left(934778-2187\cdot420\right)\\
&=\boxed{2989146}.
\end{aligned}
\]

若不同稳定子元素在该纤维上给出相同仿射作用，代码先去重，动作数还会减少。
另由 (kᵢ−1)(kᵢ−96)≤0 得 kᵢ+96/kᵢ≤97，故 Σkᵢ≤23118。
全部 transporter 和稳定子的零点/基向量核对至多 8(40320+23118)=507504 次。
这些界没有包括距离 BFS、距离表语义认证、分配器成本或查询后的缓存行为。

若排列从 S₈ 均匀抽取，其稳定子大小的平均值为 96×654/40320=109/70。
这不是搜索访问分布的平均值，更不是平均加速比。

## 2. 稠密距离认证，以及为什么通常不能把 36 个邻居再除以二

### 2.1 保持旧文件格式的直接稠密加载

`DenseCornerPdb::load_and_verify` 读取原来的完整角 96 文件协议，逐项检查：

1. 格式、长度及校验和正确；记录 rank 严格递增。
2. 每个 rank 确实是稠密索引对应轨道的最小代表。
3. 每个稠密 ID 恰好出现一次，全部 934778 个 ID 均覆盖。
4. 只有单位元轨道的距离为零，所有值均为合法 u8 距离值。
5. 对每个代表 r，全部 18 个右后继 canon(rm)（m∈S）满足相邻值差至多 1；每个正值节点至少有一个下降邻居。

这里的 18 边证书需要专门证明，不能借用“取逆是右图自同构”这个错误命题。
把每个规范代表的右后继组成有向图 Q_R。每条边的真 d_C 值之差至多 1。
对任何代表 r，取 r 的一条真最短右动作解词的首动作 m，则 d_C(canon(rm))=d_C(r)−1。
反复在当前代表选这样的动作，得到一条长度 d_C(r) 的有向路径到单位元；
任意路径又因距离每步至多降 1 而不可能更短。因此 Q_R 中**到单位元**的距离恰为 d_C。

现在对候选表 h：沿 Q_R 真最短路累加 Lipschitz 约束得 h(r)≤d_C(r)；
反复沿 h 的下降边到唯一零点，得 d_C(r)≤h(r)。所以 h=d_C。
代码检查 18×934778=**16826004** 条有向边，用稠密编号读取相邻值。
不需要构建反向图，也不要求候选 h 在原始完整图上预先满足所有边约束。
这是认证给定数值的证明，不是从单位元沿正向 18 边 BFS 的证明。

该加载路线不构造 88179840 字节的 raw-distance 证书数组，也不保留稀疏 DistanceNode 数组。
输入文件缓冲在逐边认证前释放。原稀疏加载路线仍保留，供本地互证。
减少了某个明确的临时数组，不代表已经测得进程峰值或加载时间改善。

### 2.2 后继稳定子约简的实际数学边界

令 B=Stab_A(r) 是完整角状态的稳定子。B 作用于带侧别动作 (side,m)：
普通空间元素保持 side，带取逆的元素交换 side 并把动作取逆，再应用空间置换。
同一 B 轨道中的动作产生同一个 A 轨道邻居，因此只保留这些动作轨道的代表是安全的。
但这里必须用完整状态稳定子，不能用只固定角排列的 Aᵢ；后者可能改变朝向。

这一技巧没有普遍的二倍约简。设非自由 A 轨道数为 t。任一非自由轨道大小至多 48，
每个至少对 96−|orbit| 贡献 48。因此

\[
48t\le96\cdot934778-88179840=1558848,
\]

\[
t\le32476,\qquad\boxed{\text{至少 }902302\text{ 个轨道的完整稳定子平凡。}}
\]

对这些轨道，稳定子约简不会合并任何带侧别动作。不同动作仍可能偶然通向同一邻居，
但那是另一种需要实际识别的重复，不能从“有 96 个操作”直接推得。

由 |C/M|=1841970 和 |C/A|=934778，取逆固定的 M 轨道数为
2×934778−1841970=27586。只有这 27586 个 A 轨道有带取逆的点稳定子。
这再次排除了“每个节点都能把左右各 18 个后继配成 18 对”的推断。

### 2.3 一个严格的 18 边替代方案及其代价

可以为每个规范代表只建立 18 个右后继，得到有向图 Q_R。
在每个代表上都有一个普通右动作沿真角距离下降，且任何边最多降低真距离 1，
因此 Q_R 中到单位元的有向距离恰为 d_C。
于是若显式存储该图的反向 CSR，从单位元沿反向边 BFS 就能精确建表。

不能从单位元沿这 18 条正向边直接 BFS；那计算的是另一个方向的距离，基础报告已给出一般反例。
18×934778 个 u32 邻接目标要 67304016 字节，另加 offset/计数。
如果先存目标再转置，会同时保留两份；若用两遍重算建反向 CSR，则重新计算了两遍 18 个邻居。
所以 18 边方案在邻居计算、内存和构建流程之间有取舍。本轮将 18 边用于给定表的认证，
没有实现这个反向 CSR 构建器；现有 BFS 与断点恢复仍使用 36 边方案。

## 3. 让完整角距离安全进入现有 NISS

### 3.1 将距离证书与半转子群证书分开

现有 `PruningOracle::prepare/lookup` 返回的同侧值必须左乘 H 不变。
完整角距离 d_C 仅保证 d_C(g)≤D(g)，不满足这个条件。
例如 g=U²：d_C(g)=1，但同侧半转子群距离为零。把 d_C 直接 max 进旧字段，
可能在剩余一步时错误触发“排除半转动作”的规则，删掉真实的一步解。

v2 在 `corner-research` feature 下增加独立入口：

```rust
fn distance_only_bound(&self, cube: &Cube, remaining: u8) -> Option<u8> {
    None
}
```

其唯一数值契约是 L(cube)≤D(cube)。它不要求 H 不变性、不要求一致性，也不要求与旧 max_bound 同范围。
`None` 表示本次没有额外证书。调用位置是零预算叶判定之后、旧查询流水线标记为 live/pending 之前。
若 L>remaining，直接走通用距离拒绝，并退出本节点；不写 normal_bound、inverse_bound、半转缓存或同侧查询值。

`frame.inverse` 已有完整状态，因此查询它可以避免为该拒绝条件物化延迟的 normal 状态。
D(g)=D(g⁻¹) 保证任意 L(g⁻¹) 也是 D(g) 的下界；这里甚至不要求 L 自身满足 L(g)=L(g⁻¹)。
具体实现使用 d_C，它还额外满足整个 A 上的不变性。

### 3.2 为什么通用余量传播可以保留

令当前剩余预算 r，证书给 D(x)≥L=r+δ，δ>0。
NISS 任意一次扩展，在某一标架中是右乘一个动作或左乘一个动作，并可把整个残余取逆；
所以相邻栈帧的真实距离之差至多 1。
退回 j 层祖先后，预算变成 r+j，距离下界至少 L−j，拒绝余量至少 δ−2j。
只在 δ−2j>0 时传播，因此最多退 floor((δ−1)/2) 层，与 `reject_bound` 的算术一致。

同一个父节点上的同面兄弟由同一面的不同非零幂产生。它们之间相差至多一个 HTM 动作；
若当前子节点 δ≥2，兄弟的距离至少 L−1>r，也可拒绝。NISS 可能改变存储侧别，
但其同面掩码及帧恢复记录的是该父帧中的动作，取逆只把这些动作换成逆动作，不改变这个距离界。

这些推理依赖真实距离的三角不等式，完全不依赖 H 不变性。
相反，旧 stage 2 中的 quarter/axis/backward-coset/coset-chain 规则有额外子群前提；
新入口在进入这些路径前退出，所以不会误用它们。

### 3.3 最优性、查询跳过和统计

新入口只删掉真实残余距离严格大于剩余预算的节点，故不删除任何预算内的解。
它沿用已有 NISS 的两端覆盖、前缀覆盖、动作标架及路径还原；在这些既有条件成立时，
按深度递增搜索找到的首个整解仍最优。有限节点预算中断只表示未完成当前层，不能记作无解。

`DistanceGatedOracle` 包装既有子群 oracle，完整转发旧行为。
`StrengthenedOracle` 也转发此独立入口，防止再包一层后丢失增强。
完整角 provider 在构造时保存认证表的最大值 Δ，查询时若 remaining≥Δ，则 d_C 不可能拒绝，直接跳过。
若内层的独立证书已经拒绝，也可以跳过新查表。后一跳过可能放弃更大的拒绝余量，但不会破坏正确性。

当前统计 `probes` 沿用原来 H 表查询的定义，不包含独立角距离查询。
因此不能用这个字段下降来声称总查表次数或总工作量下降；本地比较还要记录完整耗时、资源与配置。
普通 IDA 参考消费者也跳过零预算节点及 remaining≥Δ 时无用的角表查询。

## 4. 一个仅 2048 状态、严格提供新增信息的 EO 下界

### 4.1 完整 EO 是确定性右转移坐标

记边排列为 p，EO 为 e∈F₂¹²，Σeᵢ=0。源码乘法给

\[
e_{gm}(i)=e_g(p_m(i))\oplus e_m(i).
\]

右边不需要当前边排列 p_g，所以完整 11 位 EO 坐标有确定性 18 动作转移。
取前 11 位编号，第 12 位由偶校验恢复；在该 2048 点图上从零 BFS，得到精确抽象距离 d_E。
它是到 EO=0 的最小步数，通常不是到完整复原的距离。

所有半转生成器的 EO 都为零，零 EO 对乘法封闭，故 e_h=0 对所有 h∈H 成立。
于是 e_{hg}=e_g，得到

\[
d_E(e_g)=d_E(e_{hg})\le D(hg)\quad\forall h\in H,
\]

\[
\boxed{d_E(e_g)\le d_H^L(g):=\min_{h\in H}D(hg).}
\]

它可以与旧同侧表、u(g)、ell5(g) 取 max，再按旧接口上限截断；更强的 ℓ₅ 证明见 §6.5。
这个增强与独立的 d_C 拒绝入口有不同契约；代码分别处理。

### 4.2 一个旧投影和角距离都看不见的严格见证

在旧 Opt8 选中的 solved-corner 标架里，取边排列和角状态均为单位元，只翻转两个被截断 EO 所忽略的位置。
这是合法状态，且 g=g⁻¹。旧两侧 q 均等于 solved 键；所有角投影下界为零。
但该状态的 EO 恰有两位为 1。

逐项读取 `cube.rs` 六个 quarter 生成器可见：每个 quarter 恰翻转其四个移动边；
其逆同样翻转四边，而半转 EO 为零。还可以把这个下界提高到 3：
至多两步中，含半转时 EO 重量只能为 0 或 4；两次 quarter 同面时为 0、对面时为 8、
相邻面时为 6。最后一项来自两个面支持恰交一条边，而第二个面的置换保持自己的支持集合。
所以至多两步不可能产生重量 2，得到 d_E≥3。
直接用源码乘法手算 U R U 的 EO 依次为
{0,1,4,7}、{0,1,4,5,7,8}、{5,8}，因此确有重量 2 的状态在三步达到。
这证明该下界严格增强旧正常/逆两查与角下界的组合。
这里没有声称它严格增强“任意 96 次旧查询的最大值”；那个比较需要另外证明。

### 4.3 代码边界

`corner_oracle/eo.rs` 从已有 MOVES 构造全部 2048×18 个转移，BFS 后核对唯一零点、
全部边 Lipschitz 约束和正值下降边；返回后释放临时转移数组，只保留 2048 字节的距离及最大值。
它没有外部文件、预存未经认证的常量或第三方依赖。
`CornerOracle::new_with_eo` 与 `StrengthenedOracle::new_with_eo` 只增强同侧结果。

完整 EO 在本源码的空间作用下可以通过置换边位置处理：该位置置换对每个生成器的排列及四边翻转支持均等变，
而生成器生成 G，因而该关系推广到所有状态。相应 d_E 对 M 不变。
但是 EO(g⁻¹) 还依赖 p_g；单独 EO 坐标仍不支持一般取逆。
因此不能把这个 2048 状态表直接称为 96 轨道表。

同样，max(d_E(g),d_E(g⁻¹)) 是完整距离下界，不自动成为左 H 不变函数；
本实现每次以实际残余 Cube 查询各侧，不把这个 max 写入 H 字段。

### 4.4 EO 单坐标的最小 96 稳定粗化：七个重量

固定一个 EO 向量 e，可以搭配任意边排列 p，再选择角排列满足共同奇偶。
取逆将 e 变成被 p⁻¹ 搬运的向量，因而覆盖所有同重量 EO 向量。
任意包含原 EO 相等关系且对取逆稳定的等价关系，都必须合并所有同重量向量。
反过来，EO 重量在取逆和空间位置置换下不变，所以重量相等本身就是所需的稳定关系。
因此完整 EO 单坐标的最小 A 稳定粗化恰为

\[
w\in\{0,2,4,6,8,10,12\}.
\]

定义七项下界

\[
\nu(w)=\min_{\operatorname{wt}(e)=w}d_E(e).
\]

它是仅依赖 EO 且要求 96 不变的所有 admissible 下界中的逐点最大者。
原因是完整 EO 的最短抽象路径可以从完整单位元用同一动作词实现，故 d_E(e) 也等于所有具有 EO=e 的完整状态的最小 D；
再对重量纤维取最小值就是任何该类下界的上限，并且该上限本身 admissible。

左 H 不改 EO，右 H 只置换 EO 位置，所以 ν 同时左 H、右 H、M、I 不变。
于是

\[
\max\{v(g),\ell_5(g),\nu(\operatorname{wt}EO(g))\}
\]

仍是满足这些全部不变性的下界，且角状态复原的两翻转见证给 ν(2)=3。
代码的 `DoubleCornerOracle::new_with_eo` 使用这七项重量下界，`solve-v-eo` 对应这条路线。
七项数值从已认证的 2048 表取最小值得到，没有硬编码未证明或未运行的距离值。

**ν 不具有一般一致性，也不是七点存在边商图的最短路。**
取重量 2 的 EO，其中一位在某个面的四边支持内，另一位在外；转该面 quarter 后重量为 4。
ν(2)=3，而 ν(4)=1，违反 3≤1+1。
存在边重量图中甚至有 0→4→2 的两步路径，但真实重量 2 最少需要三步。
这个反例具体说明了：对非确定性粗坐标做普通 BFS，会丢掉不同边见证之间的兼容性。
本实现从精确 EO 距离取纤维最小值，不作该错误替代。

### 4.5 其余重量的解析信息

通过支持集分类还可证明

\[
\nu(0)=0,\quad\nu(2)=3,\quad\nu(4)=1,\quad
\nu(6)=2,\quad\nu(8)=2,\quad\nu(10)=4,\quad\nu(12)\ge5.
\]

后三项的关键约束是：相邻两 quarter 的六翻转集合包含整个第一面，并碰到它的对面；
相对两 quarter 的八翻转集合是两个相对整面之并。因此三步不能达到重量 10；
手乘 URDB 给重量 10 的四步见证。
若四步能产生全翻转，拆成两个至多两步的字，其 EO 集合必须互补。
两步可达重量只有 0、4、6、8，故只需排除 4/8、6/6。
八集合的补集是赤道四边，不能是任何两步四集合；六集合的补集不含整面，不能是另一两步六集合。
完整分类与手乘细节见 [下界附录 §3.3](corner96-bounds.md)。尚未给 ν(12)=5 的见证，不称其精确值为 5。
实现仍从认证的 EO 表生成七项 min，没有把这张解析表硬编码进去。

## 5. 当前 Opt8 的全 G 粗化：从万亿参考枚举到有限符号闭包

完整证明与可直接编码的规格见 [全局粗化附录](corner96-coarsening.md)。这里保留关键逻辑与数目。
目标 E 是包含 q(g)=q(h) 且对 A 稳定的最小等价关系。
**A 稳定不等于把 g 和 a(g) 合并**；最后的对称轨道折叠仍是另一项操作。

### 5.1 前提与新坐标

只使用实际 corner_class 中的 class 和 frame、完整 ESEP、保留的 EO 位置 3..10，
不假定 class 采用任何特定的最小代表选择法。
需要所选 frames 是真实的空间作用，并正常化块内置换群 K；字节格式检查本身不证明这一语义前提。
K 的角部分是两个 tetrad 内的 S₄²，边部分是三个边组内的 S₄³，角边排列满足共同奇偶。

q 对左 K 恒定；加入取逆稳定性后，E 也包含右 K 关系。
角 K_C 双陪集 D 可用 2×2×3 张量记录：每格统计身份 tetrad、位置 tetrad 和 twist。
边先只记录 3×3 矩阵 N，统计身份边组与位置边组交叉数；其行、列和均为 4。

Opt8 隐藏位置是 {0,1,2,11}，在三个边组中分别占 3、0、1 个位置。
对每个 D 选代表并读其 frame，令 b(D) 为完全可见的物理位置组，a(D)=b(D⁻¹)。
右 K 的偶块内置换把一个隐藏跨组翻转对搬成另外两个组上的全部偶翻转；
取逆同样给身份组上的自由。两个八位置集合至少交四点，它们的偶翻转空间相加，
恰为它们并集上的全部偶翻转空间。于是唯一可能尚存的 EO 信息位于一个保护格

\[
P(D)=(a(D),b(D)),\qquad
k=\#\{\text{该格中的翻转边}\},\quad0\le k\le N[P(D)]\le4.
\]

同 D 的不同代表之间可用左右 K 搬运；边补奇偶只需组内置换，不改变这些位置组/身份组。
因此这个结论对整个 D 成立，不只对所选代表成立。

### 5.2 分裂奇偶位为何在这里确实可以消掉

原 K 双陪集在所有彩色格至多一个元素时可能分裂，不能直接忽略那个奇偶位。
此处有额外 EO 自由：两个非保护位置组的八条边分布在六个未着色格中，必有某格至少两条边。
可将这两条边设为相同 EO，把所需的外部奇数翻转放到其他位置。
同时交换这两条边的位置与身份，就得到左右皆奇的稳定子。
它能把一个左右皆违反共同奇偶的搬运改成合法 K×K 搬运。

因此，左右 K 加上这些必然的 EO 自由所生成的基础关系 B₀，**恰由 (D,N,k) 分类**，
无需额外 split bit 或 charge；并且 B₀⊆E。

### 5.3 330960 是什么数，318480 又是什么数

角张量的未着色部分为 [[m,4−m],[4−m,m]]。m=0,1,2,3,4 时，满足总 twist=0 的三色张量数分别为
75、300、432、300、75，合计 **1182**。
边矩阵 N 共 **120** 个。行列对称性给任一固定格的 Σ_N N[a,b]=160，
所以 Σ_N(N[a,b]+1)=280，得到

\[
\boxed{|G/B_0|=1182\cdot280=330960.}
\]

这是基础符号类的精确数，不是 E 的最终类数。
当某个空间作用把 P(D) 搬到不同于 P(mD) 的格时，目标格全部 k 都被迫合并；
再沿 A 的角层作用传播这些标记。标记层只保留 (D,N)，其他层保留 k。
这恰为 B₀ 的最小 A 稳定粗化 B₁；若 r 个 D 被标记，则

\[
|G/B_1|=330960-160r.
\]

还能不读表就证明 r≥78：体对角 120° 在这些角双陪集上等效于对两个非对角 twist 格作三循环。
它固定的 D 为 m=4 的 75 层，加 m=1 的 3 层。与此同时，它把三个边组作三循环，
不固定任何有序保护格，因此这 78 层无论怎样选 frame 都须消去 EO。于是

\[
\boxed{|G/B_1|\le318480.}
\]

### 5.4 如何精确产生实际 q 纤维关系

扫描 153090 条 raw corner 数据，记录实际 O、D、frame 的组置换和格内 EO 偏移，按 O 分桶。
对每个 O 与 120 个规范交叉矩阵之一，产生描述符对应的 B₁ 顶点。
若所有描述符的保护格在规范标架中是同一个完全可见的格，分别对相同格内翻转数建星连接；
各 frame 若补翻转，使用 k↔n−k。
若有层已遗忘 EO、保护格不同，或者保护格遇到隐藏位置，则把该组所有允许计数连成一棵星。

最后一项不能只检查某个固定 ESEP：B₁ 已经遗忘同 N 内的具体排列，可以把保护格中的一条边放到隐藏位置，
再用另一组中的隐藏位置补偶奇约束，逐个连接 k→k+1。完整的必要性和构造性充分性在附录中逐项证明。
因此无需枚举 34650 种 ESEP 或 256 种保留 EO。

将这些星边送入并查集。每次新合并 u~v，同时处理每个 A 生成元的像 h(u)~h(v)，
直到无新合并。所得关系恰是 E：生成的每条边都属于 E，反过来结果包含全部 q 碰撞且 A 稳定。
用 4 个生成元时，映射数组与并查集都只随至多 318480 个顶点增长；
一个粗略的星生成访问上界为 120×5×153090=91854000，描述符去重可再减少它。

**尚未求值的是实际 snapshot 的最终 E 类数和最后是否仍有 k 信息。**
这两个结果需执行已给出的符号算法；本轮没有用猜测替代它们。
这个新商也没有自动获得单值右转移；若要定义下界，仍需纤维最小距离或完整诱导后继的证明。
它不构成“当前 Opt8 表可以原值直接减半”的依据。


### 5.5 进一步压缩成带符号图：残余 EO 的形式也可穷尽

令几何顶点为 (D,N)，一共 1182×120=**141840** 个。这是解码图的顶点数，**不是最终 E 类数上界**。
除“把所有计数连成一星”的情况之外，每条 q 星边及其共同 A 像都保持同一个 n，并给完整匹配

\[
k\longmapsto k\quad\text{或}\quad k\longmapsto n-k.
\]

所以每个几何连通分量只有三种可能：

- 触及任一全计数合并约束：整分量只余一个 E 类。
- 没有全计数合并，符号沿每个回路之和为偶：保留 n+1 个计数类。
- 没有全计数合并，存在奇符号回路：恰加入 k~n−k，余 ⌊n/2⌋+1 类。

证明是沿路径合成恒等/补数两个变换；闭路只有恒等与补数两种结果。没有第四种残余 EO 形式。
这给出最终坐标“分量 ID＋搬运后的 k”，或“分量 ID＋min(k,n−k)”，或仅分量 ID。
如果将来用带奇偶的并查集实现，已同根的奇符号回路也会产生新约束，必须传播其 A 像；
不能照搬普通并查集“同根即跳过”的优化。本包先给扩展顶点上的普通 DSU 参考实现，证明和状态处理更直接。

## 6. 如何从独立下界获得严格增强，而不破坏 H 契约

### 6.1 一步耦合可以严格优于分别查询再取 max

设 E 是完整 EO 距离，b(g)=max(u(c_g),E(e_g))。定义

\[
B(g)=
\begin{cases}
0,&b(g)=0,\\
\max\{b(g),\;1+\min_{m\in S}b(gm)\},&b(g)>0.
\end{cases}
\]

这是一个左 H 不变的 d_H 下界。证明：b>0 保证 g 不在 H；到 H 的任一最短字都有首步 m，
其后继满足 b(gm)≤d_H(g)−1。对全部 18 个 m 取 min 即得 B≤d_H。
左 H 平移与右后继交换，且 b 左 H 不变，所以 B 也逐点左 H 不变。
不能在这里仅对当前路径掩码允许的动作取 min，然后把结果无条件存回全局 H 表；
那是附带未来动作语言限制的证书，需要另外的覆盖证明。

存在合法完整 Cube 使增强严格：角部分取 U，边部分取 R。二者排列均为奇，
twist/flip 总和也满足合法性，因此可以组合。此时 u=E=1，b=1。
要一步使角状态进入 H_C，quarter 必须在 U 面，因为角 tetrad 的失配支持恰为 U 的四角；
要一步使 EO 归零，quarter 必须在 R 面，因为当前 EO 恰为 R 的四边支持。
两个动作集合不相交，half 又不能消去这两个正值；因此所有后继 b≥1，得到 B≥2>b。
该见证只比较 u 与 EO 的 max，不声称一定超过已有 Opt8/9 的总下界。

还能精确加强为 **B=3，而 b=1**。角 u≤1 的后继恰为 {U,U′,U²,D²}；
EO≤1 的后继恰为 {R,R′,R²,L²}。前者由角排列奇偶和 tetrad 支持判定，后者由面支持判定。
两集合不交；又因 u、EO 均一致，每个后继的值均至多为 2，因此全部 18 个后继恰有 b=2。
故一步增强值是 3。这不证明完整状态的 d_H 或 D 精确等于 3。
各后继类型的完整推导见 [下界附录 §6](corner96-bounds.md)。

参考算法如下。它可以按预算在 b 已拒绝、b=0、或声明上限不足以产生拒绝时跳过；
若要报告 B 的完整数值，必须遵守下列全后继定义。

~~~text
coupled_bound(g):
    b0 = max(u(corners(g)), EO(edges(g)))
    if b0 == 0: return 0
    smallest = infinity
    for m in all_18_HTM_moves:
        smallest = min(smallest, max(u(corners(g*m)), EO(edges(g*m))))
        if smallest + 1 <= b0:
            return b0  // 后续 min 只会更小，不可能强化
    return max(b0, 1 + smallest)
~~~

更强的完整乘积表有 918540×2048=**1881169920** 个坐标；每项一字节时仅值数组就约 1.88 GB。
上面的一步算法以额外后继查询换去这个乘积数组。
`coupled_one_step_h_bound` 已实现该公式，`query-u-eo` 可单独比较耦合前后的数值；
它尚未被搜索包装器自动调用，没有认为额外查询在实际搜索中一定划算。

### 6.2 一个普通距离标量不能免费变成 H 下界

若只知道 L≤D(g)，以及 R≥max_{a∈H}D(a)，三角不等式给

\[
\boxed{\max(0,L-R)\le d_H(g).}
\]

没有更多结构时，这个半径损失不能普遍消除。H 内从单位元沿 half-turn 路径走到一个
D 达到 subgroup radius 的元素，D 每步至多改变 1，因此途经每个中间整数；
这些状态 d_H 全为零，却可有对应的正 D 下界。将 L 截断到 remaining 附近并不能修复这个问题。

若拥有整个可采纳函数 b，则正确操作是 H 下包络

\[
(P_Hb)(g)=\min_{a\in H}b(ag).
\]

它左 H 不变且≤d_H。对完整角距离 d_C，这正是已经构造的 u。
因此 u 是该角投影内最强的同侧 H 下界；对同一精确角信息作更多采样不能超过它。
若 b 已左 H 不变，还有

\[
P_H\max\{b(g),b(g^{-1})\}
=\max\left\{b(g),\min_{a\in H}b(g^{-1}a)\right\}.
\]

对 b=u，第二项等于双陪集距离 v≤u，所以“先 normal/inverse max，再做 H-safe 包络”
最终仍为 u。这个结论不自动适用于更粗的旧表 b；后者需要独立分析。
空间 M 正常化 H，故固定空间查询集合的 max 仍保持左 H 契约；加入 inverse 没有同样的保证。

### 6.3 多个距离证书的覆盖式转换

已知 a_i∈H、L_i≤D(a_i g)，以及 C(h a_i⁻¹)≥D(h a_i⁻¹)，则

\[
F(g)=\min_{h\in H}\max_i\bigl(L_i-C(ha_i^{-1})\bigr)_+\le d_H(g).
\]

对每个 h,i，D(hg)≥L_i−D(h a_i⁻¹)≥L_i−C(h a_i⁻¹)，故公式成立。
F(g)>r 等价于每个 h 都被至少一个证书覆盖：C(h a_i⁻¹)<L_i−r。
在角投影中，用 d_C 证书与相应角距离上界 C_C，可在 96 元的 H_C 上直接写有限覆盖算法，
所得结果不超过精确 u。不能把一般完整 Cube 公式中的 H 任意替换为 96 个 H_C lifts。
固定、不完整的采样集合所产生的数值可以是有效 H 证书，函数本身却未必逐点 H 不变；
满足现有 oracle 的更强契约，可使用全 H 采样、同一函数 L_a(g)=b(ag) 和同一 C，
或证明标签、数值与代价整体随 H 平移协变。仅有“采遍 H”而数值算法随标签任意变化，仍不充分。

### 6.4 成本分摊与路径传播各自能做什么

多个可采纳下界直接相加一般不安全：一个 quarter 可以同时被角表和 EO 表各计为 1，
相加就大于该完整状态的一步解。可证明的加法规则是为每个 move m 分配非负成本 c_i(m)，
要求 Σ_i c_i(m)≤1，分别建立加权 pattern 距离 h_i；目标集必须包含 H 的投影。
任何实际解词在所有 pattern 中都给路径，累加成本不超过字长，因此 Σ_i h_i≤d_H。
若还需空间不变性，M 必须在 pattern 上良定义并保持目标和后继，且成本随空间作用运输，
或整组 pattern 与成本共同协变；在这些条件下可选 move 轨道上恒定的成本。

均匀成本 c_i(m)=λ_i、Σλ_i≤1，只给 Σλ_i h_i^unit≤max_i h_i^unit；它无法严格超过原 max。
非均匀成本在此组合中的具体收益尚未给出见证。一手文献也把可加性建立在明确的抽象成本条件上，
见文末 Yang 等人的论文，而非仅凭“不同 pattern”这一名称。

对任意 b≤d_H，固定右动作字 w 给 b(gw)−|w|≤d_H(g)。但精确 u、精确 EO 及其 max 都一致，
所以这种“后继值减路径长度再取 max”不能提高它们；它与 §6.1 的“1＋全部后继 min”不同。
一般的 D 证书可沿实际移动边损失 1 传播；H 证书穿过 NISS 反侧 quarter 时，不能未经证明
继续保持原侧 H 类型。反侧 half 的零损复用使用了更强的群结构。

### 6.5 常数下界由 4 提高到 5：已证明但不声称锐性

进一步的短字定理为：**任意 HTM 长度≤4 的字，若其角状态在 K_C，则已经在 H_C。**
因此定义

\[
\ell_5(c)=5\,\mathbf 1_{K_C\setminus H_C}(c)
\]

得到双侧 H、M、inverse 不变的 d_H 下界。因为对 c∈K_C\H_C 和任意 h∈H_C，
hc 仍在 K_C\H_C；若 u(c)≤4，就有一个这样的 hc 能由≤4 个动作实现，与定理矛盾。

证明不用枚举 18⁴ 个字。把角位置写成 v=(x,y,z)∈{±1}³，χ(v)=xyz 区分 tetrad，
B(p)={v:χ(pv)≠χ(v)}。源码乘法给

\[
B(pq)=B(q)\mathbin{\triangle}q^{-1}B(p),\qquad
t_{Q_a}(v)=k_a\chi(v)\mathbf1_{F_a}(v)\pmod3,
\quad(k_x,k_y,k_z)=(-1,0,1).
\]

两个角状态处于同一左 K_C 轨道，当且仅当 B 与位置 twist 全部相等。
按字中 quarter 数分类：至多两个 quarter 时，B=0 迫使其支持在中间 half 字的共轭下对齐，
最终为单位或 half 的 H_C 状态；三个 quarter 时，将字拆成 u v⁻¹，|u|,|v|≤2，
QQ 的相邻面失配支持有四个非零 Fourier 字符，不能等于 QH/HQ 的单字符支持。
四个 quarter 时，QQ 的相同 B 只有同面、相对面、相邻面三种类型；
前两种的 twist 条件直接给同一 H_C 轨道，相邻面支持的两种几何表示若同时有相同 twist，
将强制 k_x=k_y=k_z，与上式矛盾。完整的两种表示公式及纤维方向证明见
[下界附录 §9](corner96-bounds.md)，已经独立符号复审。

源码保留旧 `lower_bound4` 的 4/0 行为，新增 `lower_bound5`，当前研究 oracle 使用后者。
`verify-small` 和对应测试源码扩至≤4 字的独立核对，但本轮没有运行。
尚未构造达到 5 的 K_C\H_C 见证，因此不称 5 为最优常数。

## 7. 缓存、最优性与后继覆盖的最终条件

### 7.1 三种缓存内容必须分开

| 缓存内容 | 可安全运输的对象 | 必须保留的条件 |
| --- | --- | --- |
| 数值 L≤D(g) | 完整状态的全部 96 操作 | 只是距离证书，不能附送 H 掩码；生成函数不必在轨道上给相同值 |
| 数值 L≤d_H(g) | 左 H 与正常化 H 的空间 M | inverse 改变侧别；双侧复用需额外证明 |
| 受限 DFS 在预算 r 内失败 | 同状态且同未来动作语言；预算 r′≤r | 必须完整覆盖、未取消、未达到资源上限；路径上下文不能丢失 |

精确 D 自然可按完整 96 轨道缓存，但“在一个受限上下文中没找到解”不自动等于 D>r。
形式化地，失败只断言：在该自动机上下文 σ 允许的语言 L_σ 中，不存在长度≤r 的解词。
只有另证 L_σ 包含每个预算内解的某个等价代表，才能把它提升成全局距离证书。

M 规范化时，必须同时运输 last face、双侧 move mask、active side、root stabilizer、
prefix ownership 等实际限制。inverse 把右延伸变成左延伸，不能只把状态取逆而保留一侧自动机。
当前普通 IDA* 的失败缓存仍以完整 Cube＋previous face 为键；没有改成角 ID，也不缓存取消。
新的 NISS 独立距离 gate 没有新增失败缓存。

### 7.2 可采纳并不要求启发式一致

IDA* 的安全拒绝只需要 h(g)≤D(g)；ν 的不一致反例不破坏这一结论。
但缓存路径失败、把函数值沿边原样继承、以及合并图上 BFS 的正确性各有更强条件。
这也是本包在给定表上使用完整语义证书、对 ν 使用纤维 min、对 NISS 使用独立 D 拒绝通道的原因。

在所有有预算的搜索命令中：返回并重放到 solved 的解可以验证其长度；
声称最优还需要低于该长度的深度全部完成、允许后继覆盖成立、所有下界可采纳。
若达到 node cap 或取消，只能返回预算耗尽状态，不能写“无解”或把它缓存成完成失败。
本轮没有实际求解输出，也没有以测试源码的存在代替这些完成证据。

### 8.2 新命令

以下文件参数含义：U 是已认证角左陪集表；FULL96 是已有完整角 96 文件；DOUBLE 是已有双陪集类文件；
SMALL/OPT 为匹配的现有 Opt8 或 Opt9 输入。完整用法见 binary 的 HELP。

| 命令 | 用途 |
| --- | --- |
| `verify-eo` / `query-eo` | 显式构造并认证 EO 表；输出同侧、逆侧和 7 项重量界 |
| `query-u-eo U` | 比较 max(u,EO) 与全部 18 后继的一步耦合界 |
| `verify-dense FULL96` | 直接稠密加载，并执行 18 边全表证书 |
| `query96-dense FULL96` | 查询角精确距离与稠密 ID |
| `solve-u-eo U DEPTH NODES [CTX]` | 同侧 max(u,ell5,EO) 的原 NISS |
| `solve-v-eo U DOUBLE DEPTH NODES [CTX]` | 双侧/96 不变 max(v,ell5,ν) 的原 NISS |
| `solve-u-distance U FULL96 DEPTH NODES [CTX]` | u 的 NISS 加稠密 d_C 独立 gate |
| `solve-u-distance-sparse U FULL96 DEPTH NODES [CTX]` | 同上，保留 sparse 距离查询用于对照 |
| `solve-distance-dense FULL96 DEPTH NODES [CACHE]` | 普通 IDA* 使用稠密 d_C |
| `solve-opt-distance U FULL96 8\|9 SMALL OPT DEPTH NODES [CTX]` | 原 Opt＋u 同侧增强，再加独立 d_C gate |
