# H48 递归 BPMX 实验

本候选独立于 `../h48-bpmx`，补丁直接应用到原 vendor 快照的副本，不能叠加单层补丁。原源码与 H10 表均不修改。接口保持 `bpmx.h` 的 `cuberoot_h48_bpmx_enable(bool)`，编译时仅编译本目录 `engine.c`，其内部包含候选 `nissy.c`。

## 传播证明

若一次实际查表在后代状态 `z` 得到可采纳下界 `L(z)`，距它 `k` 条搜索边的祖先 `x` 满足：

```text
d(x) >= d(z) - k >= L(z) - k
```

HTM 的面转代价均为 1，且字长 `d(x)=d(x^-1)`。每层即使切到逆状态，仍是一次面转后至多再取逆，所以上式同时覆盖正向、前转以及 NISS。每层只减 1；合并多个证据取最大值；只有结果严格大于该层剩余预算才剪枝。

DFS 保留原来的解数／错误返回值，另用 `generic_bound` 返回真实查表证据产生的通用下界。pipeline 把真实邻居界 `L` 转成当前节点界 `max(0,L-1)`；递归返回后再将子界减 1。无直接剪枝时也保留该证据，供更高层使用。

这里没有把“这次没搜到”转成距离证据。已达到解数、遇到已复原状态时输出 0；错误返回清空证据；末层搜索无论找到解与否都不凭受限动作集合生成距离下界。现有暂停／终止检查仍位于线程任务边界。有效界只来自本次真实查表及其沿路径减 1 的结果。

## 实现约束与计数

独立通用下界不进入 `pn/pi`、`lb_normal/lb_inverse` 或半转动作掩码，也不改变搜索方向选择。所有新增整层退出通过统一清理路径恢复 cube、inverse、两个动作掩码、正逆解长度以及原有正逆下界。原始解数与错误语义保留。

- `stats[7]`：局部与递归传播导致的总剪枝次数。
- `stats[8]`：这些剪枝跳过的尚未处理候选数。pipeline 提前退出时，其余候选不一定都能通过完整过滤；不能当作精确减少的递归节点。
- `stats[9]`：总剪枝中由子 DFS 返回界触发的祖先剪枝次数，可用于衡量多层传播是否实际生效。

这是多层反向传播版本，未加入新表、transposition 表、前向启发式缓存或新的失败缓存。其效果仍须与关闭开关及单层候选分别核验；更少节点不保证更短时间。

## 验证边界

`engine.test.c` 单独编译。它使用约 1.1 MB 人工 cocsep 缓冲检查实际 DFS 提前退出和状态恢复，用真实魔方的至多两步枚举检查距离边界与正逆操作恒等式，并检查证据逐层减 1、等号不剪枝、零值不下溢、提前结束不产生虚假界。

这些检查不加载 H10、不生成表，不是完整最优性验收。真实验收应复用已知精确长度案例和同一 H10 表，在可重复的单线程条件下比较所有结果、节点与查表次数，再比较单层／递归的实际时间。

数学背景见单层实验的[一手论文出处](../h48-bpmx/README.md)。不能把论文中的收益比例直接用于当前 H48。
